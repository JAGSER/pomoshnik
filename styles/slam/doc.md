# SLAM - терминальный HUD: графит, лайм, точки-пиксели

Ролик выглядит как экран системы, которая сама себя запускает: тёмный графит, мелкий моно-HUD по краям, печать с курсором, огромные цифры из LED-точек, иконка из точек, которая рассыпается в облако и собирается снова, наклонные ленты «/// ...» и глитч на склейках.

## Палитра
- Фон `#08090C`, в центре светлее до `#141518` (радиальная виньетка), сетка 90 px линиями rgba(255,255,255,0.035). Поверх всего сканлинии каждые 4 px и зерно (`SLAM.frame` делает сам).
- Текст `#E8E9EC`. Второстепенный текст `#8B8E94`, тусклый `#5C5F66`, подписи HUD `#6B6E73`.
- Акцент один: лайм `#C6FA40` (точки `#B4E838`, тусклые `#7E9E2A`, светлые искры `#EAF7C8`). Лаймом: одно ключевое слово или вся вторая строка заголовка, курсор, «$», «[ ok ]», статус «работает», полоска прогресса, точки-пиксели.
- Сцены-вставки: полноэкранный лайм `#C6FA40` с чёрным текстом `#0A0B0D` и светлая `#E4E5E8` с чёрным текстом (`bg:'lime'`, `bg:'light'`). Только на короткие удары 0.5-0.7 с.
- Красный `#FF3B4E` только точка окна лога; красный/голубой только в глитче.

## Шрифты
- Заголовки: гротеск `SLAM.SANS` вес 500, строчные, 90-160 px, межстрочный 1.04. Ключевое слово лаймом (`hi`) или вся вторая строка (`hiLine`), дополнение серым (`greyLine`).
- Подводка: гротеск 400, 38-44 px, серая, важная часть белая: `'Обычные слова *белая часть до конца*'`.
- Моно `SLAM.MONO`: HUD 21 px с разрядкой (только `tracked`, letterSpacing нельзя), разделы `[02] РАЗДЕЛ` 26 px, комментарии `// ...` 30 px, терминал 34-84 px, лог 34 px.
- LED-шрифт 5x7 (`pixText`, свой, рисуется квадратами): цифры, %, кириллица. `mode:'cluster'` (каждый пиксель - крестик 3x3, как табло) для огромных чисел, `mode:'solid'` для слова в строке гротеска («НЕТ полива») и плакатного слова на весь экран («БЕЗ / РУК»).

## Композиция (вертикаль 1080x1920)
- HUD всегда: сверху две строки моно (y 50 и 86), линия y 106; уголки рамки y 124 и 1636; снизу «■ РИС.0N - НАЗВАНИЕ» и «РЕНДЕР: LIVE · время» (y 1668), лаймовая линия прогресса y 1685. `setHud({...})` задаёт тексты под тему.
- Контент по левому краю x 60 (цифры 95% по центру, x 81). Сверху вниз: раздел `[0N]` y≈205-470, заголовок, подводка, затем крупный блок (панель с иконкой, LED-число, лог, карточки).
- Горизонтальные приёмы оригинала переложены в столбик: панель-иконка под заголовком, счётчики над логом, ряд карточек 01-05 стал сеткой 2x3, шестая ячейка - итог «СОЗРЕЛО 2/5».
- Ничего ниже y 1650 (кроме HUD). Не больше 2-3 текстовых блоков.

## Приёмы
- `term` - старт: «$ команда» печатается с блочным курсором, затем строки `[ ok ] имя ........ значение` по одной (0.13 с), последняя `> вывод` лаймом.
- `typeLines` - заголовок печатается по буквам (26-30 зн/с), свежая буква на миг глитч-символ (+#%/) и падает на базу, в конце мигающий лаймовый блок-курсор.
- `dots` - иконка из точек (росток, сетка 28x34, клетка 15-16 px) в `figPanel` с уголками и подписями «РИС.01 - ...». Растёт снизу вверх (`grow`), фрагменты-блоки 3x3 отлетают вверх-вправо, в конце сцены `scatter` рассыпает в облако. Свою иконку темы делай так же: функция-маска на сетке.
- `morph` - облако из точек прошлой сцены собирается в `pixPoints('95%', ...)`, потом стоит `pixText` cluster со свечением. `ratioBar` - лаймовая доля + белый остаток, подписи «■ АВТО 95 / ■ ВЫ 05».
- Серия ударов «НЕТ ...»: 3 сцены по 0.6 с (лайм, тёмная, светлая) + плакат LED «БЕЗ / РУК» с двумя скрещенными лентами (`ribbon` лайм -0.12 рад и белая +0.1 рад), текст лент `/// ...` бежит 160-260 px/с.
- `logPanel` - окно журнала: строки агентов из «в очереди» в «работает» каскадом 0.17 с, строка человека подсвечивается с белой кнопкой «собрать ✓», внизу лента событий `06:02:17 полив → ...`. `stats` - ячейки с LED-числами, счётчик крутится.
- `card` - тёмная карточка: тег в рамке, номер-пиксели тусклым, название, лаймовая (готово) или серая подпись, подвал «грядка.01 / собрать ↗», у готовых лаймовая кромка сверху.
- Финал: `vortex` (кольцо частиц стягивается) -> `logo` (иконка белыми пикселями + лаймовые фрагменты) -> `wordmark` (строчное слово + лаймовая точка) -> слоган с курсором -> `brk('[ подключить ]')` + моно-строки.

## Движение
- Камера: после склейки наезд 1.04 -> 1.0 за 0.55 с, дальше медленный дрейф +1.4% за сцену; перед глитч-склейкой рывок +3% и сдвиг кадра по X.
- Текст печатается, а не проявляется. Интерфейс (кнопка, карточки) на пружине `spring`, с лёгким перелётом.
- Сцены 2.5-3.5 с, удары 0.6 с. Фоновое движение всегда: мерцание точек, дрейф фрагментов, бег лент, счётчики HUD.

## Переходы (`frame(k, t, CUTS, SCENES, {tr})`)
- `glitch` (основной): сдвиг кадра, полосы красного/голубого тона, подъём чёрного, серые и оливковые горизонтальные полосы, лаймовая линия с цветными концами. 0.13 с до и 0.17 с после.
- `grey` - кадр уходит в серую сетку (#5D5E61), `flash` - белая вспышка (перед финалом), `cut` - жёсткая склейка с двумя-тремя полосами (для серии ударов).
- Рассыпание частиц делается в самих сценах (`scatter` в конце, `morph` в начале следующей).

## Звук
Сухие клики и тики: `type`/`tick`/`key_soft` под печать и строки терминала, `click` (pitch 0.6) + `tick` на глитч (`cutSounds`), `woodblock`/`rim` на ударах «НЕТ», `sparkle` на рассыпании, `counter`/`odometer` на счётчиках, `toggle_on` с растущим pitch на «работает», `notify` на кнопке человека, `magic` -> `success` на сборке логотипа. Громкость 0.08-0.16.

## Запреты
- Без длинного тире, эмодзи, чужих марок, адресов и ников. Без градиентов кроме виньетки, без других акцентных цветов.
- Не центрировать заголовок на пустом фоне (кроме финала). Не делать текст жирнее 500 и не капсом (капс только моно и LED).
- Свечение только у LED-цифр, точек и лаймовой кнопки. Глитч только на склейках.

## Каркас
```js
const S = SLAM, C = S.C;
const CUTS = [2.2, 5.6, 8.6, 9.2];             // склейки на ключевых словах
const TRS = ['glitch', 'glitch', 'cut', 'flash'];
S.setHud({ tl: 'МАРКА.ОНЛАЙН', tr: ['ЦЕЛЬ:', '95% АВТО / 5% ВЫ'], bl2: ['ЗАДАЧИ:', '2/5'], bm2: ['АПТАЙМ:', '24/7'], clock: 'МСК 06:14' });
function A(g, lt, sc) { S.term(g, 'марка --старт', [{ name: 'модуль', val: 'онлайн' }, { prompt: 'готово' }], 70, 760, lt, { big: 84 }); }
function B(g, lt, sc, t) {
  S.kicker(g, 'о чём ролик', 60, 250, lt, 0.05);
  S.typeLines(g, 'Заголовок|в две строки', 60, 290, lt, 0.2, { size: 132, hi: 'строки' });
  S.figPanel(g, 60, 860, 960, 730, { tl: 'РИС.01 - ИКОНКА', tr: ['РЕЖИМ:', 'АВТО'] }, S.eo(lt / 0.3));
  S.dots(g, 540, 1228, 15, { grow: S.prog(lt, 0.3, 1.5), scatter: S.ein(S.prog(lt, sc.d - 0.32, sc.d)), t, glow: true });
}
const SCENES = [{ bg: 'dark', fig: 'РИС.00 - ЗАГРУЗКА', draw: A }, { bg: 'dark', fig: 'РИС.01 - ...', draw: B } /* ... */];
function draw(t, k) { S.frame(k, t, CUTS, SCENES, { tr: TRS }); }
function sound(s) { S.cutSounds(s, CUTS, TRS); s.play(0.2, 'type', 0.09); }
```
