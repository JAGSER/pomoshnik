# SLAM - терминальный HUD: графит, лайм, точки-пиксели

Ролик выглядит как экран системы: тёмный графит, мелкий моно-HUD по краям, печать с курсором, огромные цифры из LED-точек, картинки из квадратных точек (люди, дома, транспорт), которые собираются снизу вверх, рассыпаются в облако и собираются снова, наклонные ленты «/// ...» и глитч на склейках.

## Палитра
- Фон `#08090C` с виньеткой и сеткой, сканлинии и зерно делает `SLAM.frame`.
- Текст `#E8E9EC`, второстепенный `#8B8E94`, тусклый `#5C5F66`, HUD `#6B6E73`.
- Акцент интерфейса один: лайм `#C6FA40` (ключевое слово заголовка, курсор, «$», статус, прогресс, LED-числа).
- **Мир в своих цветах.** Точечные объекты (люди, здания, транспорт, животные, природа) рисуются цветами из `SLAM.WC`: `pink orange red rust(рыжий) yellow blue sky navy green brown wood violet beige white grey sea warm(свет окна)` или '#hex'. Цвет, названный в тексте, обязателен: «розовое солнце» `col:'pink'`, «оранжевые куртки» `shirt:'orange'`, «синий автобус» `col:'blue'`, «жёлтый кран» `col:'yellow'`, «рыжий пёс» `col:'rust'`.
- Вставки: полноэкранный лайм с чёрным текстом и светлая `#E4E5E8` (`bg:'lime'`, `bg:'light'`), только удары 0.5-0.7 с.

## Шрифты
- Заголовки `SLAM.SANS` 500, строчные, 90-160 px: ключевое слово лаймом (`hi`) или вторая строка (`hiLine`/`greyLine`). Подводка 38-44 px серая, `*белая часть*`.
- Моно `SLAM.MONO`: HUD 21 px (`tracked`), разделы `[02] РАЗДЕЛ` 26 px, `// комментарий` 30 px, терминал 34-84 px.
- LED 5x7 `pixText` (цифры, %, ₽, кириллица): `mode:'cluster'` для огромных чисел, `'solid'` для слова-плаката.

## Композиция (1080x1920)
- HUD: две строки моно сверху (y 50/86), уголки y 124 и 1636, низ: подпись сцены `fig` и таймкод (y 1668), лаймовая линия прогресса. `setHud({tl, tr:[подпись, значение], bl2, bm2, clock, rec})`: все поля необязательны, пишутся только фактами из озвучки (место, число, время дня); пустые не рисуются. Не выдумывай погоду, часы, проценты.
- Контент слева x 60. Сверху вниз: раздел `[0N]`, заголовок, подводка, крупный блок: `figPanel` с картинкой из точечных объектов, LED-число, лог или карточки. Ничего ниже y 1650. Не больше 2-3 текстовых блоков.

## Приёмы
- `typeLines` заголовок печатается с глитч-буквой и курсором. **Скорость печати подбирай так, чтобы фраза допечаталась до того, как голос её договорил** (`cps` = длина / (время слов - 0.3), обычно 40-70), сокращай заголовок до 2-5 слов.
- `term` - «$ команда» и строки `[ ок ] имя ..... значение`; `logPanel` окно журнала (path, file, tag, строки с `st0/st1`, лента событий); `stats` ячейки LED; `card` карточка; `ratioBar(…, {a, b})`; `ribbon` лента `/// ...` с текстом из темы. Все тексты этих блоков только из озвучки; их используй, если тема про систему/данные, а не вместо картинки.
- `dots` иконка из точек: растёт (`grow`), рассыпается (`scatter`), `morph` собирает облако в `pixPoints`. Иконка по умолчанию - росток из примера: для своей темы делай `SLAM.icon(id, cols, rows, (x,y)=>0|1|2)` и передавай `{icon}` в `dots`/`logo`, точки для `morph` - `iconPts(icon, cx, cy, cell)`.
- Финал: картинка темы (объекты или иконка) + `wordmark` + строка; `vortex`, `logo`, `brk('[ ... ]')` только если подходят теме.

## Типовые объекты (точечные спрайты, кэшируются)
`x, y` = середина низа (ноги, колёса, низ здания) на земле. Общие параметры: `cell` (размер точки), `col`, `dir:-1` зеркально, `p` 0..1 собирается снизу вверх (появление), `alpha`, `t` (время для анимации).
- **Люди** `person(g,x,y,{kind:'adult'|'child'|'old', pose:'stand'|'walk'|'run'|'wave'|'dance'|'hold'|'sit', t, shirt, pants, skin:0..3, hair:0..4|цвет, hairStyle:'short'|'long'|'bun'|'bald', dress:цвет, helmet:true|цвет, hat, bag:true|цвет, item:'book'|'box'|'bag'|'cup'|'phone'|'fish'|'flag'|'flower'|'accordion'|'basket', itemCol, cane, i})` → `{top, hand:{x,y}, h, seat}`. Рост при `cell` 8: взрослый ~190 px, ребёнок ~140. `crowd(g,x,y,{n,gap,kinds,shirts,poses,pose,t,helmet,bag,each:i=>({...})})` ряд разных людей (не сливаются: разные цвета, шаг ≥ 64 px).
- **Здания** `house(g,x,y,{w,h,col,roof,lit})` · `tower(g,x,y,{floors,cols,col,built 0..1 стройка,lit 0..1,out 0..1 погасшие по одному,seed})`→`{top,left,w}` · `shop(g,x,y,{w,h,col,awning,sign})` · `cafe(…)` · `school(g,x,y,{w,h,col,sign,lit})` · `crane(g,x,y,{h,jib,col,at,drop,load:{w,h,col}})`→`{hook}` · `lighthouse(g,x,y,{h,col,stripe,on,t})` · `stall(g,x,y,{w,awning,goods:[{col,n,fish,label}]})` прилавок.
- **Природа** `tree(g,x,y,{kind:'leaf'|'pine'|'bush',h,col,fruit})` · `grass(g,x,y,w,{col})` · `leaves(g,t,{x,y,w,h,n,cols})` падают · `sun(g,x,y,{r,col,horizon,rise})` · `moon(g,x,y,{r,full})` · `stars(g,t,{x,y,w,h,n,on})` · `cloud(g,x,y,{w,col})` · `sea(g,x,y,w,h,t,{col,glint:{x,col}})` · `hill(g,x,y,w,h,{col})`.
- **Транспорт** `car(g,x,y,{col,move,t})` · `bus(g,x,y,{col,num,people,move,t})` · `bike(g,x,y,{col,t,rider:{…person}})` · `boat(g,x,y,{kind:'motor'|'row'|'sail',col,stripe,riders:[{…},{…}],wake,t})`.
- **Животные** `dog(g,x,y,{col,pose:'stand'|'walk'|'sit'|'sleep',collar,t})` · `cat(…)` · `bird(g,x,y,{col,t})` · `birds(g,t,{x,y,n,rx,ry})` стая кружит.
- **Улица** `lamp(g,x,y,{h,on})` · `garland(g,x0,y0,x1,y1,{n,sag,cols,on 0..1,t})` фонарики · `bench(g,x,y,{w})`→`{seat}` · `board(g,x,y,{w,h,title,lines:['…'|['слева','справа']],p 0..1 пишется,stand,plate,size})` доска мелом или вывеска (x,y левый верх).
- Своё: `grid(w,h)` + `sprite(key,cell,roles,build)` + `put(...)` в том же языке точек.

## Смысл важнее украшений (обязательно)
- **Что названо, то нарисовано** объектами выше в `figPanel` или на весь кадр: люди, животные, транспорт, дома, природа, товары. Не заменяй предмет строкой лога, карточкой, словом или LED-числом; число рядом с картинкой можно.
- **Люди есть, если о них речь**: рыбаки, продавцы, дети, рабочие, бабушка, толпа. Сколько названо, столько и рисуй; действие позой (идёт, машет, сидит, держит, танцует).
- **Событие в момент слова**: объект появляется (`p`) на своём слове и держится, пока о нём говорят; что «проезжает» - проезжает в эту фразу; заголовок не отстаёт от голоса больше чем на 0.5 с.
- **Надписи только по теме**: числа и слова из озвучки, по-русски, без выдуманных фактов, дат, счётчиков, путей файлов и английских слов. Росток, «95% АВТО / 5% ВЫ», «агент.полив», «человек.урожай», «[ подключить ]», серия «НЕТ …» относятся к теме примера и не переносятся. Сквозной герой не обязателен: если нужен, бери его из темы (человек, животное, предмет из озвучки).
- Объекты целиком в кадре и в панели, не налезают на текст; люди ≥ 120 px.

## Движение и переходы
- Камера после склейки наезд 1.04 -> 1.0, дальше дрейф. Текст печатается, интерфейс на пружине. Сцены 2.5-5 с, удары 0.6 с. Фоновое движение всегда: мерцание, волны, птицы, ленты.
- `frame(k,t,CUTS,SCENES,{tr})`: `glitch` (основной, 0.13 с до и 0.17 после), `grey`, `flash`, `cut`. Глитч только на склейках.

## Звук
Сухие клики: `type`/`tick`/`key_soft` под печать, `cutSounds` на склейках, `woodblock`/`rim` на ударах, `sparkle` на рассыпании, `counter` на счётчиках, `pop_soft` на появлении объекта, `magic` -> `success` в финале. Громкость 0.08-0.16.

## Запреты
- Без длинного тире, эмодзи, чужих марок. Градиенты только виньетка и свечения. Текст не жирнее 500, капс только моно и LED.

## Каркас
```js
const S = SLAM, C = S.C;
const CUTS = [3.0, 7.5];                       // склейки на ключевых словах
const TRS = ['glitch', 'flash'];
S.setHud({ tl: 'ТЕМА', bl2: ['ФАКТ:', 'ИЗ ОЗВУЧКИ'] });
function A(g, lt, sc, t) {
  S.section(g, '01', 'РАЗДЕЛ', 60, 205, lt, 0.05);
  S.typeLines(g, 'Заголовок|в две строки', 60, 235, lt, 0.1, { size: 120, hi: 'строки', cps: 50 });
  S.figPanel(g, 60, 700, 960, 900, { tl: 'МЕСТО' }, S.eo(lt / 0.3));
  S.sea(g, 60, 1300, 960, 300, t, {});
  S.person(g, 400, 1300, { pose: 'wave', t, shirt: 'orange', p: S.prog(lt, 0.8, 1.2) });
}
const SCENES = [{ bg: 'dark', fig: 'СЦЕНА 1', draw: A } /* ... */];
function draw(t, k) { S.frame(k, t, CUTS, SCENES, { tr: TRS }); }
function sound(s) { S.cutSounds(s, CUTS, TRS); s.play(0.2, 'type', 0.09); }
```
