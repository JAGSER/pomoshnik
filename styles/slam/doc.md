# SLAM - агрессивная моушн-графика

## Правила стиля
1. **Палитра.** Фон #0A0A0B: сетка 60 px, крестики каждые 240, зерно, сканлинии, виньетка (всё в `SLAM.bg`). Текст #F4F1EA. Акцент только лайм #C8FF2E: одно ключевое слово, заливки прогресса, курсор, галочки, деталь предмета. Вторичный #5E5E5E: мелкий моно. #FF2E4D/#2EE6FF только для RGB-расслоения в момент удара. Других цветов и градиентов нет.
2. **Линии.** Тонкие белые 3-8 px, рамки rgba(255,255,255,.2), скругление 18 px, прямые углы. Предметы: line-art белым по чёрному с одной лаймовой деталью.
3. **Текст.** Заголовки КАПСОМ, гротеск 900, 100-250 px; каждое слово влетает «слэмом» (масштаб 1.35→1 за 0.22 с, без перелёта) с глитчем. Мелкие подписи моно 28-44 px, печатаются посимвольно (`> команда`). Числа огромные 300-400 px. Без «—».
4. **Композиция.** Одна сцена = один гигантский блок (слово или число) + 1-2 спутника (шкала, плашки, подпись). Всё по сетке, поля x 90…990, рельсы и узлы в левой колонке x≈140.
5. **Сквозной герой.** Лаймовый блок-курсор с ореолом (`cursor`): стоит после последнего слова, едет по рельсу, по шкале, ведёт подпись. Можно добавить робота-агента `bot` или свой предмет темы.
6. **Движение.** Удар камеры (`hits`) на каждом слэме, наезд с оседанием после склейки, дрейф сетки, бегущая полоса скана. Интерфейс на пружине `spring` (лёгкий перелёт), текст `eo`.
7. **Переходы.** За 0.18 с до склейки сцена ускоренно наезжает и гаснет, сверху вниз пролетает наклонная лайм-чёрная полосатая лента, белая вспышка 0.1 с, сильная тряска. Всё делает `SLAM.frame`.
8. **Прогресс.** Счётчик + сегментная шкала, галочки на плашках, штамп под наклоном в финале.
9. **Звук.** Сухие удары `rim`/`woodblock` на слэмах (pitch 0.6-1.0), `marimba_run`/`kalimba_run` на склейках, `toggle_on` на включении плашек (pitch растёт 0.9→1.25), `counter`/`odometer` на счётчике, `type` на моно, `success`/`sparkle`/`ta_da` на итогах, `drop` под штамп.
