# Стиль «Пиксельный офис» (AGOF)

`AGOF` уже подключена, саму библиотеку заново не объявляй (свои функции для новых предметов писать можно и нужно). Тёплый игровой промо-ролик: кремовый фон, чёрный жирный заголовок по центру с жёлтым маркером под ключом, пиксельные аватары-помощники, белые карточки, тёмный терминал, пиксельный офис со столами, орбита подключений, жёлтая кнопка с курсором.

## Правила
1. Палитра только `AGOF.C`: крем `cream` #FBF3DC (основной фон), песок `sand`, жёлтый `yellow` #FFD84D (маркер, рамки аватаров, финальный фон), чернила `ink`, оранжевый `orange`, белый `white`, линии `line`, серый текст `muted`. Цвета рубашек аватаров берутся сами.
2. Заголовок только `head`: по центру, y ≈ 300, 80–92 px, 900, `*ключ*` на жёлтом маркере. 2–5 слов, без длинного тире.
3. Герои: пиксельные аватары `ava(g, x, y, размер, j, t)`, j 0..5 даёт разных людей. Главный герой один и тот же во всех сценах (одно j).
4. Образы: `terminal` (как было скучно), `bars` (рост показателей), `skill` (карточки умений вокруг аватара), `office` (живой офис с бегающими задачами), `orbit` (подключения), `type` (название печатается), `cta` + `cursor` в финале.
5. Предпоследняя сцена может быть на жёлтом фоне с одной фразой крупно и покачиванием.
6. Ритм: сцена около 3 с, уход `out` за 0.25 с, камера `cam(g, lt, 540, 1000, 0.5)`.
7. Звуки: `key_soft`/`type` на терминал и печать, `pop_double` на знакомство, `pop_high` на карточки, `kalimba_run` на офис, `bubble` на орбиту, `ta_da` и `click` на финал. Склейки `cutSounds(s, CUTS, 'marimba_run', 0.12)`.

## Каркас
```js
const A = AGOF, C = A.C;
const CUTS = [0, 3, 6, 9];
function draw(t, k) {
  const g = k.g, { i, lt, dur } = A.scene(t, CUTS), last = i === CUTS.length - 1;
  g.fillStyle = C.cream; g.fillRect(0, 0, 1080, 1920);
  g.save(); A.cam(g, lt, 540, 1000, 0.5); g.globalAlpha = A.out(lt, dur, last);
  if (i === 0) { A.head(g, 'Заказы приходят *ночью*', t, 0.1); A.terminal(g, ['23:14 новый заказ'], 80, 700, 920, 560, t, 0.6); }
  // ...
  g.restore();
}
function sound(s) { A.cutSounds(s, CUTS, 'marimba_run', 0.12); }
```

## API
- `scene(t, cuts)` → `{i, lt, dur}`; `out(lt, dur, last)`; `cam(g, lt, cx, cy, k)`.
- `head(g, s, t, t0, {y, size})` → y под заголовком. `words(...)` для подзаголовков (`keyBg: C.yellow`).
- `ava(g, x, y, s, j, t)` пиксельный аватар (s 60–220).
- `card(g, x, y, w, h, r)`; `skill(g, подпись, x, y, j, p)` карточка 260×140.
- `bars(g, [[подпись, 0..1, цвет]], x, y, w, t, t0)` карточка с полосами.
- `terminal(g, строки, x, y, w, h, t, t0)` тёмное окно, строки по очереди.
- `type(g, s, x, y, size, t, t0, d, {color, align})` печать по буквам.
- `office(g, x, y, w, h, t, lt, 'задача')` офис 3×4 стола, 6 аватаров.
- `orbit(g, подписи, cx, cy, r, lt)` карточки на лучах вокруг центра (в центр поставь аватар).
- `cta(g, s, y, t, t0)` жёлтая кнопка; `cursor(g, x, y, press, s)`.
- Утилиты: `cl, eo, eio, sp, mix, font, rr, count, layout`.

## Рецепт
Хук: заголовок о проблеме и скучный терминал. Знакомство: аватар + название печатается. Затем по сцене: умения, офис, подключения. Яркая сцена на жёлтом. Финал: аватар, название, подзаголовок с маркером, кнопка и курсор нажимает.

## Типовые ошибки
- Маркер под всей фразой: в `*…*` только 1–3 слова.
- Название рядом с аватаром не помещается: аватар левее (x ≈ 250–300), текст 100–120 px.
- Карточки орбиты налезают на заголовок: центр орбиты y ≥ 1050, r ≤ 340.
