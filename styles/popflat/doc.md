# Стиль POPS: поп-моушн с героем

## Правила стиля
1. Палитра: фон #F6F1E9 / #15132B / #3A5BFF, чернила #15132B, акценты #FF5A36, #FFC83D, #1FA463. Шкала: #E63946, #FF9F1C, #1FA463. Только плоские заливки, без градиентов. Темы чередуются по сценам `theme(i)`: light, night, fresh, blue. Финал `theme('light')` или `theme('coral')`.
2. Фон: `bg()`, точечная сетка 40 px медленно дрейфует. Всегда.
3. Сквозной герой по центру низа (y 1080…1200): устройство `device()` или свой предмет того же языка: скруглённые формы, тёмный корпус #0E0D1F, светлая рамка 4 px. На каждой склейке он пружиной меняет позу (сдвиг, масштаб, наклон ±0.1). Позади `halo` цвета акцента и 4 фигуры `orbiters`.
4. Текст: гротеск 800, заголовок 120…150 px на y≈330, подпись 58…62 px (600) на y≈450…470. Слова по одному снизу (`words`), ключевое слово цветом акцента с полупрозрачной полосой-маркером. Максимум заголовок + подпись + 1 элемент с текстом. Без «—».
5. Линии: толстые 5…8 px, скруглённые концы. Карточки белые, r 34, жёсткая тень (+10,+14, 15 % чёрного), без размытия.
6. Движение: интерфейс на `spring` с перелётом, текст ease-out без перелёта. Фон и орбиты дышат всегда, герой покачивается.
7. Склейка: за 0.3 с круговая шторка цвета следующей темы из центра героя (`circleWipe`), на склейке белая вспышка экрана героя (`flashK`), камера с затуханием «оседает».
8. Каждая сцена: одна мысль и один «трюк» на экране героя (пузыри чата, видоискатель, шкала со счётчиком, путь точки, знак) плюс снаружи карточки, точки-светофор или штамп.
9. Звуки: wood/pop_soft/bubble на появлениях, marimba_run/kalimba_run на склейках, counter+tick на счётчике, drop на штамп, type на набор, success3 в финале.
