# Стиль «Отчёт-инфографика» (INFO)

`INFO` уже подключена, саму библиотеку заново не объявляй (свои функции для новых предметов писать можно и нужно). Корпоративный ролик-отчёт: тёмно-синий фон со свечением, янтарный шар-символ, моно-ярлыки разделов, таймлайн лет, цепочка шагов в кружках, жёлтая шторка с крупными цифрами, столбики с пунктиром тренда, сетка точек-целей, финал с кольцом.

## Правила
1. Палитра только `INFO.C`: фон `bg` #0D1424, янтарь `amber`/`amber2`/`deep` (символ, ключ, последний год, последний столбик), текст `text`, серый `muted`, линии `line`, жёлтый `yellow` (только сцена итогов), тёмный `ink` (текст на жёлтом).
2. Фон каждой сцены `bg(g, 'НАЗВАНИЕ · ОТЧЁТ ГОД', 'подпись')`. Одна сцена итогов на жёлтом: `wipe(g, eio(lt / 0.5))`, затем в следующей `wipe(g, 1)` и цифры `stats`.
3. Каждая сцена начинается с `label` (моно-ярлык, y 360) и заголовка `title` 58–64 px, `*ключ*` янтарём. Без длинного тире.
4. Один образ на сцену: `timeline` (история по годам), `chain` (как это работает, 3–4 шага), `stats` (3 цифры с единицами), `bars` (4 столбика, последний янтарный), `dots` (план: n из total).
5. Цифры всегда растут от нуля, числа с запятой (`1,2`). Деньги в рублях.
6. Ритм ровный, 2–3 с на сцену, камера `cam(g, lt, 540, 960, 0.3)`.
7. Финал `finale(g, НАЗВАНИЕ, подзаголовок, t, lt)`.
8. Звуки: `tick` на годы, `pop_soft` на шаги, `bubble_down` на шторку, `counter` на цифры, `marimba` на столбики, `tally` на точки, `success3` на финал. Склейки `cutSounds(s, CUTS, 'wood', 0.07)`.

## Каркас
```js
const I = INFO, C = I.C;
const CUTS = [0, 1.8, 4.4, 7.2, 7.8];
function draw(t, k) {
  const g = k.g, { i, lt } = I.scene(t, CUTS);
  I.bg(g, 'КОМПАНИЯ · ОТЧЁТ 2026', 'ДЕВИЗ'); if (i === 3) I.wipe(g, I.eio(lt / 0.5)); if (i === 4) I.wipe(g, 1);
  g.save(); I.cam(g, lt, 540, 960, 0.3);
  if (i === 1) { I.label(g, 'ИСТОРИЯ', 360, t, CUTS[1]); I.timeline(g, [['2018', 'старт'], ['2026', 'сейчас']], t, CUTS[1] + 0.1); }
  if (i === 4) { I.label(g, 'ИТОГИ', 400, t, CUTS[4], true); I.stats(g, [['Клиентов', 12, 'тыс.'], ['Мощность', 1.2, 'ГВт', 1]], t, CUTS[4] + 0.2); }
  // ...
  g.restore();
}
function sound(s) { I.cutSounds(s, CUTS, 'wood', 0.07); }
```

## API
- `scene(t, cuts)` → `{i, lt, dur}`; `cam(g, lt, cx, cy, k)`; `bg(g, левая подпись, правая)`; `wipe(g, p)`.
- `orb(g, x, y, r, t)` шар-символ; `label(g, s, y, t, t0, dark)`; `title(g, s, y, t, t0, {size, dark})` → y под заголовком.
- `timeline(g, [[год, подпись] ×3–4], t, t0, {y, gap, d})`.
- `chain(g, [[символ, подпись] ×3–4], t, t0, {y, gap})`.
- `stats(g, [[подпись, число, единица, знаков после запятой] ×3], t, t0, {y, gap})` на жёлтом.
- `bars(g, [[подпись, число] ×4], t, t0, {base, k, gap, x})`: k пикселей на единицу, следи, чтобы верх не налез на заголовок.
- `dots(g, total, n, {cols, x, y, dx, dy})`; `finale(g, имя, подзаголовок, t, lt)`.
- Утилиты: `cl, eo, eio, sp, mix, font, rr, words, count`.

## Рецепт
Шар + название (1.8 с) → история таймлайном → как это работает цепочкой → жёлтая шторка с тремя цифрами → столбики выручки → план точками → финал с кольцом.

## Типовые ошибки
- Высокий последний столбик налезает на заголовок: уменьши `k`.
- Единица налезает на число: используй `stats`, она ставит единицу после числа сама.
- Белый текст на жёлтой сцене: там только `C.ink` и `dark: true`.
