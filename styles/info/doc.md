# Стиль «Отчёт-инфографика» (INFO)

`INFO` уже подключена, саму библиотеку заново не объявляй (свои функции для новых предметов писать можно). Язык стиля: тёмно-синий фон со свечением, янтарные акценты, моно-ярлыки разделов, крупные цифры, плоские пиктограммы-силуэты (здания тёмными панелями с янтарной обводкой, свет мягким свечением). Инструменты отчёта (таймлайн, цепочка, цифры на жёлтом, столбики, точки) плюс типовые объекты реального мира.

## Правила
1. Основа палитры `INFO.C`: фон `bg` #0D1424, янтарь `amber`/`amber2`/`deep`, текст `text`, серый `muted`, линии `line`, панель `panel`, жёлтый `yellow`, тёмный `ink` (текст на жёлтом). Цвет, названный в озвучке (розовое солнце, синий автобус, рыжий пёс, оранжевые куртки), соблюдай буквально параметром `col`/`shirt`.
2. Каждая сцена: `bg(g)` (подпись подвала `bg(g, слева, справа)` только если она по теме), `label` (моно-ярлык, y 360) и заголовок `title` 58–64 px, `*ключ*` янтарём. Без длинного тире.
3. Картинка = то, о чём говорят. Люди, животные, предметы из текста рисуются типовыми объектами (ниже), а не строкой, значком в кружке или точкой. «Семь лодок» = семь лодок, «рабочие машут» = люди с `pose: 'wave'`. Подпись к предмету только короткой выноской `tag`.
4. Инструменты отчёта по смыслу: `timeline` (годы), `chain` (шаги процесса), `stats` на жёлтой шторке (несколько чисел подряд), `bars` (сравнение чисел), `dots` (n из total). Шар `orb`, шторка, подвал, финал с шаром не обязательны, только если подходят теме.
5. Синхрон: предмет или событие появляется в момент своего слова (по таймингу фразы, внутри длинной фразы ставь свою метку), а не раньше и не в конце сцены. Число доезжает до названного значения к моменту слова (длительность счёта 0.6–0.8 с). Гаснет, зажигается, едет именно на словах «гаснет», «зажигаются», «проезжает».
6. Надписи только по теме ролика, по-русски, с правильным падежом («5 этажей», «7 лодок»). Деньги в рублях `₽`, дробные числа с запятой.
7. Сцена = фраза или её часть; камера `cam(g, lt, 540, 960, 0.3)`. Нижняя половина кадра не пустая: картинка до y 1550.
8. Финал: `finale(g, название, подзаголовок, t, lt, {orb: false, y})` поверх своей картинки (например, ночной город) или с шаром, если тема про бренд.
9. Звуки: `tick` годы, `pop_soft` шаги и появление предметов, `bubble_down` шторка, `counter` цифры, `marimba` столбики, `tally` точки, `success3` финал. Склейки `cutSounds(s, CUTS, 'wood', 0.07)`.

## Каркас
```js
const I = INFO, C = I.C;
const CUTS = [0, 1.8, 4.4];
function draw(t, k) {
  const g = k.g, { i, lt } = I.scene(t, CUTS);
  I.bg(g); g.save(); I.cam(g, lt, 540, 960, 0.3);
  if (i === 1) { I.label(g, 'УТРО', 360, t, CUTS[1]); I.title(g, 'Рыбаки *уходят в море*', 420, t, CUTS[1] + 0.1); I.sea(g, t, 0, 1200, 1080, 1600); I.boat(g, 300 + 200 * I.eio(lt / 3), 1240, 320, { motor: true, run: 1, t }); }
  g.restore();
}
function sound(s) { I.cutSounds(s, CUTS, 'wood', 0.07); }
```

## API отчёта
- `scene(t, cuts)` → `{i, lt, dur}`; `cam(g, lt, cx, cy, k)`; `bg(g, левая?, правая?)`; `wipe(g, p)` жёлтая шторка.
- `orb(g, x, y, r, t)`; `label(g, s, y, t, t0, dark)`; `title(g, s, y, t, t0, {size, dark})` → y под заголовком.
- `timeline(g, [[год, подпись] ×3–4], t, t0, {y, gap, d})`; `chain(g, [[символ, подпись] ×3–4], t, t0, {y, gap})`.
- `stats(g, [[подпись, число, единица, знаков] ×1–4], t, t0, {y, gap})` на жёлтом; чтобы число появилось к слову, вызывай с t0 своего слова для каждой строки отдельно.
- `bars(g, [[подпись, число] ×2–4], t, t0, {base, k, gap, x, dec})`: k пикселей на единицу, верх не выше заголовка.
- `dots(g, total, n, {cols, x, y, dx, dy})`; `finale(g, имя, подзаголовок, t, lt, {orb, y})`.
- Утилиты: `cl, eo, eio, sp, mix, font, rr, words, count`.

## Типовые объекты
x центр, y земля (у лодки ватерлиния); цвет каждой части параметр (#RRGGBB); `t` оживляет; `dir` ±1 разворот.
- Люди: `person(g, x, y, {h: 300, age: 'adult'|'kid'|'old', pose, t, dir, skin, hair, hs: 'short'|'long'|'bun'|'bald', shirt, pants, dress, apron, scarf, helmet, cap, bag, glasses, book, seat, sleep, mouth: 'open', hands})` → `{hand, hand2, head, top}`; pose: stand walk run wave hold point shout sit read dance. Предмет в руку по `hand`. `crowd(g, x0, x1, y, n, {h, pose, t, kids, old, shirts, seed, opts: (i) => ({…})})` разные люди рядом. Палитры `SKIN HAIR SHIRTS`.
- Здания (тёмная панель с обводкой `edge`, `edge: false` без неё): `house(g, x, y, w, h, {wall, roof, door, lit, night})` · `tower(g, x, y, cols, rows, {wall, roof, lit: 0..1 гаснут по одному, grow: 0..1 стройка по этажам, night, cw, ch})` → {x0, top, w, h} · `shop(g, x, y, w, h, {kind: 'shop'|'cafe', sign, awning, awning2, lit})` · `school(g, x, y, w, h, {sign: 'Школа'|'Библиотека', flag, hm: [8, 0], lit})` · `winR(g, x, y, w, h, lit)`.
- Растения: `tree(g, x, y, s, {kind: 'leaf'|'oak'|'pine', col, trunk, t})` · `grass(g, x0, x1, y, {col, h, t})` · `leaf(g, x, y, s, {col, rot})` · `leaves(g, t, x0, x1, y0, y1, {n, cols})` падают.
- Транспорт: `car(g, x, y, s, {col, t})` · `bus(g, x, y, s, {col, num: '№3', people, t})` · `bike(g, x, y, s, {col, rider: {shirt, helmet, …}|false, t})` · `boat(g, x, y, s, {col, stripe, cabin|false, motor, run: 0..1, t})` → {deck}.
- Животные: `dog(g, x, y, s, {col, pose: 'stand'|'run'|'sit'|'sleep', collar, t})` · `cat(g, x, y, s, {col, pose: 'sit'|'walk'|'sleep'})` · `bird(g, x, y, s, {col, fly, t})` · `flock(g, t, cx, cy, n, {r, s})` стая кружит.
- Небо и природа: `sky(g, x, y, w, h, {tone: 'dawn'|'morning'|'day'|'evening'|'night'|col})` · `sun(g, x, y, r, {col, rays, glow, t})` · `moon(g, x, y, r)` · `stars(g, t, x, y, w, h, {n, alpha})` · `cloud(g, x, y, s, {col})` · `sea(g, t, x0, y, x1, y1, {col, amp})` · `hill(g, x, y, w, h, {col})`.
- Улица: `lamp(g, x, y, h, {on: 0..1, light})` · `garland(g, x0, y0, x1, y1, {n, on: 0..1 по очереди, sag, cols})` · `board(g, x, y, w, h, ['Уха 350 ₽', 'Кофе 120 ₽'], {kind: 'chalk'|'white'|'wood', legs, n})` (x, y центр; n сколько строк видно).
- Оформление: `frame(g, x, y, w, h, (g, b) => {…}, {sky, bg, edge, p})` картинка в панели-рамке; `tag(g, x, y, 'подпись', {dx, dy, p})` выноска к предмету; `glow(g, x, y, r, col, a)` свечение.
- Примитивы для своих предметов: `rr gsh seg disc ell poly cmix dark light Tr`.

## Типовые ошибки
- Строка текста или значок вместо людей и предметов: рисуй объект.
- Цвет из палитры вместо названного (янтарное солнце вместо розового).
- Счётчик не дошёл до числа к слову, «1 лодок»: начинай счёт на слове, падеж по числу.
- Высокий столбик налезает на заголовок: уменьши `k`. Белый текст на жёлтой шторке: там только `C.ink` и `dark: true`.
