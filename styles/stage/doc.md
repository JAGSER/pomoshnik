# Стиль «Демо интерфейса» (STAGE): ролик-инструкция, где в правдоподобном приложении происходит одно действие

По мотивам скилла stageshow. Глобальная `STAGE` уже подключена: `const S = STAGE;`. Своё `STAGE` не объявляй, `k.text/k.card/k.emoji/k.mascot` не используй, всё рисуй через `S` и обычный canvas.

## Одна идея
Кадр выглядит как настоящий продукт, упрощённый до того, что нужно зрителю, снятый с намерением, и у каждого движения есть причина. Зритель узнаёт экран и видит, как в нём что-то происходит: нажали, напечатали, сумма подставилась, кнопка стала «Оплачено».

Пять провалов, которых не должно быть:
- **Слишком много**: настоящие слова в каждой строке, цифры везде. Чем больше деталей, тем сильнее «сгенерировано».
- **Каркас**: два серых прямоугольника и кнопка. Экран должен быть полным и узнаваемым.
- **В коробке**: окно или телефон целиком посередине с ровными полями. Устройство занимает ≥ 2/3 кадра и уходит за край (обычно за низ).
- **Плоско**: всё одного веса, глазу некуда сесть. Один главный объект, остальное тише.
- **Пресно**: серый экран с курсором вне зависимости от темы. Бери образ темы (банк, аптека, госуслуги, чат, календарь) и строй его по этим правилам.

## Правила
1. **Раскладка 1080×1920**: сверху заголовок `S.head` (y 150…520, 2 строки, 96–110 px, слова в такт голосу, ключ `*акцентом`). Ниже устройство: `S.phone` (x 110, y 600…660, w 860, h 1600, уходит за низ) или `S.win` (окно шире кадра, x 40…60, уходит за правый или нижний край). Подложка — `S.ground` (тихое поле), не плашка под окном.
2. **Бюджет слов**: настоящих строк на экране 3–7, только там, о чём рассказ (выбранный пункт, сумма, кнопка, поле). Всё остальное — заглушки `S.bar`, `S.lines`, `row` без title. Серые заглушки по краям, не там, куда смотрит глаз.
3. **История 3–5 шагов и итог**, по фразам озвучки: найти → открыть → ввести → подтвердить → результат. Палец/курсор движется только к тому, что сейчас нажмут; без лишних кругов. Итог держится до конца (кнопка «Оплачено», тост, галочка), не исчезает.
4. **Содержимое двигается, а не подменяется**: число набегает (`S.amount` с `at`), текст печатается (`S.field` с `t0`), кнопка меняется сама (`done`, `doneLabel`), новый экран въезжает (`in:'push'`), строка выделяется перед переходом. Данные не откатываются без причины.
5. **Камера** `S.camera` наезжает на место действия (зум 1.06–1.2) и возвращается к общему плану на итоге. Без тряски и резких рывков.
6. **Цвет**: светлая тема по умолчанию, один акцент (синий `P.accent` или цвет темы через `S.begin(t,k,{accent:'#…'})`), успех зелёным `P.ok`. Без фиолетового «ИИ», без искр и блёсток, без выдуманных логотипов и «буквы в цветном квадрате». Иконки — линейные из `S.ICONS`.
7. **Устройство не рисуй руками**: статус-бар, островок, полоска «домой», светофор окна рисуют `S.phone`/`S.win`. Не вписывай телефон целиком с воздухом вокруг.
8. **Аккуратность**: единица рядом с числом и мельче (`amount` с `unit`), текст не касается краёв карточек, отступы внутри одинаковые (36–60 px), подписи ≥ 27 px, основной текст на экране 34–42 px. Без длинного тире.
9. **Кадр-постер**: момент итога (кнопка «Оплачено» + тост) должен сам рассказывать историю — его чаще всего видят на превью.

## Каркас
```js
const S = STAGE;
const HEADS = [[0, 'Оплатить *квартиру|за минуту'], [6.6, 'Откройте|*Платежи']];   // [t, текст] по фразам
const PATH = [[2.6, 820, 1560], [5.4, 300, 1240, .9]];                         // [t прихода, x, y, длительность хода]
const TAPS = [5.6];                                                            // моменты нажатий
const CAM = [[0, 540, 1150, 1], [10.8, 540, 1240, 1.12, 1.1]];                 // [t, cx, cy, zoom, dur]
const SC = [
  { t0: 0, draw: (g, t, lt, scr) => { /* экран 1 внутри телефона: S.amount, S.tile, S.row… */ } },
  { t0: 6.6, in: 'push', draw: (g, t, lt, scr) => { let y = S.navbar(g, scr, 'Платежи', { back: true }); /* … */ } },
];
function draw(t, k) {
  const g = S.begin(t, k); S.ground(g);
  let hi = 0; while (hi < HEADS.length - 1 && t >= HEADS[hi + 1][0]) hi++;
  S.head(g, t, { s: HEADS[hi][1], t0: HEADS[hi][0] + .05, t1: HEADS[hi + 1] ? HEADS[hi + 1][0] - .25 : null, y: 260, size: 104 });
  g.save(); S.camera(g, t, CAM); g.translate(0, (1 - S.spring(t, .1, .9)) * 500);
  S.phone(g, { x: 110, y: 640, w: 860, h: 1600, content: (g, scr) => S.run(g, t, SC.map(s => ({ t0: s.t0, in: s.in,
    draw: (g, tt, lt) => { S.fill(g, scr.x, scr.y, scr.w, scr.h, 0, S.P.sunk); s.draw(g, tt, lt, scr); } })), { pushW: scr.w }) });
  S.toast(g, t, { x: 540, y: 760, s: 'Платёж прошёл', sub: '4 860 ₽ · ЖКХ', t0: 16.6 });
  S.pointer(g, t, { path: PATH, taps: TAPS, t1: 18.2 });       // палец; kind:'cursor' — стрелка мыши для окна
  g.restore(); S.finish(g);
}
function sound(s) { s.play(5.6, 'click', .14); s.play(6.6, 'marimba_run', .1); }
```
Полный пример ниже показывает, как этим пользоваться. Для компьютерных тем бери `S.win({x:40,y:640,w:1160,h:1500,url:'site.ru',side:true,content})` и `kind:'cursor'`.

## API
**Время**: `cl` · `pr(t,a,b)` · `lerp` · `eo`/`eo5`/`eio` · `sp` · `spring(t,t0,dur)` · `ap(t,t0,dur)` появление 0…1 · `vis(t,t0,t1)` появление и уход · `stag(t,t0,i,step)` каскад · `kf(keys,t)` · `step(keys,t,d)` держит и переходит · `count(t,t0,dur,a,b)` · `typed(s,t,t0,cps)` · `hash(n)` · `fmt(v,dec)` → «4 860».
**Цвет**: `S.P` текущая тема: `ground surface sunk line bar bar2 ink ink2 mute faint accent accentP ok okP warn bad chrome`. Тема и акцент: `S.begin(t,k,{theme:'dark',accent:'#E11D48'})`. `S.mix(a,b,p)`.
**Рисование**: `fill(g,x,y,w,h,r,col)` · `stroke(g,x,y,w,h,r,col,lw)` · `shadow(g,x,y,w,h,r,k)` · `text(g,s,x,y,{size,weight,col,al,max,a,mono,base})` одна строка, `max` ужимает кегль · `bar(g,x,y,w,h)` заглушка · `lines(g,x,y,w,n,{gap})` абзац-заглушка · `icon(g,name,cx,cy,s,col,lw)` · `tile(g,name,cx,cy,s,col,bg)` · `avatar(g,cx,cy,r,'АБ',col)`.
**Рамки**: `phone(g,{x,y,w,h,time,screen,darkStatus,content(g,scr)})` → scr `{x,y,w,h,top,bot}` (контент начинай от `scr.top`) · `win(g,{x,y,w,h,title|url,side,sideW,content(g,body)})` → body `{x,y,w,h,side}` · `card(g,x,y,w,h,{r,col,lift})` · `navbar(g,scr,'Заголовок',{back})` → y под шапкой.
**Части**: `row(g,{x,y,w,h,icon|avatar,title,sub,subBar,bw,val,vcol,chev,toggle,sel,a,dy,div})` строка списка (без title — заглушка) · `button(g,{x,y,w,h,label,icon,primary,press,done,doneLabel})` · `toggle(g,x,y,on)` · `field(g,{x,y,w,h,label,value,t0,cps,focus,unit,ph},t)` поле, печатает · `chip(g,x,y,s,{icon,bg,col,al})` · `badge(g,cx,cy,n)` · `amount(g,t,{v,from,at,dur,x,y,size,unit,al,col})` число набегает, y — базовая линия · `toast(g,t,{x,y,w,s,sub,icon,t0,t1})` · `bubble(g,t,{x,y,s,me,t0,maxW})` сообщение чата → высота · `note(g,t,{x,y,tx,ty,s,t0})` выноска к месту.
**Жест и камера**: `pointer(g,t,{path:[[t,x,y,dur]],taps:[t],kind:'finger'|'cursor',t0,t1})` → {x,y,press}; координаты в системе кадра (как устройство) · `camera(g,t,[[t,cx,cy,zoom,dur]])` · `run(g,t,SC,{pushW})` сцены с переходом `in:'push'|'fade'|'cut'` · `head(g,t,{s,t0,t1,y,size,al,keyCol})` заголовок по словам (`слово@1.2` — своё время) · `ground(g)` · `fade(g,x,y,w,h,'bottom'|'right')` затухание к краю.
**Иконки**: home search bell user card wallet house bolt drop flame phone wifi check plus chev back send clock gear chat mic cal doc lock heart cart star bus pill camera arrow x more list.

## Рецепт сильного ролика
1. 0–1 с: заголовок-обещание + телефон въезжает снизу пружиной.
2. Каждые 3–5 с новый шаг: палец идёт к цели → нажатие (круги) → строка выделяется → экран въезжает.
3. Ввод печатается, сумма набегает, рядом выноска «по квитанции» к важному.
4. На подтверждении камера наезжает, кнопка меняется на «готово», сверху тост.
5. Последние 2 с — итог держится, камера возвращается, заголовок «Готово».

## Звук
Тихий интерфейс: `click` (нажатие), `marimba_run` (новый экран), `type` (печать), `counter` (набег суммы), `pop_high` (выноска), `success3` (готово), `notify` (тост). Громкость 0.08–0.16.

Нельзя: `document`, `Math.random`, `Date`, `ctx.filter`, `shadowBlur`, `letterSpacing`, полупрозрачные заливки во весь кадр.
