# MORF: одна фигура морфится в интерфейс под 120 BPM

## Правила стиля
1. Палитра: фон `#E7E3DC` с сеткой точек, фигура и UI только `#121212` / `#FFFFFF`, серые `#8A857D` `#DCD8D1` `#E6E2DB`. Один акцент `#FF5B1F`, только ключевое слово заголовка. Без градиентов, свечений, частиц.
2. Один герой без склеек: скруглённый прямоугольник, у которого пружинят w, h, радиус, цвет (0 чёрный…1 белый) и зум. Сцена = состояние фигуры, смена содержимого с коротким «блюром» (hero делает сам). Последнее состояние = первое.
3. Ритм 120 BPM, доля 0,5 с. Все события на долях (t кратно 0.5). Крупное состояние живёт 3-5 с (6-10 долей), внутри каждую долю мелкое событие: клик, тик, переключение, буква.
4. Курсор ведёт каждое изменение: подлетает, кликает (press) ровно в момент смены, тянет ползунок. Клик = морф = звук в одну долю.
5. Текст: над фигурой (y≈540) заголовок 1-3 слова, 112 px, жирность 750, по словам, `*ключевое*` акцентом. Внутри UI гротеск 38-48 px, числа и время моно. Максимум 2-3 текстовых блока.
6. Линии: иконки штрихом 4-6 px, круглые концы, одна толщина в кадре. Иконки рисуй сам, без эмодзи и чужих логотипов.
7. Движение: пружины `sp`/`trk`, у UI крошечный перелёт, у текста нет. Камера: `cam` в состояниях (мелкое крупно 1.6-2.2, большие панели ≈1.1) + дрейф фона. Тень только у фигуры.
8. Предметы темы = UI-состояния: кнопка с глаголом, статистика, график, список, ⌘K с командами темы, тост с итогом.
