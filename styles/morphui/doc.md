# MORF: продуктовый промо, один элемент интерфейса морфится в следующий

## Палитра (пипеткой по оригиналу)
- Фон светлой части `#F4F5F8`, карточки `#FFFFFF`, обводка карточки чёрная 3,5 %. Тень очень широкая и мягкая: размытие 70, сдвиг вниз 26, альфа 0,15 (`M.shadow`, спрайт, рисует `hero`).
- Тёмная часть: фон `#0A0A0A`, карточки `#121212`, линии `#1F1F22`, текст `#F1F1F2`, вторичный `#8C8C92`. Переключение на всю сцену за 0,35 с (`begin(k, t, [[t, 0|1], ...])`), лучше всего по клику «Тёмная».
- Текст: основной `#0E0F12`, вторичный `#6B7079`, третичный `#A3A8B1`, подсветка строки `#F1F2F5`.
- Акценты, каждый строго по смыслу: кнопка отправки `#1C3460` (navy), «в работе» `#4EA8D2` (голубой, спиннер), «готово» `#0A8459` + фон `#E2F7EC`, тумблеры и выбор `#147870` (teal), удалено `#C8324A` + `#FDE9EC`, график `#D0695C` (лосось, заливка градиентом), бейдж события `#7B3FE4` на `#F0E8FE`, звезда `#F2A93B`, мелкий синий `#2F6FD8` (бейдж «НОВОЕ»).
- Никаких градиентов фона, свечений, зерна, виньетки. Плоско и чисто.

## Шрифты
- Гротеск (стек Inter/Roboto/Arial), вес 400-600, обычный регистр, без трекинга. Мелкий аккуратный интерфейсный текст: заголовок строки 42-44 / 550-600, подпись 30 / 400 вторичным цветом.
- Моно (`fam:'mono'`) только для времени, чисел-счётчиков в диффе, клавиш: 24-34 px.
- Крупный текст только в двух местах: чёрная карточка-заголовок `uiHeadline` (80-92 px, 650, белый, по словам, ключевое слово `*так*` мятным `#9FD8C9`) и итоговая подпись под иконкой (100+ px). Над элементами заголовков нет.
- Числа крутятся барабаном `roll` со смазом (счётчик, сумма на графике).

## Композиция (вертикаль 1080×1920)
- В кадре всегда один элемент по центру (x 540, y 880), ширина 760-920. Вокруг много воздуха, как в оригинале. Маленькие элементы (кнопка 230, таблетка 660×164, уведомление 900×200) тоже по центру, без подписей вокруг.
- Высокие элементы под вертикаль: план/дифф 900×880, меню 860×760, график 920×900, телефон 600×1180.
- Ничего важного ниже y 1690, текст не шире x 60…1020 (`txt` сжимает по `max`).

## Приёмы
- Герой `M.hero(t, S, R)`: состояния `{t, k, w, h, r, fill, o}`; `fill`: `card` (по теме), `navy`, `black`, `phone`. Ширина/высота/радиус едут пружиной с лёгким перелётом, цвет контейнера через серый `#C3C8D2`, содержимое старого и нового состояния перетекает с сильным размытием (уменьшение до 4 % и растяжение). Морф 0,3 с.
- Цепочки как в оригинале: кнопка → таблетка статуса → карточка; поле с чипами → клик по чипу → выпадающее меню → выбор → снова поле с новым значением; спиннер «в работе» → галочка «готово» внутри того же элемента.
- Внутри состояния мелкие события на долях: строки диффа заливаются зелёным слева направо (0,32 с, полоска 6 px слева), удалённые красным с зачёркиванием; подсветка строки меню едет за курсором; звезда пульсирует при клике; тумблеры по одному; рамка выбора темы переезжает; линия графика рисуется слева направо 1 с; подсказка у точки; вкладка меняет число барабаном и форму кривой.
- Курсор macOS (`M.cursor`): чёрная стрелка с белой обводкой (в тёмной части наоборот), едет последние 0,55 с сегмента с ease, клик = сжатие 14 %, при быстром движении смаз. Каждый морф начинается кликом курсора по нужной точке.
- Готовые элементы: `uiSend`, `uiStatus`, `uiPlan`, `uiComposer`, `uiMenu`, `uiSettings`, `uiThemes`, `uiChart`, `uiBars`, `uiSlider`, `uiHeadline`, `uiToast`, `uiPhone`, `uiCounter`, `uiSearch`, `uiIcon`. Геометрия для прицела курсора: `planGeo`, `composerGeo`, `menuGeo`, `setGeo`, `themesGeo`, `chartGeo`, `segGeo`.
- Иконки только штрихом 3-4 px с круглыми концами (`icCheck`, `icStar`, `icBell`, `icSun`, `icMoon`, `icSearch`...). Логотип продукта рисуй своей простой фигурой (`M.logo`: три плашки «стопкой»).

## Движение и ритм
- 120 BPM, доля 0,5 с. Морфы и клики на долях. Состояние живёт 1-4 с: короткие (кнопка, таблетка) 1-2 с, карточки 3-4 с.
- Камера: лёгкий наезд +1,8 % за состояние, на морфе вдох -2,5 %; `z` в состоянии для крупного плана.
- Тёмная часть посередине ролика (выбор темы → график), возврат к светлому через чёрную карточку-заголовок.
- Финал: морф в иконку `fill:'black'` 300×300, r 76 (y 780), под ней название 104 px и подпись 46 px по словам, курсор кликает по иконке.

## Звуки
`M.cutSounds(s, [[t, вид, громкость?, pitch?]])`: `click` на клик, `morph` (pop_soft) на морф, `toggle`, `type`, `tick` (строки, счёт), `star` (pop_high), `done` (success), `dark` (bubble_down) на смену темы, `roll` (odometer) на счётчик, `notify` на уведомление, `scene` (marimba) на чёрную карточку, `end` (ta_da) в финале. Громкость 0,08-0,15, одно событие в 0,5-1 с.

## Запреты
- Чужие названия моделей, сервисов, логотипы (никаких звёздочек-искр, «T3», провайдеров), чужие пути и ники. Всё по-русски, деньги в рублях, без длинного тире.
- Заголовки над элементом, градиентный фон, свечение, частицы, несколько карточек сразу.
- Линейные движения, появление без морфа, смена сцены без клика или доли.

## Каркас
```js
const M = MORF;
const DK = [[0, 0], [12, 1]];                       // светлая → тёмная
const S = [
  { t: 0, k: 'send', w: 230, h: 230, r: 115, fill: 'navy', intro: 1 },
  { t: 1, k: 'status', w: 660, h: 164, r: 82, o: { label: 'Ищу', done: 2.5, doneLabel: 'Нашёл' } },
  { t: 3, k: 'menu', w: 860, h: 700, r: 30, o: { search: 'Найти', rows: [{ title: 'Пункт', sub: 'Подпись', key: '1' }], hover: [[0, 0]] } },
  { t: 6, k: 'icon', w: 300, h: 300, r: 76, fill: 'black', y: 780 }
];
const R = { send: M.uiSend, status: M.uiStatus, menu: M.uiMenu, icon: M.uiIcon };
const CK = [[0, 180, 240], [0.9, 20, 30], [2.9, 300, 260]], CL = [1.0];
function draw(t, k) { M.begin(k, t, DK); const Hr = M.hero(t, S, R); M.cursor(t, Hr, CK, CL); }
function sound(s) { M.cutSounds(s, [[1, 'click'], [1.05, 'morph'], [2.5, 'done'], [3, 'morph']]); }
```
