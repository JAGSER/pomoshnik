# MORF: один элемент в центре, который морфится в следующий (продуктовый промо и иллюстрированные истории)

## Палитра
- Светлая часть: фон `#F4F5F8`, карточки `#FFFFFF`, тень очень широкая и мягкая (рисует `hero`). Тёмная: фон `#0A0A0A`, карточки `#121212`, текст `#F1F1F2`, вторичный `#8C8C92`; смена всей сцены за 0,35 с через `begin(k, t, [[t, 0|1], ...])`.
- Текст: `#0E0F12`, вторичный `#6B7079`, третичный `#A3A8B1`.
- Акценты интерфейса строго по смыслу: navy `#1C3460` (отправка), голубой `#4EA8D2` (в работе), зелёный `#0A8459` на `#E2F7EC` (готово), teal `#147870` (тумблеры, выбор), красный `#C8324A` (удалено), лосось `#D0695C` (график), фиолетовый `#7B3FE4` (бейдж), золото `#F2A93B` (звезда).
- Предметные цвета `M.C`: orange yellow pink rose ginger brown beige grey grey2 wood sea sky2 grass leaf pine red blue navy teal green purple · кожа skin skin2 skin3 · волосы hair blond grey2 · warm (свет окон, фонарей) chalk (доска) night. Везде, где цвет: параметр, можно имя из `M.C` или `'#hex'`.
- Без градиентов фона, свечений, зерна, виньетки. Плоско и чисто.

## Шрифты
- Гротеск 400-600, обычный регистр. Интерфейсный текст: строка 42-44 / 550, подпись 30 / 400 вторичным. Моно (`fam:'mono'`) только для времени, счётчиков, клавиш.
- Крупный текст только в чёрной карточке `uiHeadline` (80-92 px, ключевое слово `*так*` мятным) и в итоговой подписи (100+ px). Числа крутятся барабаном `roll`.

## Композиция (1080×1920)
- В кадре всегда один элемент по центру (x 540, y 880), вокруг воздух. Интерфейс: ширина 760-920 (кнопка 230, таблетка 660×164, уведомление 900×200, меню 860×760, телефон 600×1180). Сцена-картинка `scene`: 900-940 × 900-1150, r 36-44.
- Ничего важного ниже y 1690, текст в x 60…1020 (`txt` сжимает по `max`).

## Герой и морф
- `M.hero(t, S, R)`: состояния `{t, k, w, h, r, fill, y, z, o}`; `fill`: `card`, `navy`, `black`, `phone` или `'#hex'` (небо сцены). Размер и радиус едут пружиной с перелётом, содержимое перетекает через сильное размытие, морф 0,3 с. Камера: наезд +1,8 % за состояние.
- Готовые элементы (рисуют от центра): `uiScene` (картинка из типовых объектов), `uiSend`, `uiStatus`, `uiPlan`, `uiComposer`, `uiMenu`, `uiSettings`, `uiThemes`, `uiChart`, `uiBars`, `uiSlider`, `uiHeadline`, `uiToast`, `uiPhone`, `uiCounter`, `uiSearch`, `uiIcon`. Геометрия для курсора: `planGeo`, `composerGeo`, `menuGeo`, `setGeo`, `themesGeo`, `chartGeo`, `segGeo`.
- Все тексты элементов только из параметров (`label`, `title`, `foot`, `search`, `tabs`, `days`, `section`, `brand`, `clock`); пустой параметр = ничего не пишется. Логотип-стопку (`o.logo:1` в `uiHeadline`/`uiCounter`, `uiIcon` без `o.draw`) только для своего продукта темы.
- Цепочки: кнопка → таблетка статуса → карточка; поле с чипами → меню → выбор; спиннер → галочка. Мелкие события на долях (строки заливаются, тумблеры по одному, линия графика рисуется 1 с).

## Типовые объекты (`uiScene`)
Состояние: `{t, k:'scene', w:920, h:1100, r:40, fill:'#DCEBF7', o:{ground:[y, 'grass'], draw:(t, i) => {...}, cap:{text, t0}}}` (`R.scene = M.uiScene`). Внутри `draw` координаты от центра карточки (видно ±w/2, ±h/2), всё обрезается формой. Якорь объектов: середина низа (на земле), у неба: центр. Плоские скруглённые фигуры без обводок, детали штрихом с круглыми концами, пятно-тень `ground(x, y, w)`. `t`: время кадра для ходьбы, волн, мерцания.
- **Люди**: `person(x, y, рост, {kind:'adult'|'child'|'old', pose:'stand'|'walk'|'run'|'wave'|'sit'|'hold'|'ride', dir:±1, t, ph, shirt, pants, dress, skin, hair, hairStyle:'short'|'long'|'bun'|'bald', hat (каска), cap (кепка), bag (рюкзак), item:'book'|'phone'|'basket'|'flag'|'cane'|fn(x,y), itemCol, edge})`. Рост взрослого в сцене 200-360, ребёнок ×0,66. `people(x, y, рост, [опции…], {gap:.42, t, edge})`: ряд с обводкой цветом фона (`edge:false` без неё, если люди не касаются), не сливаются, шаг вразнобой.
- **Здания**: `house(x,y,w,h,{wall,roof,door,win,lit})` · `tower(x,y,w,h,{floors,cols,wall,lit,litCol,build 0…1})`→ число горящих окон · `shop`/`cafe(x,y,w,h,{sign,signBg,signCol,wall,awning,awning2})` · `school(x,y,w,h,{sign,wall,roof,flag})` · `windows(x,y,w,h,rows,cols,{lit})`. `lit`: доля или `(i, r) => 0…1`; «гаснут один за другим»: `lit: (i, r) => 1 - M.prog(t, t0 + r * 5, t0 + r * 5 + .3)`. Стройка: `build: M.prog(t, t0, t1)`.
- **Растения**: `tree(x,y,h,{kind:'leaf'|'oak'|'maple'|'pine', col, col2, trunk})` · `grass(x,y,w,{h,col,t})` · `leaf(x,y,s,{kind:'maple'|'oval', col, rot})`.
- **Транспорт**: `car(x,y,w,{col,dir,t})` · `bus(x,y,w,{col,num,dir,t})` · `bike(x,y,w,{col,dir,t,rider:{опции person}|false})` · `boat(x, y_воды, w, {col,cabin,motor,crew:[опции person…],dir,t,ph,wake})`. Движение: x от t.
- **Животные**: `dog(x,y,s,{col,pose:'stand'|'walk'|'sit'|'sleep',dir,t})` · `cat(x,y,s,{col,pose:'sit'|'walk'|'sleep',dir,t})` · `bird(cx,cy,s,{pose:'fly'|'sit',col,t,ph})` (летящая: чайка галочкой).
- **Небо и природа**: `sun(cx,cy,r,{col,rays,t})` · `moon(cx,cy,r,{col})` · `stars(x,y,w,h,{n,on 0…1,col,seed,t})` · `cloud(cx,cy,w,{col})` · `sea(x, y_горизонта, w, h, {col,col2,t})` · `hill(x,y_верха,w,h,{col})`.
- **Улица**: `lamp(x,y,h,{on 0…1,col,light})` · `garland(x1,y1,x2,y2,{n,sag,on (сколько горит, дробное) | fn(i),cols})` · `board(x_лев,y_верх,w,h,{title,lines:['строка'|['слева','справа']],p (доля написанного),bg,col,frame})` · `sign(cx,cy,'текст',{bg,col,size,pole})`.
Скорость: всё неподвижное в сцене (дома, деревья, полки, земля) заверни в `M.layer('ключ', i.w, i.h, () => {...})`: рисуется один раз в спрайт; живое (люди, транспорт, волны, окна) рисуй поверх каждый кадр. Своё (маяк, кран, рынок, баян) рисуй в том же языке: скруглённые плоские фигуры цветами `M.C`, детали штрихом 4-6 px, тень `ground`. Контекст бери `M.ctx()` (во время морфа это холст размытия, не `k.g`), помощники: `M.rr` `M.circ` `M.ell` + `M.fill(цвет)`, `M.pl(точки, цвет, толщина)`.

## Как ставить сюжет (обязательно)
- **Тема без интерфейса** (город, история, природа, люди): основа: сцены `scene`, которые морфятся одна в другую на ключевых словах (8-14 сцен), между ними короткие интерфейсные «островки» только если в тексте есть число, цена, список (`uiStatus` с `icon:'sun'|'moon'` для времени суток: спиннер значит «загрузка»; `uiCounter`, `uiToast`). Тумблеры, меню, дифф, графики и телефон не заменяют предметы.
- **Люди**: если в тексте есть люди (рыбаки, продавец, дети, рабочие, бабушка, танцующие), они нарисованы `person`/`people` в нужной позе и с предметом (рюкзак, книга, каска, машет).
- **Предметы**: каждый названный предмет рисуется объектом, а не словом в строке списка или значком.
- **Цвета**: цвет, названный в тексте (розовое солнце, оранжевые куртки, жёлтый кран, синий автобус, рыжий пёс), соблюдается точно, оттенком из `M.C`.
- **Время**: событие появляется в момент слова (по таймингу фразы, ±0,3 с), не раньше и не позже; морф на ключевом слове, числа докручиваются до названного значения к моменту слова.
- **Надписи** только по теме ролика и короче озвучки: подпись `cap` 1-3 слова, вывески и доски: то, что сказано. Никаких текстов из примера, английских слов, выдуманных подписей.
- **Курсор, тёмная тема, иконка в финале**: приёмы продуктового ролика. Используй их, только если тема про приложение или сервис. В остальных темах морф идёт по доле без курсора, ночь: сцена с тёмным небом (`fill:'#14213D'`), а финал: ключевая сцена темы с подписью-названием.
- Сквозной герой ролика выбирается из темы (человек, животное, предмет из озвучки), а не значок шаблона.

## Движение и ритм
- 120 BPM, доля 0,5 с. Морфы и клики на долях. Состояние живёт 1-6 с, сцены дольше, внутри них что-то происходит (идут, плывут, машут, гаснут окна).
- Курсор (`M.cursor(t, Hr, keys, clicks)`, только продуктовые темы): едет последние 0,55 с, клик = сжатие 14 %.

## Звуки
`M.cutSounds(s, [[t, вид, громкость?, pitch?]])`: `click`, `morph`, `toggle`, `type`, `tick`, `star`, `done`, `dark`, `roll`, `notify`, `scene`, `end`, или любое имя библиотеки звуков (`bubble`, `pop_soft`, `kalimba_run`…). 0,08-0,15, одно событие в 0,5-1 с.

## Запреты
- Чужие бренды и логотипы, длинное тире, английские слова. Всё по-русски, деньги в рублях.
- Заголовки над элементом, градиентный фон, свечение, частицы, несколько карточек сразу.
- Линейные движения, появление без морфа, смена сцены вне доли.

## Каркас
```js
const M = MORF;
const S = [
  { t: 0, k: 'scene', w: 920, h: 1100, r: 40, fill: '#DCEBF7', o: { ground: [300, 'grass'], cap: { text: 'Утро', t0: .3 },
    draw: (t, i) => { M.sun(-260, -300, 70, { col: 'pink' }); M.people(0, 300, 260, [{ pose: 'walk', shirt: 'orange' }, { kind: 'child', bag: 'red', pose: 'run' }], { t }); } } },
  { t: 4, k: 'status', w: 660, h: 164, r: 82, o: { label: 'Полдень', icon: 'sun', c: 'orange' } },
  { t: 5, k: 'count', w: 860, h: 420, r: 32, o: { from: 0, to: 7, t0: 5.1, t1: 6, label: 'лодок' } }
];
const R = { scene: M.uiScene, status: M.uiStatus, count: M.uiCounter };
function draw(t, k) { M.begin(k, t, [[0, 0]]); M.hero(t, S, R); }
function sound(s) { M.cutSounds(s, [[4, 'morph'], [5, 'morph'], [5.1, 'roll']]); }
```
