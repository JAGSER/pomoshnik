# «Швейцарский постер»: разбор образца

Образец: два шоурила моушн-дизайнера по одному вирусному промпту (16:9, ~15 с каждый, смена картинки примерно раз в секунду).

## Правила стиля
1. **Палитра: 5 сплошных полей.** Красно-оранжевый `#FF5937`, ультрамарин `#2E3AFE`, кремовый `#F2EDE7`, почти чёрный `#0F0F11`, жёлтый `#FAC63C`. Поле занимает весь кадр, без градиентов. На поле 1 цвет текста и 1 акцент: красное → чёрный текст + кремовый; синее → кремовый + жёлтый/красный; кремовое → чёрный + красный; чёрное → кремовый + красный; жёлтое → чёрный + красный/синий.
2. **Фактура почти нулевая:** плоская печать, лёгкое «кипящее» зерно (5–6 % шума, 12 раз/с). Никаких теней и свечений, объём только через тонкие концентрические кольца и точки.
3. **Линии:** волосяные (2–3 px) для линеек, рамок, колец, выносок; толстые (12–20 px) только у паттернов (трюше, улицы, трубка). Скругления лишь у паттернов, у плашек углы прямые.
4. **Шрифты и набор:** огромный жирный гротеск капсом, широкий (900, растяжка по ширине ×1,12–1,18, плотный трекинг), занимает 80–95 % ширины. Пара к нему: курсивная антиква строчными («motion designer»). Служебное: мелкий моно капсом и разрядка капсом (0,3 em). Точка-акцент после слова цветным кружком («LINEAR.», «Claude.»).
5. **Композиция:** строгая сетка, поля 96 px, всё выровнено по оси или по левому краю. Один крупный объект (слово, круг, звезда, сфера) и 1–2 подписи. Над словом волосяная линейка с моно-метками по краям, под ним строка выходных данных.
6. **HUD по углам постоянно:** уголки-скобки, слева сверху название ролика, справа сверху «01 / ИНТРО» (номер главы), слева снизу таймкод `00:00:03:12` и FPS, справа снизу «120 BPM» с индикатором долей ■■■□. Мелко, 24–26 px, полупрозрачно.
7. **Характер движения:** упругое и быстрое. Объекты вылетают пружиной с лёгким перелётом, буквы «надуваются» по ширине (ось ширины), слова въезжают со смазом (3–5 призраков). Ничего не плывёт линейно: старт резкий, оседание мягкое. Фон живёт постоянно: кольца расходятся, точки волнуются, сфера крутится.
8. **Монтаж:** смена цветового поля на долю/ключевое слово; склейки жёсткие или геометрические: круг растёт из объекта (iris), поле въезжает блоком, сетка плиток. После склейки камера чуть оседает (масштаб 1,06 → 1).
9. **Сквозные приёмы:** точка, которая растёт в круг и становится следующим объектом (матч-кат); морфинг фигур (круг → звезда → треугольник) в рамке трансформации с ручками и моно-подписью «ROT 053°»; кольцо из 12 точек/звёзд вокруг центра; текст по кругу; кривые изинга «из A в B» строками; трюше-волны; точечная сетка с радиальной волной; точечная сфера/тор; полосатая трубка.
10. **Финал:** знак + огромное слово + курсив + волосяная линия + строка мелких выходных данных. Точка-акцент последней.
11. **Звук:** сухие щелчки, вудблок, тики на каждое событие, перебор маримбы на смену поля, «та-да» только в финале.

## Мир и герой демо
Мир: серия плакатов открытия кофейни, отпечатанных по швейцарской сетке. Герой: **кофейное зерно** (эллипс с S-образной бороздкой) проходит через все сцены: падает точкой, становится точкой-акцентом «ЗЕРНО.», обжаривается (кремовый → жёлтый → красный → чёрный), крутится в барабане, размножается в 12 сортов, отмечает страны на сфере, морфится в звезду чемпиона, сидит в чашке, становится осью часов, булавкой на карте, точкой после «08-22» и знаком логотипа. Счётчик: номер главы в HUD 01…08 с прокруткой цифр + числа сцен (12, °C, 07:00, 15, 08-22). Штамп: текст по кругу «СКОРО ОТКРЫТИЕ» в начале → печать «ОТКРЫТО» в финале.
