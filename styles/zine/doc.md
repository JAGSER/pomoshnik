# Стиль «Поп-журнал» (ZINE)

`ZINE` уже подключена, своё не объявляй. Громкий соцсетевой рил в стиле журнала-вырезки: яркие фоны с растром точек, наклонные ленты с бегущим текстом, огромные слова капсом с чёрной обводкой, белая карточка с курсивом, наклейки с тенью-сдвигом, окно терминала, телефоны, лучи, нумерованные шаги и призыв «напиши слово».

## Правила
1. Палитра только `ZINE.C`: розовый `pink`, жёлтый `yellow`, синий `blue`, оранжевый `orange`, лайм `lime`, фиолетовый `violet` (каждый с парой для растра: `pinkDot`, `yellowDot`, `limeDot`, `violetDot`), чернила `ink`, белый `white`.
2. Каждая сцена свой фон: `half(g, цвет, цветDot)` (растр), `checker(g)` (синяя клетка), `rays(g, t)` (оранжевые лучи) или тёмный `C.night`. Соседние сцены разного цвета.
3. Слова только `word`: капсом, 900, обводка чёрная, 110–190 px, слегка повёрнуты (rot ±0.03), появление пружиной `p: sp((lt - задержка) / 0.3)`. Вторая строка другим цветом (`white` и `yellow`). Без длинного тире.
4. Акцентное слово курсивом на белой карточке `card`. Мелкие пометки маленьким `word` 50–70 px под углом.
5. Факты и пункты на наклейках `sticker` (сетка 2×N, 440×250, разные цвета, по очереди через 0.5 с). Шаги через `step`. Процесс через `term`. Результат через `phone` на фоне `rays`.
6. Лента `tape` сверху или снизу почти в каждой сцене: короткая фраза со стрелками или точками.
7. Финал: «хочешь …? напиши «СЛОВО»» и ник канала.
8. Звуки: `pop_double` на слова хука, `drop` на склейки-удары, `pop_high` на наклейки, `type` на терминал, `ta_da` на результат. Склейки `cutSounds(s, CUTS, 'rim', 0.1)`.

## Каркас
```js
const Z = ZINE, C = Z.C;
const CUTS = [0, 3, 8];
function draw(t, k) {
  const g = k.g, { i, lt } = Z.scene(t, CUTS);
  g.save(); Z.cam(g, lt, 540, 960, 0.6);
  if (i === 0) { Z.half(g, C.pink, C.pinkDot); Z.tape(g, 'ДО → ПОСЛЕ → ДО →', 150, -0.06, t);
    Z.word(g, 'ГРОМКИЙ', 540, 600, 150, C.white, { align: 'center', p: Z.sp(lt / 0.3) });
    Z.card(g, 'заголовок', 540, 820, 110, Z.sp((lt - 0.5) / 0.4)); }
  // ...
  g.restore();
}
function sound(s) { Z.cutSounds(s, CUTS, 'rim', 0.1); }
```

## API
- `scene(t, cuts)` → `{i, lt, dur}`; `cam(g, lt, cx, cy, k)`.
- Фоны: `half(g, c1, c2, step)`, `checker(g, c1, c2, s)`, `rays(g, t, c1, c2, cy)`.
- `tape(g, текст, y, rot, t, bg, fg, dir)` наклонная лента.
- `word(g, s, x, y, size, fill, {align, rot, p, stroke, max})` слово с обводкой (y базовая линия).
- `card(g, s, x, y, size, p, rot)` белая карточка, курсив по центру x, y.
- `sticker(g, заголовок, подпись, x, y, w, h, цвет, p, {rot, fg})`.
- `term(g, x, y, w, h, строки, t, t0, {title, d, rot})`: строки с «✦» оранжевые, с «+» лаймовые.
- `phone(g, x, y, s, rot, заголовок, c1, c2, t)`; `step(g, n, текст, x, y, цвет, p)`.
- Утилиты: `cl, eo, eio, sp, mix, font, rr, words, cursor, count`.

## Рецепт
Хук за 3 с: 2 огромных слова + карточка с курсивом + подпись в скобках. Затем «что/как» с наклейками, процесс в терминале на клетке, результат на лучах, 3 шага на лайме, финал «напиши слово» на фиолетовом.

## Типовые ошибки
- Белый текст на жёлтом или лаймовом без обводки: всегда `word`, у него обводка.
- Слишком много текста на наклейке: заголовок 1–2 слова, подпись до 5 слов.
- Ленты налезают на нижнюю панель: лента не ниже y 1600.
