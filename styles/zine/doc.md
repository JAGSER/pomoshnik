# Стиль «Поп-журнал» (ZINE)

`ZINE` уже подключена, саму библиотеку заново не объявляй (свои функции для новых предметов писать можно и нужно, в том же языке: плоская заливка, чёрный контур 5–6 px, тень-сдвиг 10 px). Громкий рил в стиле журнала-вырезки: яркие фоны с растром точек, огромные слова капсом с чёрной обводкой, белая карточка с курсивом, наклейки с тенью, наклонные ленты, плоские картинки-аппликации с толстым контуром.

## Главные правила (против частых ошибок)
1. **Рисуй, а не подписывай.** Всё, что названо в озвучке (люди, дома, транспорт, животные, еда, погода), рисуется предметом: из «Типовых объектов» или своей функцией. Наклейка или слово вместо предмета («РЫЖИЙ ПЁС», «АВТОБУС №3» на плашке) запрещены. Слова только дополняют картинку.
2. **Люди, если о них речь.** Рыбаки, продавцы, дети, рабочие, бабушка, танцующие: `person` в нужной позе и одежде, столько, сколько сказано (семь лодок = 7 лодок). Сквозного героя выбирай из самой темы.
3. **Цвет из текста соблюдай**: «розовое солнце», «оранжевые куртки», «синий автобус», «жёлтый кран», «рыжий пёс» передай параметром цвета (ближайший оттенок `C`).
4. **Событие в момент слова**: предмет появляется или действие начинается на фразе, где он назван (по таймингу из `k.subs`), не раньше и не позже; глагол показывай движением (солнце встаёт, лодки уходят, кран поднимает плиту, огни гаснут).
5. **Надписи только по теме ролика.** Терминал, телефон, нумерованные шаги, призыв «напиши слово» и ник канала только если они есть в теме (про приложения, соцсети, инструкции). В рассказе про город, природу, людей их нет. Финал: последняя мысль озвучки.
6. Пустых кадров нет: в каждой сцене есть картинка, не только слово.

## Палитра и фон
- Только `ZINE.C`: розовый `pink`, жёлтый `yellow`, синий `blue`, оранжевый `orange`, лайм `lime`, фиолетовый `violet` (растр: `pinkDot`, `yellowDot`, `limeDot`, `violetDot`, `blue2`, `orange2`), чернила `ink`, белый `white`, ночь `night`. Для предметов: `red, green, green2, brown, grey, grey2, sky, sand, skin, skin2, skin3, hair, blond, ginger, silver, chalk, board, wood`.
- Фон сцены: `half(g, цвет, цветDot)` (растр), `checker(g)` (клетка), `rays(g, t)` (лучи) или своя сцена (небо `half(g, C.sky, C.blue2)`, земля `ground`, море `sea`). Соседние сцены разного цвета.

## Текст
- Заголовок `word`: капсом, 900, обводка, 110–190 px, rot ±0.03, `p: sp((lt - задержка) / 0.3)`. Вторая строка другим цветом. Без длинного тире.
- Акцент курсивом на `card`. Числа и факты на `sticker` (заголовок 1–2 слова, подпись до 5 слов). Ленту `tape` ставь, когда есть короткая фраза по теме, не ниже y 1600.
- Текст не перекрывает рисунок: заголовок вверху (y 200–500), картинка ниже.

## Каркас
```js
const Z = ZINE, C = Z.C;
const CUTS = [0, 3, 8];
function draw(t, k) {
  const g = k.g, { i, lt } = Z.scene(t, CUTS);
  g.save(); Z.cam(g, lt, 540, 960, 0.6);
  if (i === 0) { Z.half(g, C.sky, C.blue2); Z.sun(g, 760, 520 - 200 * Z.eo(lt / 2), 110, { c: C.pink, rays: true, t }); Z.sea(g, 900, t);
    Z.word(g, 'РАССВЕТ', 540, 330, 160, C.white, { align: 'center', p: Z.sp(lt / 0.3) }); }
  g.restore();
}
function sound(s) { Z.cutSounds(s, CUTS, 'rim', 0.1); }
```

## API
- `scene(t, cuts)` → `{i, lt, dur}`; `cam(g, lt, cx, cy, k)`. Утилиты: `cl, eo, eio, sp, mix, font, rr, words, count, ink(g, fill, lw)` (заливка + контур текущего пути), `box(g, x, y, w, h, fill, тень)`.
- Фоны: `half(g, c1, c2, step)`, `checker(g, c1, c2, s)`, `rays(g, t, c1, c2, cy)` (кэшируются).
- `tape(g, текст, y, rot, t, bg, fg, dir)`; `word(g, s, x, y, size, fill, {align, rot, p, stroke, max})`; `card(g, s, x, y, size, p, rot)`; `sticker(g, заголовок, подпись, x, y, w, h, цвет, p, {rot, fg})`.
- Только по теме: `term(g, x, y, w, h, строки, t, t0, {title, d, rot})`, `phone(g, x, y, s, rot, заголовок, c1, c2, t)`, `step(g, n, текст, x, y, цвет, p)`.

## Типовые объекты
Все: x, y = точка на земле по центру (кроме оговорённых), s = масштаб, цвет параметром, `t` для анимации, `dir: -1` разворот.
- `person(g, x, y, s, o)`: рост взрослого 330·s, ребёнка 220·s. `o = {age:'adult'|'kid'|'old', pose:'stand'|'walk'|'run'|'wave'|'hold'|'sit'|'dance', t, phase, dir, skin, shirt, pants, hair, hairStyle:'short'|'long'|'bun'|'bald', dress, dressColor, apron, hat:'helmet'|'cap'|'scarf', hatColor, backpack:цвет, glasses, mouth:'smile'|'open'|'sleep', item:'book'|'bag'|fn(g), itemColor, arm:'left'}`. `sit` с `item` держит предмет на коленях (бабушка с книгой); сиденье рисуй сам до человека. Группа: шаг 150·s, разные `shirt` и `phase`.
- Здания: `house(g, x, y, w, h, {wall, roof, door, lit, cols, rows})`; `tower(g, x, y, w, h, {floors, cols, wall, lit, built: 0…1})` (растёт снизу вверх); `shop(g, x, y, w, h, {wall, awning, sign, signBg, lit})` (магазин, кафе); `school(g, x, y, w, h, {wall, roof, sign, flag})` (школа, библиотека). `lit`: доля горящих окон 0…1 (гаснут по одному, если уменьшать) или функция(номер); без `lit` окна дневные.
- Природа: `tree(g, x, y, s, {kind:'leaf'|'pine'|'oak', c, trunk, t, fall: число листьев, leaf: цвет})`; `leaf(g, x, y, s, c, rot)`; `grass(g, x, y, w, {c, t})`; `ground(g, y, c)`; `hill(g, x, y, w, h, c)`; `sea(g, y, t, {c, c2})` (от y до низа).
- Небо: `sun(g, x, y, r, {c, rays, t, glow})`, `moon(g, x, y, r, {c})`, `stars(g, t, {n, x0, y0, x1, y1, c, p})` (p доля зажжённых), `cloud(g, x, y, s, c)`, `bird(g, x, y, s, {c, t, phase, dir})` (x, y центр; чайка по умолчанию).
- Транспорт: `car(g, x, y, s, {c, t, dir})` 300·s; `bus(g, x, y, s, {c, num, t, people, dir})` 560·s; `bike(g, x, y, s, {c, t, rider: опции person | false})`; `boat(g, x, y, s, {c, cabin | false, motor, people: [опции person], t, dir})` (y = линия воды); `crane(g, x, y, s, {c, h, jib, hx, hook, load: цвет плиты, op: опции person})`.
- Животные: `dog(g, x, y, s, {c, ear, pose:'stand'|'sit'|'run'|'sleep', zzz, t, dir})`; `cat(g, x, y, s, {c, pose:'sit'|'sleep', t})`.
- Улица: `lamp(g, x, y, s, {on: 0…1, c})`; `garland(g, x1, y1, x2, y2, {n, on: 0…1, colors, sag, t})`; `board(g, x, y, w, h, строки, {p, title})` (доска с мелом, p доля написанного); `sign(g, x, y, w, h, текст, {bg, fg, rot})` (x, y центр).
- Перемещение считай от времени: `x = mix(-300, 1380, cl((t - t0) / 4))`. Чего нет в списке (рыба, фрукты, баян, рюкзак отдельно), рисуй своей функцией из кругов и многоугольников с `ink`.

## Звуки
`pop_double` на слова хука, `drop` на склейки-удары, `pop_high` на появление предметов и наклеек, `ta_da` на финал. Склейки `cutSounds(s, CUTS, 'rim', 0.1)`.

## Типовые ошибки
- Наклейка или слово вместо предмета; пустой фон со словом. Рисуй предмет.
- Терминал, телефон, «напиши слово» в теме, где их нет.
- Мелкие предметы (лодка 40 px): главный предмет сцены не меньше 250 px.
- Белый текст на жёлтом или лайме без обводки: всегда `word`.
