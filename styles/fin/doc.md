# Стиль «Финансовый канал» (FINS)

`FINS` уже подключена, своё не объявляй. Ролик для канала о деньгах: почти чёрный зелёный фон в линейку, жёлтый и красный, огромные слова капсом слева, красное зачёркивание старой мысли, рубрики канала с полосой прогресса, тёмные панели с графиками, кривая сложного процента, огонёк-символ, жёлтый взрыв и карточка канала с подпиской.

## Правила
1. Палитра только `FINS.C`: фон `dark` #0B110E, панели `panel`, линии `line`, жёлтый `yellow` #F7D23E (главное слово, рост), красный `red` #F04E37 (зачёркивание, падение), зелёный `green` (рост свечей), текст `text`, серый `muted`, выцветший `faded` (старая мысль).
2. Фон `bg(g)`; одна сцена может быть жёлтой: `bg(g, true)` + `burst` + `flame`, текст на ней `C.ink`.
3. Каждая сцена: `top(g, 'ИМЯ КАНАЛА', n)`. В сценах-рубриках n '01'..'04' даёт полосу «рубрика n / 04».
4. Слова только `word`: капсом, 900, 100–130 px, слева x 80, по 1–2 слова на строку. Под словом `note` одной строкой. Без длинного тире.
5. Хук: старая мысль (жёлтым и белым) → `strike` красным, цвет меняется на `faded` → ответ жёлтым.
6. Рубрики: `candles` (рынок), `metrics` (4 плитки-показателя), `bars` (парные столбики), `curve` (рост со временем). Панель сверху (y 320–1220), слово под ней (y ≈ 1400).
7. Финал: `profile` с подпиской и курсором, сверху серый моно-ярлык и жёлтая фраза.
8. Деньги в рублях. Не давай инвестиционных советов и обещаний дохода.
9. Звуки: `drop` на слова, `error_soft` на зачёркивание, `marimba_run`/`counter`/`odometer` на графики, `ta_da` на взрыв, `click` + `success3` на подписку. Склейки `cutSounds(s, CUTS, 'rim', 0.08)`.

## Каркас
```js
const F = FINS, C = F.C;
const CUTS = [0, 1.8, 3.4, 5.4];
function draw(t, k) {
  const g = k.g, { i, lt } = F.scene(t, CUTS);
  F.bg(g, false);
  g.save(); F.cam(g, lt, 540, 960, 0.5);
  if (i === 0) { F.top(g, 'КОПИЛКА'); F.word(g, 'ВСЯ ЗАРПЛАТА', 760, t, 0.1, C.yellow, 120); }
  if (i === 2) { F.top(g, 'КОПИЛКА', '01'); F.candles(g, 80, 320, 920, 900, t, CUTS[i]); F.word(g, 'РЫНОК', 1400, t, CUTS[i] + 0.3); F.note(g, 'Разбор каждый день', 1470); }
  // ...
  g.restore();
}
function sound(s) { F.cutSounds(s, CUTS, 'rim', 0.08); }
```

## API
- `scene(t, cuts)` → `{i, lt, dur}`; `cam(g, lt, cx, cy, k)`; `bg(g, yellow)`.
- `top(g, имя, n, total, ярлык)` шапка канала и рубрика.
- `word(g, s, y, t, t0, col, size)` слово капсом (y = базовая линия); `note(g, s, y, col)`.
- `strike(g, x, y, w, t, t0)` красная черта поверх слова (y ≈ базовая линия − 40% размера).
- `panel(g, x, y, w, h)`; `candles(g, x, y, w, h, t, t0, {label, badge})`.
- `metrics(g, [[подпись, значение, 0..1, цвет] ×4], y, t, t0)` плитки 2×2.
- `bars(g, [[a, b] ...], [имяA, имяB], подписи, x, y, w, h, t, t0)` парные столбики.
- `curve(g, t, t0, {x, y, w, h, max, d, ticks})` кривая роста до ×max.
- `flame(g, x, y, s, t)`; `burst(g, t, cx, cy)`; `letters(g, s, y, size, t, t0, col)` буквы антиквой по одной.
- `profile(g, имя, подзаголовок, [[число, подпись] ×3], подписан?, t, t0, {y, line})`; `cursor(...)`.
- Утилиты: `cl, eo, eio, sp, mix, font, rr, words, count`.

## Рецепт
Хук за 1.8 с: старая мысль и зачёркивание, ответ жёлтым. Затем 2–4 рубрики по 1.6–2.5 с. Сцена роста с `curve`. Жёлтый взрыв с огоньком и именем канала. Финал: карточка канала, курсор жмёт «Подписаться».

## Типовые ошибки
- Слово длиннее 12 букв в одну строку: раздели на две строки `word`.
- Зачёркивание мимо слова: y черты чуть выше середины букв.
- Текст белым на жёлтом фоне: на жёлтом только `C.ink`.
