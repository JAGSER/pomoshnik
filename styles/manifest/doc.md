# Стиль «Манифест» (MANI)

`MANI` уже подключена, саму библиотеку заново не объявляй (свои функции для особых предметов писать можно и нужно, в том же языке: плоская заливка, без контура и теней). Ролик выглядит как запись видоискателя: по углам тонкие уголки и мелкий моно-HUD. Резкие склейки на долях 128 BPM, смена цвета фона на каждой смысловой сцене, огромные узкие заглавные слова по одному на долю, между ними плоские пиктограммы того, о чём говорится.

## Палитра (`MANI.C`)
- Фоны: `night` #0B0D0D, `cream` #ECE7DB, `blue` #2B28EB, `red` #ED391D. Один фон на сцену, сцены чередуют фоны. Фон по смыслу: ночь, вечер = `night`; день = `cream`.
- Пиктограммы и текст по умолчанию «чернила» к фону (`fg()`): на тёмном и синем кремовый, на кремовом и красном чёрный. Красный #ED391D: ключевое (последнее) слово серии и акценты.
- **Цвет, названный в тексте, обязателен** (розовое солнце, оранжевые куртки, жёлтый кран, синий автобус, рыжий пёс): тона `pink orange yellow green sky brown ginger navy` (+ `red cream ink gray`). Фон под таким предметом бери контрастный (синий автобус не на синем фоне). Кожа `SKIN[0..3]`.
- HUD сам «противоположного» цвета к фону. Без градиентов, теней, свечения; зерно уже в `bg`, белая вспышка только на ударе.

## Шрифты и композиция (1080×1920)
- Плакатный узкий гротеск 700, сжатие 0.7, ЗАГЛАВНЫЕ, с точкой в конце: 300–360 px одно слово, 190–230 px 2–4 строки (ширина подгоняется сама, ≤ 12 букв в строке). Моно: HUD 24 px, метки 30–38 px. Чат 50–58 px. Финал: имя 170 px, слоган 46 px разрядкой.
- Слово на базовой линии y ≈ 1010 или над/под картинкой. Пиктограммы на линии земли y 1100–1500, крупно (человек 260–420 px, здание 300–500 px), не ближе 60 px к краю. HUD-зона: y < 190 и y > 1600, туда ничего не ставь.
- В кадре максимум 2 текстовых блока + HUD.

## Что рисовать (правила против ошибок)
- **Каждый предмет, человек, животное из озвучки рисуется** типовым объектом или своей функцией. Не заменяй его словом, счётчиком, точкой, значком в рамке или пустой карточкой.
- **Люди, если о них речь** (рыбаки, продавщица, дети, рабочие, бабушка, танцующие): `person`/`crowd` с нужной позой, возрастом, одеждой и предметом в руке. Сколько сказано, столько и рисуй, если ≤ 8.
- **Событие в момент слова.** У фраз только t0/t1: время слова = t0 + (t1 − t0) × (символов до слова / символов во фразе). Склейка на ближайшей доле к этому моменту (сдвиг ≤ 0.25 с), предмет появляется на этой склейке или раньше, не позже. Счётчик доходит до сказанного числа к моменту, когда его произносят.
- **Надписи только из темы:** слова и цифры, которые звучат в озвучке. Не выдумывай статусы, даты, реплики и подписи. Моно-метка (`typed`) только с фактом из текста («МАЯК · 27 М»), без «ИМЯ_01 · СТАТУС».
- **Сквозной герой выбирается из темы** (человек, животное, предмет из озвучки) и только если подходит теме. Красная точка, клетка, замок, штампы, чат, облако точек, сеть: приёмы для абстрактных тем (внимание, свобода, данные). В бытовой теме не используй их вместо предметов. Чат-пузырь только для прямой речи из текста, штампы только для слов, которые звучат.
- HUD: `brand` = короткое имя темы. Финал: имя и слоган из темы, третья строка только если есть смысл.

## Движение и ритм
- `BEAT` = 0.469 с. `CUTS` = доли (`n * BEAT`), под фразы. Сцена 2–6 тактов; серия слов по 1 доле. Склейки резкие, без наплывов. Камера `camera(g, lt)`: оседание и наезд.
- Пиктограммы входят пружиной/ease-out за 0.2–0.4 с (масштаб от линии земли или выезд из-за края), дальше живут: идут, машут, едут, крутятся колёса (`t`). Слова и штампы ударом за 3–4 кадра.

## Звуки
`drop` на слово (последнее pitch 0.8), `woodblock` на склейки, `pop_soft`/`pop_high` на появление предметов, `type` на моно-метки, `tick`/`rim` на мелкие удары, `odometer` на счётчик, `sparkle` на огни, `marimba` + `success` в финале. Громкость 0.1–0.2.

## Запреты
Чужие логотипы и бренды, длинное тире, эмодзи. Больше одного красного слова в кадре. Склейка вне доли, плавные наплывы. Обрезанные краем фигуры и слова.

## Типовые объекты
Все стоят на точке земли `y` (лодка на линии воды), `x` = центр, смотрят вправо (`flip` влево). `t` = время для анимации (обычно `lt`). `col` = основной цвет (по умолчанию `fg()`), `cut` = цвет вырезов и кромки (по умолчанию фон из `bg`).
- `person(g,x,y,{h,age:'adult'|'child'|'old',pose:'stand'|'walk'|'run'|'wave'|'hold'|'sit'|'dance',t,phase,flip,body,legs,skin,hair,hairStyle:'short'|'long'|'bun'|'none',skirt,hat:'helmet'|'cap'|'kerchief',hatCol,backpack,item:'book'|'bag'|'box'|'flag'|'phone'|fn(g,x,y,u),itemCol,cane,seat})` → `{head,hand}`. Рост: взрослый 300, ребёнок 190, пожилой 285. `body` = одежда (куртка), голова и ноги по умолчанию `fg()`. Сидящему скамья рисуется сама (`seat:false` убрать). Кромка цвета фона: стоящие рядом не сливаются.
- `crowd(g,x,y,[опции person...],{h,gap,t})` ряд людей с разной фазой движения.
- `building(g,x,y,{kind:'house'|'tower'|'shop'|'cafe'|'school',w,floors,cols,fh,col,lit 0..1,litCol,seed,p 0..1,sign,signCol,signText,awning})` → `{x0,x1,top}`. `lit` доля горящих окон (уменьшай, гаснут по одному), `p` стройка снизу вверх, `sign` текст вывески, `awning` цвет маркизы (у кафе по умолчанию красная).
- `sign(g,cx,cy,'ТЕКСТ',{col,textCol,size,maxW})` табличка. `board(g,cx,cy,{w,h,title,lines:[...],size,t,t0,step,cps})` доска мелом, строки печатаются с `t0` через `step`.
- `tree(g,x,y,{kind:'leaf'|'pine',h,col,trunk,t})`, `grass(g,x0,x1,y,{h,col})`, `hill(g,x0,x1,y,{h,col})`, `ground(g,y,{x0,x1,col,lw})`, `leaves(g,t,{x0,x1,y0,y1,n,cols,s,speed})` падающие кленовые листья.
- `car(g,x,y,{w,col,t,flip})`, `bus(g,x,y,{w,col,num,heads:[цвет|null...],t,flip})`, `bike(g,x,y,{r,col,t,flip,rider:{опции person}|false})`, `boat(g,x,y,{w,col,kind:'motor'|'sail'|'row',sail,crew:[опции person],crewH,wake,t,flip})`.
- `dog(g,x,y,{s,col,pose:'stand'|'walk'|'sit'|'sleep',t,flip})` (s 1 ≈ 180 px), `cat(...)` то же (≈ 130 px), `bird(g,x,y,{s,col,t,phase})` чайка, `birds(g,t,{n,cx,cy,rx,ry,s,col,speed})` стая кружит.
- `sun(g,x,y,r,{col,rays,t,horizon})` (по умолчанию жёлтое; `horizon` прячет часть ниже y), `moon(g,x,y,r,{col,phase})`, `stars(g,t,{x0,x1,y0,y1,n,col,p})` (`p` доля зажёгшихся), `puff(g,x,y,{s,col})` облако, `sea(g,t,{y0,y1,n,col,fill,amp})` волны.
- `lamp(g,x,y,{h,col,on,lightCol})`, `garland(g,x0,y0,x1,y1,{n,sag,col,cols,on 0..1})` фонарики загораются слева направо.
- Своё: `prims(g,[['c',x,y,r,col],['l',[x,y,...],lw,col],['r',x,y,w,h,rad,col],['p',[x,y,...],col]],halo,cut)` рисует пиктограмму с кромкой.

## Приёмы стиля (для абстрактных тем)
`dot` точка, `crosshair` + `leader` + `typed` прицел с меткой, `cage`/`shards` клетка и ломка, `split`/`counter`/`cloud` деление и счёт, `bubble`/`typing` чат, `stamp`/`pile` штампы, `network` созвездие, `lock` замок, `mark`/`logo` знак и финал.

## Каркас
```js
const M = MANI, C = M.C, B = M.BEAT;
const CUTS = [0, 8, 12, 16].map((n) => n * B), THEME = ['night', 'cream', 'blue', 'cream'];
function draw(t, k) {
  const g = k.g, { i, lt } = M.scene(t, CUTS), th = THEME[i];
  M.bg(g, t, th); g.save(); M.camera(g, lt);
  if (i === 0) { M.sea(g, t, { y0: 1250, y1: 1500 }); M.sun(g, 540, 1250 - 260 * M.eo(lt / 1.2), 120, { col: C.pink, horizon: 1250 });
    M.boat(g, M.mix(300, 700, lt / 4), 1250, { t, crew: [{ body: C.orange }, { body: C.orange, pose: 'wave' }], wake: true }); }
  if (i === 1) ['ТВОЙ', 'ХОД?'].forEach((s, j) => M.word(g, s, 540, 1010, 330, t, CUTS[1] + j * B, j ? C.red : C.ink, { t1: CUTS[1] + (j + 1) * B }));
  if (i === 2) { M.ground(g, 1300); M.bus(g, M.mix(1400, 540, M.eo(lt / 0.6)), 1300, { col: C.yellow, num: '3', t }); }
  if (i === 3) M.logo(g, 'Имя', ['СЛОГАН', 'В ДВЕ СТРОКИ'], '', 540, 1000, t, CUTS[3]);
  g.restore(); M.hud(g, t, th, { brand: 'ТЕМА', a: i === 3 ? 1 - M.eo((t - CUTS[3]) / 0.5) : 1 });
}
function sound(s) { M.cutSounds(s, CUTS); s.play(CUTS[1], 'drop', 0.18); }
```

## API
- `scene(t, cuts)` → `{i, lt, dur}`; `camera(g, lt, {push, drift, cx, cy})`; `beat(n)`; `eo eo5 eio sp mix cl rng`.
- `bg(g, t, theme)`; `fg(theme)`, `bgc(theme)`; `hud(g, t, theme, {a, brand, total, rec})`; `flash(g, t, t0, d, a)`.
- `word(g, txt, x, y, size, t, t0, col, {t1, align, max})` (y = базовая линия); `lines(g, [[txt, col, t0]...], cx, cy, size, t, {lh, max})`.
- `mono(g, txt, x, y, size, col, {align, a, w})`; `typed(g, [[txt, col]...], x, y, size, t, t0, {cps, align})`; `spaced(g, txt, x, y, size, col, {track, max})`; `counter(g, label, value, x, y, size, col)`.
- `dot`, `crosshair(g, cx, cy, p, {len, a})`, `leader`, `cage(g, cx, cy, S, t, {sq0, bars, n, bend, ring, shake})`, `shards`, `split(g, cx, cy, t, times, {r})`, `cloud(g, cx, cy, p, t)`, `bubble(g, txt, x, y, 'r'|'l', t, t0, {size, max})`, `typing`, `stamp(g, txt, x, y, ang, size, t, t0)`, `pile`, `network(g, t, t0, {col})`, `lock(g, cx, cy, s, open)`, `mark(g, cx, cy, r, p)`, `logo(g, name, slogan, sub, cx, cy, t, t0)`, `cutSounds(s, CUTS, name, v)`.
