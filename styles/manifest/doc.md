# Стиль «Манифест» (MANI)

`MANI` уже подключена, своё не объявляй. Кинетическая типографика: бумага, чёрная тушь, один красный. Ролик звучит как заявление: короткие слова падают с ударом, линии подчёркивают и зачёркивают, простые фигуры (точки-люди, кирпичи-слова, печать) превращают мысль в образ.

## Правила
1. Палитра только `MANI.C`: бумага `paper` #F1ECE2, тушь `ink` #151311, красный `red` #D7261E (одно главное слово сцены или знак), серый `gray` #8C857A (второстепенные слова). Одна сцена за ролик может быть ночной: `bg(g, t, true)`, тогда текст `paper`.
2. Фон всегда `MANI.bg(g, t, dark)`: ровная бумага с зерном. Без градиентов, теней, свечения, фото, эмодзи.
3. Текст: рубленый 900 для главных слов (150–300 px, капсом для ударов), антиква `serif` 700 для тихих слов («не», «а», «должен»), 110–150 px. Одна мысль на сцену, 1–3 слова на удар. Слова появляются только `slam` (падение с наездом), по одному, шаг 0.25–0.4 с. Без длинного тире.
4. Композиция: текст по центру или слева на x 70, крупно, много воздуха. Фигуры под текстом (y 600–1600). Не больше 3 текстовых блоков.
5. Образы: `crowd` (люди-точки, «все»), `gather` (многое сжимается в одно, «немногие»), `bricks` (слова-кирпичи строят основание), `strike` (зачеркнуть неверное), `rule` (красная черта под главным), `seal` (печать-итог).
6. Ритм: склейка каждые 3–4 с ровно на начале фразы, сцена уходит `fade` за 0.2 с. Камера `camera(g, lt)` в каждой сцене: удар-наезд и дрейф.
7. Финал: название или главный лозунг крупно + красная черта или печать, держится 2 с.
8. Звуки: `drop` и `woodblock` на удары слов, `rim` на тихие слова, `error_soft` на зачёркивание, `bubble_down` на сжатие, `marimba_run` на рост толпы, `fanfare_soft`/`success3` на финал. Громкость 0.12–0.2. Склейки: `cutSounds(s, CUTS)`.

## Каркас
```js
const M = MANI, C = M.C;
const CUTS = [0, 3, 6.5, 10];            // начала фраз
function draw(t, k) {
  const g = k.g, { i, lt, dur } = M.scene(t, CUTS), last = i === CUTS.length - 1;
  M.bg(g, t, i === 2);
  g.save(); M.camera(g, lt); g.globalAlpha = M.fade(lt, dur, last);
  if (i === 0) { M.slam(g, 'СЛОВО', 540, 900, 240, t, 0.2, C.ink); M.rule(g, 140, 960, 800, t, 0.9); }
  // ...
  g.restore();
}
function sound(s) { s.play(0.2, 'drop', 0.18); M.cutSounds(s, CUTS); }
```

## API
- `scene(t, cuts)` → `{i, lt, dur}`; `fade(lt, dur, last)` → прозрачность ухода; `camera(g, lt, cy=960)`.
- `bg(g, t, dark)` бумага или ночь с зерном.
- `slam(g, txt, x, y, size, t, t0, col, o)` удар слова. `o`: `align` ('center'|'left'), `serif`, `w` (жирность), `max` (ширина, по умолчанию 960, ужимает), `a` (прозрачность). y = базовая линия. Возвращает ширину.
- `stack(g, [[txt, col, size, serif], ...], y, t, t0, {x, align, step, lh})` несколько строк ударами подряд, возвращает y под стопкой.
- `rule(g, x, y, w, t, t0, {col, h, d})` черта; `strike(g, x, y, w, t, t0)` зачёркивание.
- `crowd(g, t, t0, {cols, rows, gap, y, r, every, col})` люди-точки растут от центра.
- `gather(g, n, k, cx, cy, {y, col})` n кругов сжимаются в красный (k 0..1, считай `eio`). Для ночной сцены.
- `bricks(g, words, y, t, t0, {w, gap})` слова-кирпичи падают в ряд (до 5 слов по 4–8 букв).
- `note(g, txt, y, t, t0, {size, col})` серая подпись по центру.
- `seal(g, txt, x, y, r, t, t0)` красная печать с одним коротким словом.
- Утилиты: `cl, eo, eio, sp, mix, font(size, w, serif), rr`.

## Рецепт сильного ролика
Хук в первые 0.3 с: одно огромное слово. Дальше спор: «не X» серым с зачёркиванием, «а Y» крупно. Середина: образ из фигур (толпа, сжатие, кирпичи). Финал: лозунг ударами + черта или печать.

## Типовые ошибки
- Длинная фраза в одном `slam`: её ужмёт в мелкий текст. Делите на удары по 1–3 слова.
- Два красных слова в сцене: красный один.
- Фигуры налезают на текст: текст выше y 560 или ниже 1600, фигуры между.
- Пустая последняя секунда: финал держит лозунг и печать до конца.
