# Стиль «Манифест» (MANI)

`MANI` уже подключена, своё не объявляй. Ролик выглядит как запись видоискателя: по углам тонкие уголки и мелкий моно-HUD, в центре красная точка-герой. Резкие склейки строго на долях 128 BPM, смена цвета фона на каждой смысловой сцене, огромные узкие заглавные слова по одному на долю.

## Палитра (`MANI.C`, сняты с оригинала)
- фоны: `night` #0B0D0D, `cream` #ECE7DB, `blue` #2B28EB, `red` #ED391D. Один фон на сцену, сцены чередуют фоны (тёмный → кремовый → тёмный → синий → кремовый → тёмный → красный → кремовый).
- красный #ED391D: только точка-герой, одно ключевое слово сцены (последнее), штампы, статус в метке.
- текст: на кремовом `ink` #0B0D0D, на тёмном и синем `cream`, на красном `ink`. Серый `gray` #8C877B только для облака точек. Чат: свой пузырь `cream`, чужой `bubble` #26252A.
- HUD всегда «противоположного» цвета к фону (`HUDC`): тёмный → #ECEEEE, кремовый → #0C0B08, синий → жёлтый #D4D23A, красный → бирюзовый #1CB0C8. Выбирается сам по имени фона.
- Без градиентов, теней, свечения. Фактура: мелкое зерно (в `bg`), белая вспышка только на ломке.

## Шрифты
- Плакатный узкий (как DIN Condensed): гротеск 700, сжатие `SX` = 0.7 по ширине, ЗАГЛАВНЫЕ, с точкой или «?» в конце. 300–360 px для одного слова, 190–230 px для 2–4 строк. Ширина подгоняется сама (≤ 960).
- Моно (`MONO`): HUD 24 px, метки и счётные подписи 30–38 px, капсом, со знаком подчёркивания и точкой-разделителем «·» (`ВНИМАНИЕ_01 · СТАТУС: ЗАНЯТО`).
- Чат: гротеск 400, 56–58 px.
- Финал: имя гротеск 600, 170 px, обычный регистр; слоган 700, 46 px, капсом, разрядка 0.3 кегля.

## Композиция (вертикаль 1080×1920)
- Центр действия x 540, y 880–1010. Одно слово на базовой линии y ≈ 1010. Фигуры (точка, клетка, замок) в центре, подпись-метка под ними (y ≈ 1220) или над (y ≈ 520).
- Счётчик: моно-подпись над огромной узкой цифрой, внизу по центру (y 1450).
- HUD: уголки 40 px по краям (y 104 и 1694), сверху «● ЗАП  ИМЯ» и «ТАКТ 03/11 · 128 □■□□», снизу номер кадра «К0132» и таймкод. Не масштабируется камерой. В финале гаснет.
- В кадре максимум 2 текстовых блока + HUD. Много пустого фона вокруг.

## Приёмы (функции)
- `dot` красная точка: появляется пружиной в первом кадре, живёт через весь ролик (в клетке, растёт, делится, становится скважиной замка, затем знаком).
- `crosshair` + `leader` + `typed`: прицел вокруг точки и метка, печатаемая по буквам с курсором.
- `cage`: квадрат обводится по часовой за 0.38 с, прутья падают сверху по одному на каждую восьмую; `bend` выгибает прутья, `ring` даёт тонкое кольцо давления, `shake` дрожь. `shards` + `flash`: клетка ломается, осколки разлетаются 0.55 с.
- `word`: одно слово на долю. Входит за 3 кадра с размытием (призраки) и сжатием 1.12 → 1, уходит резкой склейкой (`t1`). Последнее слово серии красное.
- `bubble`, `typing`: чат. Потом `pile` красных штампов в рамках, падают с 1.6 → 1 каждые 0.08 с, накрывают чат кучей (рисовать поверх камеры).
- `split`: точка делится вдвое каждые ~0.2 с (1 → 64), `counter` считает. `cloud`: взрыв в тысячи серых точек под огромным словом, счётчик докручивается до большого числа.
- `network`: красное поле с сеткой линий-созвездий под 2–4 строками `lines`.
- `lock`: замок, скважина = точка; дужка открывается пружиной, замок падает, точка остаётся и уплывает к знаку.
- `logo`: знак (кольцо с разрывом вокруг точки), имя шторкой слева, слоган разрядкой, моно-строка.

## Движение и ритм
- `BEAT` = 0.469 с, `BAR` = 1.875 с. Все склейки на долях: `CUTS = [0, 8, 12, 16, ...].map(n => n * BEAT)`. Сцена 2–4 такта; серия слов по 1 доле.
- Склейки резкие, без наплывов: меняется фон, HUD перекрашивается. Камера `camera(g, lt)`: оседание 1.035 → 1 за 0.3 с и медленный наезд.
- Фигуры движутся ease-out или пружиной, текст без перелёта. Штампы и слова ударом за 3–4 кадра.

## Звуки
`drop` на каждое слово (последнее с pitch 0.8), `woodblock` на склейки, `rim`/`tick` на прутья и прицел, `type` на моно-метки, `wood` на штампы (через один), `pop_high` на деление точки, `error_soft` + `pop_double` на ломку, `odometer` на счётчик, `toggle_on` на замок, `bubble_down` на падение, `marimba` + `success` на финал. Громкость 0.1–0.2.

## Запреты
- Никаких чужих логотипов, адресов и брендов: знак рисуй только `mark` (кольцо и точка), имя придумай.
- Без длинного тире, без эмодзи. Не больше одного красного слова в кадре.
- Не ставь склейку вне доли. Не делай плавных наплывов между сценами.
- Штампы не ниже y 1560 (HUD), слова не длиннее 12 букв на строку.

## Каркас
```js
const M = MANI, C = M.C, B = M.BEAT;
const CUTS = [0, 8, 12, 16].map((n) => n * B), THEME = ['night', 'cream', 'blue', 'cream'];
function draw(t, k) {
  const g = k.g, { i, lt } = M.scene(t, CUTS), th = THEME[i];
  M.bg(g, t, th); g.save(); M.camera(g, lt);
  if (i === 0) { M.cage(g, 540, 900, 460, t, { sq0: 1.8, bars: [2.3, 2.8, 3.0, 3.3, 3.5] }); M.dot(g, 540, 900, 32 * M.sp(t / 0.3));
    M.typed(g, [['ЦЕЛЬ_01', C.cream], [' · СТАТУС: ', C.cream], ['ЗАНЯТО', C.red]], 540, 1220, 32, t, 0.5); }
  if (i === 1) ['ТВОЙ', 'ХОД?'].forEach((s, j) => M.word(g, s, 540, 1010, 330, t, CUTS[1] + j * B, j ? C.red : C.ink, { t1: CUTS[1] + (j + 1) * B }));
  if (i === 2) { /* клетка гнётся и ломается */ }
  if (i === 3) M.logo(g, 'Имя', ['СЛОГАН', 'В ДВЕ СТРОКИ'], 'МАНИФЕСТ 01', 540, 1000, t, CUTS[3]);
  g.restore(); M.hud(g, t, th, { a: i === 3 ? 1 - M.eo((t - CUTS[3]) / 0.5) : 1 });
}
function sound(s) { M.cutSounds(s, CUTS); s.play(CUTS[1], 'drop', 0.18); }
```

## API
- `scene(t, cuts)` → `{i, lt, dur}`; `camera(g, lt, {push, drift, cx, cy})`; `beat(n)`.
- `bg(g, t, theme)`; `hud(g, t, theme, {a, brand, total})`; `flash(g, t, t0, d, a)`.
- `word(g, txt, x, y, size, t, t0, col, {t1, align, max})` (y = базовая линия); `lines(g, [[txt, col, t0]...], cx, cy, size, t, {lh, max})`; `fit`, `cw`.
- `mono(g, txt, x, y, size, col, {align, a, w})`; `typed(g, [[txt, col]...], x, y, size, t, t0, {cps, align})`; `spaced(g, txt, x, y, size, col, {track, w, max})`; `counter(g, label, value, x, y, size, col)`.
- `dot`, `crosshair(g, cx, cy, p, {len, a})`, `leader(g, x0, y0, x1, y1, p, col)`.
- `cage(g, cx, cy, S, t, {sq0, bars, n, bend, ring, shake, lw, col})`; `shards(g, cx, cy, S, t, t0, {n, d})`.
- `split(g, cx, cy, t, times, {r})` → число точек; `cloud(g, cx, cy, p, t, {red})`.
- `bubble(g, txt, x, y, 'r'|'l', t, t0, {size, max})`; `typing(g, x, y, t, t0, t1)`; `stamp(g, txt, x, y, ang, size, t, t0)`; `pile(g, list, t, t0, step)`.
- `network(g, t, t0, {col})`; `lock(g, cx, cy, s, open, {dot, rot})` → `[x, y]` скважины; `mark(g, cx, cy, r, p)`; `logo(g, name, slogan, sub, cx, cy, t, t0)`.
- `cutSounds(s, CUTS, name, v)`.
