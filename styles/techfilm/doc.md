# Техно-фильм (TECH): дорогой продуктовый моушн в космосе
Всё из `TECH`: `const T=TECH,C=T.C;`. Тёмный космос, точная графика по центру, много чёрного воздуха, белый жирный заголовок под ней.

## Правила стиля
1. Палитра. Фон `bg(g,t,mood)` почти чёрный с 2-3 дышащими туманностями; настроение сцены: `night` (фиолет+бирюза), `amber`, `rose`, `blue`, `teal`, `green`, `aura`; кроссфейд `moodAt`. Текст #F4F4F7, моно #8B8E9C, неактивный #4A4D5C, кромки #262838. Акценты `C`: amber pink violet blue cyan green red orange. Градиент `gradFill` только у ключевого слова и слова-названия.
2. Шрифты. Заголовок `title`: гротеск 700, 76-86 px, по центру, 1-2 короткие строки, первая y≈1300. Моно-ярлыки 32-46 px (`mono`, `spaced`).
3. Композиция 9:16. Графика сцены в центре y 380-1180, x 60-1020; заголовок под ней. Максимум 3 текстовых блока.
4. **Мир рисуется, а не подписывается.** О чём говорит озвучка (люди, звери, дома, транспорт, еда, природа, предметы), то и нарисовано: типовые объекты ниже или своя функция из `paint/rr/glow` в том же языке (тонкий контур 2.5 px + полупрозрачная заливка цветом объекта, огни со свечением). Слово, значок, узел графа, карточка-список вместо предмета запрещены. Названное число (семь лодок, два велосипедиста) показывай столько, сколько сказано.
5. **Люди**, если о них речь: `person`/`crowd` нужного возраста, одежды и действия (машут, бегут, читают, танцуют), крупно (h 180-300), не сливаются.
6. **Цвет из текста обязателен**: «розовое солнце», «оранжевые куртки», «синий автобус», «жёлтый кран», «рыжий пёс» = этот цвет у этой части (`c`, `top`, `helmet`...), оттенком палитры, но узнаваемо.
7. **Синхрон**: предмет, человек, действие появляются в момент своего слова (±0,2 с), а не на склейке; счётчик `countTo` доезжает до числа к моменту, когда оно звучит, и стоит на нём. Заголовок держится, пока фраза звучит. Сцена меняется на новой мысли озвучки.
8. **Надписи только по теме**: слова и числа из озвучки, по-русски, коротко. Не выдумывай итоги («07/24»), время, статусы, коды. Интерфейсные элементы оригинала (`plaque` код-функция `узел()`, `orbit`, `starGraph`, `tabs`, `input`, `wave`, `filmstrip`, `tag` ГОТОВО, пилюля «онлайн», `formula`) и шина `bus` только если тема про технику, приложения, данные; в остальных темах их нет. Сквозной герой ролика берётся из темы (человек, животное, место, предмет из озвучки), а не из шаблона.
9. Движение: появление 0,3-0,6 с (`eo5`), пружина `spring`/`back` с малым перелётом; заголовок по словам снизу с размытием. Фон дышит, люди и звери живут (`t`). Элемент превращается в следующий, а не меняется склейкой.
10. Переходы `stage`: уходящая сцена гаснет 0,22 с, новая проявляется из 1,04 за 0,35 с, медленный наезд 2%. Финал по теме, спокойные последние 2 с (город гаснет, герой засыпает). Финал-заставка `implode`+`aura`+`logo`+`tagline` только для продукта или бренда из темы; цена только если она есть в озвучке.
11. Нельзя: эмодзи, чужие логотипы, длинное тире, контурные линии толще 4 px, крупные яркие заливки фона, вспышки и тряска, текст меньше 32 px, всё ниже y 1690, текст поверх рисунка без подложки.

## Типовые объекты (x центр, y земля; `a` прозрачность; `t` оживляет; цвета: имя из `C` или '#rrggbb')
- `person(g,x,y,{h:220,age:'adult'|'kid'|'old',pose,t,dir:±1,skin,hair,hs:'short'|'long'|'bun'|'bald',top,bottom,dress,shoes,helmet,cap,bag,apron,glasses,cane,mouth,book,seat})` → `{head,hand,hand2,top,hip}`. `pose`: stand walk run wave cheer hold point shout sit read dance ride. `seat:true` сидит с любой позой рук (читает, держит); сиденье ниже бедра рисуй сам. Предмет в руку кладётся по `hand`.
- `crowd(g,x0,x1,y,n,{h,pose,t,kids,old,tops,seed,dir,opts:i=>({...})})` разные люди в ряд. Палитры `SKIN HAIR TOPS`.
- Здания: `house(g,x,y,w,h,{c,roof,door,lit})` · `tower(g,x,y,{floors,cols,cw,ch,c,lit:0..1|массив,grow:0..1,seed})` многоэтажка: `lit` доля горящих окон (гаснут по одному), `grow` стройка по этажам, → `{top,l,r,fh}` · `shop(g,x,y,w,h,{c,kind:'shop'|'cafe',sign,signC,awning,lit})` · `school(g,x,y,w,h,{c,sign,flag,roof,lit,t})` (и библиотека) · `win(g,x,y,w,h,on,c)`.
- Природа: `tree(g,x,y,s,{kind:'leaf'|'oak'|'pine',c,trunk,fruit,t})` · `grass(g,x0,x1,y,{c,h,t})` · `leaf(g,x,y,s,{c,rot})` · `leaves(g,t,x0,x1,y0,y1,{n,cols,s})` падают · `hill(g,cx,y,w,h,{c})` · `sea(g,t,y,{x0,x1,h,c,amp,glint:x})` → `wy(x)` высота волны · `ground(g,y,{x0,x1,c})`.
- Небо: `sun(g,x,y,r,{c,rays,t})` · `moon(g,x,y,r,{c})` · `stars(g,t,x0,y0,x1,y1,{n,p:0..1,seed,c})` · `cloud(g,x,y,s,{c})`.
- Транспорт (s длина, `dir`, `t` крутит колёса): `car(g,x,y,s,{c})` · `autobus(g,x,y,s,{c,num:'№3',people})` · `bike(g,x,y,s,{c,rider:{параметры person}|false})` · `boat(g,x,y,s,{c,cabin,motor,run:0..1,crew:[{top,pose}...]})` (y ватерлиния).
- Животные (s длина тела): `dog(g,x,y,s,{c,pose:'stand'|'walk'|'sit'|'sleep',collar})` · `cat(g,x,y,s,{c,pose:'sit'|'walk'|'sleep'})` · `bird(g,x,y,s,{c,t,fly})` · `flock(g,t,cx,cy,n,{rx,ry,s,c})` кружат.
- Улица: `lamp(g,x,y,h,{on:0..1,c,light})` · `garland(g,x0,y0,x1,y1,{on:0..1 по очереди,n,cols,sag,t})` · `board(g,x,y,w,h,['строка',...],{kind:'chalk'|'sign'|'paper',c,size,legs,p:0..1 пишется})` (x,y центр).
- Своё (маяк, кран, прилавок, баян, рыба): `g.beginPath()…; T.paint(g,c,{fa,lw,grad:[y0,y1]})`, `T.floorGlow`, `T.glow`, `T.mix`.

## Интерфейс (для тем про технику)
`plaque(g,s,cx,cy,{size,pop})` · `orbit(g,cx,cy,rx,ry,n,lit,t,{grow,col})` · `starGraph(g,cx,cy,t,p,{r,seed})` · `tabs(g,list,active,y)` · `input(g,cx,cy,w,s,p,t)` · `wave(g,cx,cy,w,h,t,{grow,c1,c2})` · `card(g,x,y,w,h,{edge,bar,halo})` · `tag(g,s,x,y,{color,outline,pop})` · `label` · `progress` · `bus(g,x0,y0,x1,y1,t,{col,lit})` · `link/flow` · `picture(g,x,y,w,h,t,{kind,sunCol})` · `filmstrip` · `formula` · `implode/aura/logo/tagline`. Время: `prog lerp eo eo5 eio back spring vis countTo fmt typed`.

## Звуки стиля
Тихие и точные: tick (счётчик), pop_soft/pop_high (появление), woodblock (событие), bubble, sparkle (цвет, свет), drop или wood (шаг, проезд), success в конце. Склейки `cutSounds(s,CUTS)`. Громкость 0,08-0,17, 25-35 событий на тех же моментах, что события.

## Каркас
```js
const T=TECH,C=T.C,CUTS=[0,14.7,24.6,31.1];
const MOOD=[[0,'night'],[14.7,'rose'],[24.6,'amber']];
function draw(t,k){const g=k.g;T.bg(g,t,T.moodAt(t,MOOD));const S=T.scene(t,CUTS);
  T.stage(g,t,S,()=>[s0,s1,s2][S.i](g,t,S),{last:S.i===CUTS.length-2,cy:800});}
function s1(g,t,S){ // «Над морем встаёт розовое солнце» на 16.4 с
  T.sun(g,540,T.lerp(1000,760,T.eo(T.prog(t,16.4,18))),90,{c:'#F27BA0',t});
  T.sea(g,t,1000,{h:200,c:'blue',glint:540});
  T.title(g,['Розовое солнце.'],{t,t0:16.4,t1:S.t1,y:1300});}
```
