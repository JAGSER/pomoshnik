# Техно-фильм (TECH): дорогой продуктовый моушн в космосе
Всё из `TECH`: `const T=TECH,C=T.C;`. Мелкая точная графика по центру, много чёрного воздуха, белый жирный заголовок под ней.

## Правила стиля
1. Палитра. Фон почти чёрный #050508 (`bg`), поверх 2-3 размытых туманности, которые медленно дышат и плывут; настроение сцены задаёт цвет туманностей: `night` (фиолет+бирюза), `amber`, `rose`, `blue`, `teal`, `green`, `aura` (маджента для финала). Переход настроения кроссфейдом 0,8 с (`moodAt`). Еле видная перспективная сетка из точки схода и редкие звёзды. Текст #F4F4F7, вторичный моно #8B8E9C, неактивный #4A4D5C, кромки #262838, карточки #0F1018 (почти непрозрачные). Акценты: янтарь #F5A646, розовый #EC5A7E, фиолет #9A6BF5, синий #4BA8F5, циан #2FD6F2, зелёный #34E3A0 (успех, поток), красный #F05A6A (обрыв). Градиент янтарь→розовый→фиолет→синий (`gradFill`) только у кода-функции, ключевого слова формулы и слова-логотипа.
2. Шрифты. Заголовок: гротеск 700, 80-86 px, белый, по центру, 1-2 короткие строки с точкой в конце («Одна точка. / Любой прибор.»), первая строка y≈1300. Интерфейс, ярлыки, счётчики: моно 32-46 px (`mono`, `spaced` с разрядкой для КАПСА). Код-функция `узел()` моно 600 градиентом в тёмной плашке (`plaque`, 110-130 px). Формула-подпись: «код · слово» (`formula`, 72-78 px).
3. Композиция 9:16. Графика сцены в центре y 450-1150 (центр y 800), в пределах x 150-930, вокруг пусто. Заголовок под графикой. Сквозная тонкая шина (`bus`) горизонтально через центр графики на всю ширину кадра: базовая линия цвета сцены + бегущие белые штрихи 30/46 px; после «головы» сигнала точечный пунктир. Максимум 3 текстовых блока.
4. Элементы оригинала (все в библиотеке): звезда-граф с кольцами-узлами и бусинами (`starGraph`), орбита из 24 колец вокруг плашки с последовательной подсветкой и ярлыком прибора (`orbit`+`label`), счётчик `приборов 07/24`, вкладки-модальности КАПСОМ с розовой активной (`tabs`), поле ввода с печатью и кареткой (`input`), волна из столбиков синий→фиолет (`wave`, крупная = янтарь→розовый), градиентная картинка-силуэт (`picture`), лента кадров (`filmstrip`), граф карточек на S-кривых с бегущей точкой (`link`,`flow`,`card` с полосой прогресса), плашки-события залитые цветом с тёмным моно-текстом (`tag`: ГОТОВО, ПОТОК), контурные статусы (`tag` с outline: «сеть пропала», «продолжено с 1 285»), пилюля «● онлайн», полоса `progress`, каретка `caret`.
5. Движение. Всё мелкое и точное: появление 0,3-0,6 с ease-out (`eo5`), интерфейс пружиной `spring`/`back` с малым перелётом (плашка 0,86→1). Заголовок по словам снизу с размытием движения (две призрачные копии), шаг 0,09 с, вторая строка через 0,3 с. Фон дышит всегда, штрихи шины едут всегда. Внутри сцены элемент превращается в следующий (поле ввода → волна → картинка → лента), а не меняется склейкой.
6. Переходы (`stage`): мягкие, без вспышек: уходящая сцена гаснет за 0,22 с, новая проявляется из масштаба 1,04 за 0,35 с; камера медленно наезжает на 2% за сцену. Финал: цветные изогнутые штрихи схлопываются в белую точку (`implode`), раскрывается эллипс-аура из цветных точек (`aura`), слово-логотип проявляется по буквам с размытием (`logo`: белая часть + градиентная), под ним градиентная черта, строка-слоган (`tagline`) и внизу контурная плашка + моно-цена.
7. Ритм: сцена 3-4,5 с, одна мысль на сцену, смена сцены на ключевом слове фразы. Прогресс по смыслу: счётчики (`countTo`), «ГОТОВО» на карточках по очереди, «3/3», зелёная шина-прогресс.
8. Нельзя: эмодзи, чужие логотипы и названия, длинное тире, толстые линии (>4 px), крупные яркие заливки фона, свечение у карточек без события (ореол `halo` только у активной/готовой), вспышки и тряска на склейках, текст меньше 32 px, всё ниже y 1690.

## Звуки стиля
Тихие и точные: tick (счётчик, pitch растёт), key_soft/type (печать), click/toggle_on (переключение вкладок), pop_soft/pop_high/pop_double (карточки, метки), woodblock ×3 с растущим pitch (ГОТОВО по очереди), bubble (событие), error_soft (обрыв), success (возврат). Склейки `cutSounds`: marimba_run/kalimba_run 0,12. Финал: magic на схлопывании, ta_da на логотипе, success3 в конце. Громкость 0,08-0,17, 25-35 событий.

## Каркас
```js
const T=TECH,C=T.C,CUTS=[0,3.5,7.5,11.5,15,18.5,21.5,25];
const MOOD=[[0,'night'],[3.5,'amber'],[7.5,'rose'],[11.5,'blue'],[15,'teal'],[18.5,'green'],[21.5,'aura']];
function draw(t,k){const g=k.g;T.bg(g,t,T.moodAt(t,MOOD));const S=T.scene(t,CUTS);
  T.stage(g,t,S,()=>[s0,s1/*...*/][S.i](g,t,S),{last:S.i===CUTS.length-2,cy:800});}
function s0(g,t,S){const l=S.l;
  T.bus(g,0,800,1080,800,t,{col:'violet'});
  T.plaque(g,'узел()',540,800,{size:120,pop:T.prog(l,.05,.55)});
  T.orbit(g,540,800,420,230,24,T.lerp(0,24,T.eio(T.prog(l,.5,3.3))),t,{grow:T.prog(l,0,.8)});
  T.title(g,['Одна точка.','Любой прибор.'],{t,t0:S.t0+.2,t1:S.t1,y:1300,size:84});}
function sFinal(g,t,S){const l=S.l;T.implode(g,540,840,T.prog(l,0,.75));T.aura(g,540,840,480,330,T.prog(l,.65,1.6),t);
  T.logo(g,'Узел','Дом',540,790,T.prog(l,.75,1.9),{size:140});T.tagline(g,'Весь дом в одной точке.',960,T.eo(T.prog(l,1.6,2.1)));}
function sound(s){T.cutSounds(s,CUTS);s.play(.1,'pop_soft',.12);/* ... */}
```
