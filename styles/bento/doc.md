# Стиль «Бенто-блоки» (BENTO)

`BENTO` уже подключена, саму библиотеку заново не объявляй (свои функции для новых предметов писать можно и нужно). Яркий продуктовый ролик: каждая сцена меняет фон (новый цвет заезжает снизу), чёрный жирный заголовок слева, ключевые слова цветом или на наклонной плашке, плитки бенто, телефон со страницей, цепочка «шаг → шаг», чат с агентом, логотип из трёх квадратов и кнопка.

## Правила
1. Палитра только `BENTO.C`: синий `blue` #2E6BFF, коралл `coral` #FF5A4E, жёлтый `yellow` #FFC02E, белый `white`, чернила `ink` #111318, ночь `navy` #141A33 (сцена с чатом), серый фон `gray` #F2F3F5, зелёный `green` (успех), серый текст `muted`.
2. Фоны сцен чередуются: светлые (`gray`, `white`) и цветные (`blue`, `coral`, `yellow`, `navy`). Смена фона только `bg(g, прежний, новый, lt)`. На цветном фоне можно `cubes(g, t)`.
3. Заголовок `head` слева, y ≈ 300, 84–100 px, 900. Одна мысль, 2–5 слов. `*ключ*` синим на светлом, жёлтым или белым на цветном (`o.key`). Без длинного тире.
4. Образы: `tile` (плитки бенто, сетка с зазором 20), `chip` (слово на плашке), `phone` (страница из цветных блоков), `flow` (цепочка карточек с пунктиром), `chat` (реплики с агентом), `sticker` (круглая наклейка), `logo` + `cta` в финале.
5. Ритм: сцена 3–3.5 с, появление пружиной `sp`, уход `out` за 0.25 с. Камера `cam(g, lt, 540, 1000, 0.5)` в каждой сцене.
6. Деньги в рублях, названия свои, без чужих брендов и адресов сайтов.
7. Звуки: `pop_soft` на плитки, `pop_double`/`pop_high` на плашки, `success` на шаги цепочки, `notify` на реплики чата, `ta_da` на финал. Склейки `cutSounds(s, CUTS, 'marimba_run', 0.12)`.

## Каркас
```js
const B = BENTO, C = B.C;
const CUTS = [0, 3, 6.5, 10];
const BGS = [C.gray, C.white, C.blue, C.white];
function draw(t, k) {
  const g = k.g, { i, lt, dur } = B.scene(t, CUTS), last = i === CUTS.length - 1;
  B.bg(g, BGS[Math.max(0, i - 1)], BGS[i], i ? lt : 1);
  if (i === 2) B.cubes(g, t);
  g.save(); B.cam(g, lt, 540, 1000, 0.5); g.globalAlpha = B.out(lt, dur, last);
  if (i === 0) { B.head(g, 'Пять приложений *для одного дела?*', t, 0.1); /* плитки */ }
  // ...
  g.restore();
}
function sound(s) { B.cutSounds(s, CUTS, 'marimba_run', 0.12); }
```

## API
- `scene(t, cuts)` → `{i, lt, dur}`; `out(lt, dur, last)`; `cam(g, lt, cx, cy, k)`; `bg(g, prev, col, lt)`; `cubes(g, t, n)`.
- `head(g, s, t, t0, col, {x, y, size, key, w})` → y под заголовком. `words(...)` как в общих роликах.
- `chip(g, s, x, y, size, bg, fg, p)` слово на плашке, возвращает ширину (для строки из плашек: `x += chip(...)`).
- `tile(g, x, y, w, h, col, label, p, {size, big, bigSize})` плитка; `big` крупная цифра сверху.
- `card(g, x, y, w, h, r)` белая карточка с тенью.
- `phone(g, x, y, s, t, title, [[цвет, текст] ×5])` телефон, блоки выскакивают по очереди (передай `lt - задержка`).
- `flow(g, [[подпись, текст] ×2–4], t, t0, {y, dy, line})` карточки по диагонали с пунктиром.
- `chat(g, [[текст, моё?]], t, t0, {x, y, w, dark})` реплики снизу вверх по очереди.
- `sticker(g, s, sub, x, y, t, t0, col)`; `logo(g, x, y, s)`; `cta(g, s, y, t, t0, col)`.
- Утилиты: `cl, eo, eio, sp, mix, font, rr, cursor, count, layout`.

## Рецепт
Хук: проблема «много всего» плитками, которые улетают вверх. Дальше «одно решение» сеткой бенто, потом по сцене на возможность (телефон, цепочка, чат). Финал на белом: логотип, название, подзаголовок с ключом, кнопка.

## Типовые ошибки
- Ключевое слово того же цвета, что фон (синее на синем): задай `key`.
- Плитки и телефон налезают на заголовок: содержимое ниже y 600.
- Тёмный текст на `navy` или `blue`: там заголовок `C.white`.
- Больше 5 блоков в `phone` не влезает.
