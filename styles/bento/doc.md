# Стиль «Бенто-блоки» (BENTO)

`BENTO` уже подключена, саму библиотеку заново не объявляй (свои функции для особых предметов писать можно и нужно). Яркий плоский ролик: каждая сцена меняет фон (новый цвет заезжает снизу), чёрный жирный заголовок слева, ключевые слова цветом или на наклонной плашке, картинки собраны в плитки бенто со скруглением 28 и мягкой тенью.

## Главные правила (против частых ошибок)
1. **Рисуй, а не подписывай.** Каждый предмет, место, животное из фразы показывается картинкой из «Типовых объектов» внутри плитки `pic`, а не словом на плашке, блоком телефона, карточкой цепочки или пустой плиткой. Особого предмета нет в библиотеке (маяк, кран, баян, рыба, фрукты) - напиши свою функцию из `rr/disc/ell/poly/seg` в том же языке: плоская заливка цветами палитры, скругления, без обводок, тень `gsh`.
2. **Люди рисуются, если о них речь** (жители, рыбаки, продавщица, дети, рабочие, бабушка, внуки, танцующие): `person`/`crowd` нужного возраста, одежды, действия. Названное число (семь лодок, два велосипедиста) показывай столько, сколько сказано.
3. **Названный цвет соблюдай** (розовое солнце, оранжевые куртки, синий автобус, жёлтый кран, рыжий пёс): передай его в параметр объекта; оттенком палитры, если подходит: синий #2E6BFF, жёлтый #FFC02E, коралл #FF5A4E, оранжевый #F28C28, рыжий #E07A2E, розовый #FF8FB1, зелёный #22C55E.
4. **Синхрон**: предмет, человек, действие появляются в момент своего слова (± 0,2 с), а не на склейке; счётчик доезжает к моменту, когда число произносят. Действие из фразы видно (маяк гаснет, окна гаснут, кран поднимает плиту, люди машут). Сцена держится, пока о ней говорят, пустых кадров нет.
5. **Надписи только по теме**, по-русски. Плашка `chip` дополняет картинку (цена, число, имя), а не заменяет её. Телефон `phone`, цепочка `flow`, чат `chat`, курсор, логотип `logo`, кнопка `cta`, кубики `cubes` - только если тема про приложение, сервис, продукт. Иначе финал - итоговая фраза и картинка самой темы.
6. **Герой ролика** выбирается из темы (человек, животное, место, предмет) и возвращается между сценами. Никаких сквозных значков и талисманов не по теме.
7. Не больше 2-3 текстовых блоков в кадре; заголовок не налезает на картинку; ничего важного не режется краем.

## Палитра и фон
- Только `BENTO.C`: синий `blue` #2E6BFF, коралл `coral` #FF5A4E, жёлтый `yellow` #FFC02E, белый `white`, чернила `ink` #111318, ночь `navy` #141A33, серый фон `gray` #F2F3F5, зелёный `green`, серый текст `muted`. Названные в тексте цвета - по правилу 3.
- Фоны сцен чередуются: светлые (`gray`, `white`) и цветные (`blue`, `coral`, `yellow`, `navy`). Смена фона только `bg(g, прежний, новый, lt)`. На тёмном и синем заголовок `C.white`, ключ `C.yellow`.

## Композиция и ритм
- Заголовок `head` слева, y ≈ 240-300, 84-100 px, 900; одна мысль 2-5 слов, `*ключ*` синим на светлом, жёлтым или белым на цветном (`o.key`). Ниже (с y ≈ 560) крупная плитка `pic` 960 px шириной с картинкой сцены или сетка бенто из 2-4 плиток `pic`/`tile` с зазором 20. Всё в x 60…1020, ничего важного ниже y 1700.
- Сцена 3-4 с, склейка на ключевом слове фразы. Появление пружиной `sp`, уход `out` за 0.25 с, камера `cam(g, lt, 540, 1000, 0.5)`. Внутри картинки жизнь: люди идут/машут, колёса крутятся, волны бегут, окна гаснут по одному.
- Деньги в рублях, названия свои, без чужих брендов и адресов сайтов, без длинного тире, без эмодзи.
- Звуки: `pop_soft` на плитки и предметы, `pop_double`/`pop_high` на плашки, `success` на шаги, `notify` на реплики, `ta_da` на финал; склейки `cutSounds(s, CUTS, 'marimba_run', 0.12)`; громкость 0.08-0.15.

## Каркас
```js
const B = BENTO, C = B.C;
const CUTS = [0, 3.2, 7];
const BGS = [C.gray, C.blue, C.white];
function draw(t, k) {
  const g = k.g, { i, lt, dur } = B.scene(t, CUTS), last = i === CUTS.length - 1, T0 = CUTS[i];
  B.bg(g, BGS[Math.max(0, i - 1)], BGS[i], i ? lt : 1);
  g.save(); B.cam(g, lt, 540, 1000, 0.5); g.globalAlpha = B.out(lt, dur, last);
  if (i === 0) { B.head(g, 'Утро *у моря.*', t, 0.1);
    B.pic(g, 60, 560, 960, 900, (g, b) => { B.sun(g, 800, 760, 80, { col: '#FF8FB1' }); B.sea(g, t, b.x, 1100, b.x + b.w, b.y + b.h);
      B.boat(g, 420, 1200, 320, { t, motor: 1, run: B.cl((t - 1.4) / 0.5) }); B.person(g, 400, 1146, { h: 160, shirt: '#F28C28', pose: 'wave', t }); }, { sky: 'dawn', p: B.sp((lt - 0.2) / 0.5) }); }
  g.restore();
}
function sound(s) { B.cutSounds(s, CUTS, 'marimba_run', 0.12); s.play(0.3, 'pop_soft', 0.1); }
```

## API стиля
- `scene(t, cuts)` → `{i, lt, dur}`; `out(lt, dur, last)`; `cam(g, lt, cx, cy, k)`; `bg(g, prev, col, lt)`; `cubes(g, t, n)` (только для продуктовых тем).
- `head(g, s, t, t0, col, {x, y, size, key, w})` → y под заголовком. `words(g, s, x, y, size, t, t0, {align, color, key, weight, w})`.
- `chip(g, s, x, y, size, bg, fg, p)` слово на плашке, возвращает ширину. `tile(g, x, y, w, h, col, label, p, {size, big, bigSize})` цветная плитка с подписью и крупной цифрой. `card(g, x, y, w, h, r, fill)` белая карточка с тенью.
- Только для темы-сервиса: `phone(g, x, y, s, t, title, [[цвет, текст] ×5])`, `flow(g, [[подпись, текст] ×2–4], t, t0, {y, dy, line})`, `chat(g, [[текст, моё?]], t, t0, {x, y, w, dark})`, `sticker(g, s, sub, x, y, t, t0, col)`, `logo(g, x, y, s)`, `cta(g, s, y, t, t0, col)`, `cursor`.
- Утилиты: `cl, eo, eio, sp, mix` (числа), `cmix(a, b, u) dark(c, u) light(c, u)` (цвета), `font, rr, count, layout, rng`.

## Типовые объекты
x - центр, y - земля (у лодки ватерлиния); цвет каждой части - параметр (#RRGGBB); `t` оживляет; `dir` ±1 разворот.
- Плитка-картинка: `pic(g, x, y, w, h, (g, b) => {…}, {sky: 'dawn'|'morning'|'day'|'evening'|'night', bg, p, r})` рисует плитку с тенью, плоским небом или фоном `bg` и клипом; b = {x, y, w, h}.
- Люди: `person(g, x, y, {h: 300, age: 'adult'|'kid'|'old', pose, t, dir, skin, hair, hs: 'short'|'long'|'bun'|'bald', shirt, pants, dress, apron, scarf, helmet, cap, bag, glasses, book, seat, sleep, mouth: 'open', hands})` → `{hand, hand2, head, top}`; pose: stand walk run wave hold point shout sit read dance. Предмет в руку кладётся по `hand`. `crowd(g, x0, x1, y, n, {h, pose, t, kids, old, shirts, seed, opts: (i) => ({…})})` разные люди рядом. Палитры `SKIN` `HAIR` `SHIRTS`.
- Здания: `house(g, x, y, w, h, {wall, roof, door, lit, night})` · `tower(g, x, y, cols, rows, {wall, roof, lit: 0..1 гаснут по одному, grow: 0..1 стройка по этажам, night, cw, ch})` → {x0, top, w, h} · `shop(g, x, y, w, h, {kind: 'shop'|'cafe', sign, awning, awning2, lit, night})` · `school(g, x, y, w, h, {sign: 'Школа'|'Библиотека', flag, hm: [8, 0], lit, night, t})` · `winR(g, x, y, w, h, lit)`.
- Растения: `tree(g, x, y, s, {kind: 'leaf'|'oak'|'pine', col, trunk, t})` · `grass(g, x0, x1, y, {col, h, t})` · `leaf(g, x, y, s, {col, rot})` · `leaves(g, t, x0, x1, y0, y1, {n, cols})` падают.
- Транспорт: `car(g, x, y, s, {col, t})` · `bus(g, x, y, s, {col, num: '№3', people, t})` · `bike(g, x, y, s, {col, rider: {shirt, helmet, …}|false, t})` · `boat(g, x, y, s, {col, stripe, cabin|false, motor, run: 0..1, t})` → {deck}.
- Животные: `dog(g, x, y, s, {col, pose: 'stand'|'run'|'sit'|'sleep', collar, t})` · `cat(g, x, y, s, {col, pose: 'sit'|'walk'|'sleep'})` · `bird(g, x, y, s, {col, fly, t})` · `flock(g, t, cx, cy, n, {r, s})` стая кружит.
- Небо и природа: `sky(g, x, y, w, h, {tone|col})` · `sun(g, x, y, r, {col, rays, t})` · `moon(g, x, y, r)` · `stars(g, t, x, y, w, h, {n, alpha})` · `cloud(g, x, y, s)` · `sea(g, t, x0, y, x1, y1, {col, amp})` · `hill(g, x, y, w, h, {col})`.
- Улица: `lamp(g, x, y, h, {on: 0..1, light})` · `garland(g, x0, y0, x1, y1, {n, on: 0..1, sag, cols})` · `board(g, x, y, w, h, ['Уха 350 ₽', 'Кофе 120 ₽'], {kind: 'chalk'|'white'|'wood', legs, n})` (x, y центр).
- Примитивы для своих предметов: `rr gsh seg disc ell poly glow Tr`.

## Типовые ошибки
- Ключевое слово того же цвета, что фон (синее на синем): задай `key`.
- Картинка налезает на заголовок: плитки ниже y 560.
- Тёмный текст на `navy` или `blue`: там заголовок `C.white`.
- Пустой фон с одним заголовком: в каждой сцене есть картинка по фразе.
