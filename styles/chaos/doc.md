# CHAOS: монолог ИИ от первого лица, кинетическая типографика и глитч

Почти чёрный кадр с зерном, сверху живая строка интерфейса, по центру огромные узкие заглавные, которые меняются почти на каждом слове. Склейки рваные: цветное расслоение и сдвиг полос. Во второй половине фон начинает прыгать: коралл, бумага, голубой.

## Палитра (hex)
- Фон `ink`: #070707 в центре, #020202 по краям (виньетка), зерно 10 %. Основной фон, 60–70 % ролика.
- Фон `coral`: #D96D4D, края #A3533C. Текст на нём #121212 или кость #EEE9DD.
- Фон `paper` (светлая бумага): #EFEBE0, края #9C978D, сильная виньетка. Текст #121212, акцент коралл. Финал.
- Фон `blue`: #7B9EF6, края #4E6796. Текст #121212.
- Текст: кость #EEE9DD, коралл с градиентом слева направо #BF6244 → #DB7352 → #B05A41 (`'coral'`), голубой #7597EB, чернила #121212.
- Моно-пояснения #8E8A84, совсем тихие #6E6A64 / #4A4744.
- Токены: коралл #C9654A, голубой #7597EB, кость #E9E4D8, зелёный #A8D08C, жёлтый #E0BC6E, сирень #C6A0F1, розовый #F8A7B9. Текст в них #121212.
- Штамп красный #E5483C. Двойники глитча: циан #22D3EE, малиновый #FF2D55 (на светлом #2BB8D6 / #E2334F).
- Столбики: первый коралл #C9654A, остальные #6F86D6.

## Шрифты
- Плакатный узкий (`cond`): гротеск 900 со сжатием `SX = 0.62` (`g.scale(0.62, 1)`), только ЗАГЛАВНЫЕ, строки стопкой с шагом 0,84 кегля, почти касаются друг друга. Кегль 250–720 px, каждая строка подгоняется под ширину 960 (`poster`).
- Курсивная антиква (`serif`): `italic 400`, строчные, 50–120 px, интонация и тихие реплики: «ни минутой позже.», «(я считал. дважды.)».
- Жирный гротеск (`bold`, 800): короткая фраза строчными 60–80 px («так что каждый звонок»).
- Моно (`mono`): строчные 34–42 px, пояснения и печать с коралловым блочным курсором; в интерфейсе 25–28 px.
- В одном кадре максимум три шрифта: моно сверху, плакат в центре, курсив или моно под ним.

## Композиция (1080×1920)
- Верхняя строка `hud` всегда: слева название (моно 28, y 196), справа «звоню» и пульсирующая коралловая точка (x 1016); линия прогресса y 238 от x 64 до 1016 (трек #1E1E1E, коралл 5 px); второй ряд y 272: слева счётчик по теме («отложено ×7»), справа часы.
- Центр сцены около y 950–1050. Моно-подводка над плакатом (y 450–560), подпись под ним (y 1290–1400).
- Поля 64 px. Плакат занимает почти всю ширину. Ничего ниже y 1690. Счётчик слов `counter` («03/05») на y 1640 только в пулемётной части.
- Фоновые слои: гигантская полупрозрачная буква (`ghost`, 1,6 %), стена кода с номерами строк (`code: 0.2–0.35`), стена тире (`dashWall`) для перебивки.

## Приёмы (функции)
- `poster(g, u, lines, {y, kind, jit})`: главный приём, 1–3 строки разными цветами (кость + коралл, чернила + коралл).
- `bigNum`: огромное коралловое число с точкой («7.»), под ним курсив в скобках.
- `type`: печать моно по буквам с курсором. `words`: слова по одному, `*ключ*` красится в коралл.
- `tokens`: цветные плашки-токены с «·» и числами под ними (что слышит или считывает герой).
- `bars` + `stamp` + `slider`: рейтинг с процентами, штампы с перелётом («ВРАНЬЁ», «СПИСАНО»), ползунок.
- `win`: окно-файл с тремя точками и печатью строк «ключ: значение». `note`: тёмные карточки-уведомления сеткой 2×3, гаснут и перечёркиваются.
- `calendar`: лист календаря с коралловой шапкой и огромным числом. `wave`: коралловая звуковая волна.
- `storm` + `stormBg(u)`: буквенный шторм из одной буквы с RGB-расслоением, фон мигает коралл/голубой/бумага каждые 0,125 с.

## Движение
- Слово на плакате появляется за 3–6 кадров: вспышка с RGB-расслоением и разломом на полосы (0,2 с), масштаб 1,07 → 1 (ease-out 0,3 с). Без перелёта.
- Плашки, окна, календарь: пружина `spr` с лёгким перелётом. Штамп падает с масштаба 1,9 и дрожит 0,2 с.
- Камера `cam`: после склейки кадр оседает 1,04 → 1 за 0,32 с, потом медленный наезд 0,6 %/с.
- `jit: 1` у плаката: редкие самопроизвольные срывы глитча посреди сцены (для пулемёта слов).
- Фон живёт: зерно мерцает, тень-буква и стена кода медленно ползут.

## Переходы и ритм
- Только склейки, без наплывов. На каждой: `cut(g, u, seed, kind)` 0,14–0,2 с: цветные двойники в полосах и сдвиг полос кадра.
- Ритм: смысловые сцены 1,6–4,5 с, внутри них новое слово каждые 0,3–0,6 с. Во второй половине пулемёт: одно слово на сцену по 0,8 с, фон меняется на каждой склейке (`coral → paper → blue → ink → coral`).
- Финал: светлая бумага, курсив сверху, плакат-вопрос, моно-итог с мигающим курсором; держать ≥ 2,5 с.

## Звук
Сухие цифровые щелчки: склейки `click`/`tick` (`cutSounds`, 0.13–0.16), печать `type`/`key_soft`, плашки `toggle_on`/`pop_soft`, числа `counter`/`tally`, штамп `woodblock` или `rim` (0.18–0.2), ошибка или «нет» `error_soft`, волна `magic`, финал `kalimba_run` + `success3`. Без фанфар и детских звуков.

## Запреты
- Никаких скруглённых мультяшных героев и толстых контуров: здесь герой это голос, текст и интерфейс.
- Не заливать весь ролик цветными фонами: чёрный главный, цветные фоны только вспышками и во второй половине.
- Не больше 3 текстовых блоков; плакат не уже 70 % ширины; без «—», без эмодзи, без чужих названий.
- Зерно и виньетка уже запечены в `bg`, отдельно их не рисовать. `cut` вызывать после сцены и до `hud`.

## Каркас
```js
const L = CHAOS, C = L.C;
const CUTS = [0, 2.6, 4.6, 7.6];
const KIND = ['ink', 'ink', 'storm', 'paper'];
const S = [
  (g, u, t) => { L.type(g, 'вы нажали ввод.', 540, 520, { u, at: 0.05, align: 'center' });
                 L.poster(g, u, [{ s: 'Я', c: 'bone', at: 0.3, size: 260 }, { s: 'РОДИЛСЯ.', c: 'coral', at: 0.8 }], { y: 1000 }); },
  (g, u, t) => { L.tokens(g, [{ s: 'сделай', c: 'coral', n: '7002' }, { s: 'ярко', c: 'blue', n: '433' }], { y: 680, u, at: 0.2 }); },
  (g, u, t) => { L.storm(g, u, 'Р', { row: 'РРРРР' }); },
  (g, u, t) => { L.poster(g, u, [{ s: 'СПАСИБО', c: 'ink', at: 0.1 }], { y: 1000, kind: 'paper' }); }
];
function draw(t, k) {
  const g = k.g, { i, u } = L.scene(t, CUTS, k.duration);
  const kind = KIND[i] === 'storm' ? L.stormBg(u) : KIND[i];
  L.bg(g, kind, t, { ghost: kind === 'ink' ? 'Я' : null, code: i === 1 ? 0.25 : 0 });
  g.save(); L.cam(g, u); S[i](g, u, t); g.restore();
  L.cut(g, u, i + 1, kind);
  L.hud(g, t, { kind, title: 'помощник · сеанс', live: 'эфир', p: t / k.duration, left: 'контекст ' + Math.round(t / k.duration * 100) + '%', right: '00:' + L.pad(t) });
}
function sound(s) { L.cutSounds(s, CUTS, ['click', 'tick'], 0.14); L.sfx(s, [[0.3, 'pop_high', 0.12], [0.8, 'rim', 0.16]]); }
```
