# CHAOS: кинетическая типографика, глитч и плакатные силуэты

Почти чёрный кадр с зерном, огромные узкие заглавные, которые меняются почти на каждом слове, рядом плоские плакатные силуэты того, о чём говорят (люди, дома, море, транспорт). Склейки рваные: цветное расслоение и сдвиг полос. Во второй половине фон начинает прыгать: коралл, бумага, голубой.

## Палитра (hex)
- Фон `ink` #070707 (края #020202, зерно запечено), 60–70 % ролика. `coral` #D96D4D, `paper` #EFEBE0, `blue` #7B9EF6: вспышки, вторая половина, финал.
- Текст: кость #EEE9DD, коралл-градиент `'coral'`, голубой #7597EB, чернила #121212 (на светлых фонах). Моно-пояснения #8E8A84, тихие #6E6A64.
- Токены: коралл, голубой, кость, зелёный #A8D08C, жёлтый #E0BC6E, сирень #C6A0F1, розовый #F8A7B9. Штамп #E5483C. Двойники глитча: циан #22D3EE, малиновый #FF2D55.
- Цвета объектов `L.PAL`: bone ink coral orange ginger(рыжий) red pink yellow gold blue navy sky cyan green dgreen olive lilac brown dbrown grey dgrey paper white sand sea. Любой css-цвет тоже можно.

## Шрифты
- Плакат `cond`: гротеск 900, сжатие 0,62, только ЗАГЛАВНЫЕ, строки стопкой с шагом 0,84 кегля, 250–720 px, подгонка под ширину 960 (`poster`).
- Курсив `serif` 50–120 px: тихие реплики. Жирный `bold` 60–80 px: короткая фраза строчными. Моно `mono` 34–42 px: пояснения и печать с коралловым курсором.
- В кадре не больше трёх шрифтов.

## Композиция (1080×1920)
- Поля 64 px, ничего ниже y 1690. Плакат почти во всю ширину.
- Кадр с объектами: плакат-слово сверху (y 420–700) или снизу (y 1350–1600), картинка в остальной части. Земля/горизонт обычно y 1150–1450.
- Строка интерфейса `hud` необязательна: только если тема про интерфейс, эфир, отсчёт. Её тексты только по теме.
- Фоновые слои по желанию: тень-буква `ghost`, стена кода `code` (строки `codeLines` по теме, без них только полоски), стена тире `dashWall`.

## Приёмы (функции)
- `poster(g, u, lines, {y, kind, jit, seed})`: 1–3 строки разными цветами. `bigNum(g, u, '7.', {y, size})`: огромное число.
- `type(g, text, x, y, {u, at, size, align, col, cursor})`: печать моно. `words(g, text, x, y, {kind, size, col, key, u, at, step})`: слова по одному, `*ключ*` в коралл.
- `tokens`, `bars` + `stamp` + `slider`, `win` (окно-файл), `note(…, {app})`, `calendar`, `wave`, `storm` + `stormBg(u)`: инфо-приёмы для чисел, цен, списков, шума.

## Типовые объекты
Плоские силуэты острыми фигурами, без контуров и лиц. `x, y`: точка на земле (низ, центр); `s`: масштаб; `lt`: время для анимации (обычно `t`); `dir: -1` влево. Цвет любой детали параметром.
- **Появление**: `fig(g, u, at, g => {...}, {x, y, light})` объект вспыхивает RGB-двойниками и полосами, как слово. `light: true` на светлом фоне.
- **Люди**: `person(g, x, y, s, {age:'adult'|'kid'|'old', pose, top, legs, skin:0…3|цвет, hair, hairStyle:'short'|'long'|'bun'|'none', hat:'helmet'|'cap', hatCol, skirt, pack, mouth:0…1, glasses, item, itemCol, text, ph, dir})` → {top, hand}. Взрослый ≈ 290 px при s=1, ребёнок ≈ 190. `pose`: stand walk run wave cheer hold sit read dance ride. `item`: book bag box flower fish sign(+text) или `fn(g, x, y)`.
- **Толпа**: `crowd(g, x0, x1, y, n, s, {pose|poses[], ages[], tops[], bg, lt, t0, stag, each: i => ({...})})`: n человек в ряд без наложений, разная одежда, появляются по одному.
- **Здания**: `house(g, x, y, w, h, {col, roof, door, lit})` · `tower(g, x, y, w, h, {col, floors, cols, lit: 0…1, on, win, p: стройка 0…1, slab})` многоэтажка, окна гаснут по одному при уменьшении `lit` · `shop(g, x, y, w, h, {col, sign:'ТЕКСТ', signBg, signCol, awn, awn2})` · `cafe(…то же, table, cup)` · `school(g, x, y, w, h, {col, sign, flag, lit})`.
- **Природа**: `tree(g, x, y, s, {kind:'oak'|'round'|'pine', col, trunk, lt})` ≈ 400 px · `grass(g, x0, x1, y, {col, h, lt})` · `leaf(g, x, y, r, {kind:'maple'|'oval', col, rot})` · `leaves(g, lt, {x0, x1, y0, y1, n, cols})` листопад · `hill(g, x, y, w, h, {col})`.
- **Небо и вода**: `sun(g, x, y, r, {col, rays, cut: y горизонта, stripes})` · `moon(g, x, y, r, {col, bg, full})` · `stars(g, {x0, x1, y0, y1, n, p: зажигаются 0…1, lt})` · `cloud(g, x, y, s, {col, lt, drift})` · `sea(g, y, {col, col2, y1, amp, lines, lt})` море от y до y1.
- **Транспорт**: `car(g, x, y, s, {col, dir, lt})` ≈ 300 px · `bus(g, x, y, s, {col, num:'3', faces, dir, lt})` ≈ 540 px · `bike(g, x, y, s, {col, lt, rider: {параметры person} | false})` · `boat(g, x, y, s, {kind:'motor'|'sail'|'row', col, stripe, crew: n | [{top:'orange'}…], wake, lt})`.
- **Животные** (≈ 240 px): `dog(g, x, y, s, {col, pose:'stand'|'walk'|'sit'|'sleep', lt})` · `cat(g, x, y, s, {col, pose:'sit'|'walk'|'sleep'})` · `bird(g, x, y, s, {kind:'gull'|'sit', col, lt})` · `fish(g, x, y, s, {col, kind:'flat'})`.
- **Улица**: `lamp(g, x, y, h, {on: 0…1, light})` · `garland(g, x0, y0, x1, y1, n, {on: 0…1, cols, sag})` лампочки загораются слева направо · `board(g, x, y, w, h, [['уха', '350 ₽'], …], {title, p: строки по очереди, bg, frame, legs})` доска мелом · `bench(g, x, y, w)`.
- **Примитивы**: `box`, `poly`, `disc`, `seg(g, pts, w, col)`, `label(g, s, x, y, w, size, col)` узкая надпись. Нет нужного предмета (маяк, кран, баян): собери его сам из 3–8 острых плоских фигур палитры.

## Движение и ритм
- Слово на плакате появляется за 3–6 кадров: вспышка с RGB-расслоением (0,2 с), масштаб 1,07 → 1. Объекты так же через `fig`. Плашки и окна: пружина с лёгким перелётом.
- Камера `cam(g, u)`: после склейки оседает 1,04 → 1, потом медленный наезд. Объекты живут через `lt`: колёса, волны, качание, ходьба.
- Только склейки: `cut(g, u, seed, kind)` 0,14–0,2 с, вызывать после сцены. Сцены 1,6–4,5 с, внутри новое слово или объект каждые 0,3–0,8 с. Во второй половине можно пулемёт слов с прыгающими фонами. Финал ≥ 2,5 с.

## Правила против ошибок
- **Люди**: если в тексте люди (рыбаки, продавец, дети, рабочие, бабушка, танцующие), они нарисованы `person`/`crowd`, в названной одежде и позе, в нужном числе. Слово вместо человека нельзя.
- **Предметы**: всё названное в озвучке (лодка, автобус, дом, пёс, доска, фонарики) нарисовано объектом, а не заменено словом, плашкой или окном-файлом.
- **Цвета**: цвет, названный в тексте (розовое солнце, оранжевые куртки, синий автобус, жёлтый кран, рыжий пёс), соблюдается на самом объекте, ближайшим оттенком `PAL`.
- **Синхрон**: объект или слово появляется в момент своего слова в озвучке (±0,3 с), не раньше и не позже; длинная фраза делится на 2–3 события.
- **Надписи**: только слова и числа из озвучки или прямо из темы. Без придуманных реплик, без английских слов, без чужих подписей, без «-» и эмодзи.
- **Без лишнего шаблона**: интерфейс, стена кода, счётчики, токены, штампы, шторм букв только когда подходят теме. Сквозной герой ролика берётся из самой темы (человек, животное, предмет из озвучки).
- Не больше 3 текстовых блоков; не пустых кадров дольше склейки; ничего не обрезано краем.

## Звук
Сухие цифровые щелчки: склейки `click`/`tick` (`cutSounds`, 0.13–0.16), печать `type`/`key_soft`, появления `pop_soft`/`toggle_on`, числа `counter`/`tally`, штамп `woodblock`/`rim`, волна `magic`, финал `kalimba_run` + `success3`. Без фанфар.

## Каркас
```js
const L = CHAOS;
const CUTS = [0, 2.4, 5.0];
const KIND = ['ink', 'ink', 'paper'];
const S = [
  (g, u, t) => { L.poster(g, u, [{ s: 'УТРО', c: 'bone', at: 0.1 }], { y: 520 });
                 L.fig(g, u, 0.6, g => { L.sea(g, 1300, { lt: t, y1: 1690 }); L.sun(g, 540, 1300, 170, { col: 'pink', cut: 1300 }); }); },
  (g, u, t) => { L.poster(g, u, [{ s: 'ДЕТИ', c: 'coral', at: 0.05 }], { y: 520 });
                 L.crowd(g, 260, 820, 1450, 3, 1, { ages: ['kid'], pose: 'run', each: i => ({ pack: 'yellow' }), lt: u, t0: 0.4 }); },
  (g, u, t) => { L.poster(g, u, [{ s: 'СПАСИБО', c: 'ink', at: 0.1 }], { y: 1000, kind: 'paper' }); }
];
function draw(t, k) {
  const g = k.g, { i, u } = L.scene(t, CUTS, k.duration);
  L.bg(g, KIND[i], t);
  g.save(); L.cam(g, u); S[i](g, u, t); g.restore();
  L.cut(g, u, i + 1, KIND[i]);
}
function sound(s) { L.cutSounds(s, CUTS, ['click', 'tick'], 0.14); L.sfx(s, [[0.1, 'pop_high', 0.12], [0.6, 'pop_soft', 0.12]]); }
```
Нельзя: `Math.random`, `Date`, `document`, `ctx.filter`, `shadowBlur`.
