# SAAS: продуктовый ролик сервиса (индиго + лаванда, карточки интерфейса)
Всё из `SAAS`: `const {C,head,label,body,bgDark,bgLight,card,win,field,btn,chip,tag,steps,score,glass,tabs,cursor,icon,play,...}=SAAS;`

## Палитра
- Тёмный режим: фон #09051B, свечение-пятно #3B1C93 (мягкое, за заголовком), сетка 36 px едва видна, «дождь» мелких моно-строк с цветными точками (только в хуке). Текст #FFFFFF, ключевое слово сиреневым #9A80F8, подписи #B3ABD6, моно-мелочь #8E86B5.
- Светлый режим: фон #ECEAF4, лавандовое свечение сверху #D8CCFA, сетка 48 px. Текст #0C0624, вторая строка заголовка серо-фиолетовая #6B6488, надзаголовок фиолетовым #5B2EEB.
- Акцент: фиолет #5B2EEB (кнопки, пройденные шаги, бегущие точки), значок сервиса градиентом #6D3BFF → #4B1FD6. Зачёркивание красным #E8304A.
- Метки статуса (`tag`): green #17A35A/#DEF6EA, orange #B55F00/#FFF1DC, red #C8233F/#FDE6EA, blue, violet, pink, grey; на тёмном яркие: #3DDC84, #F5A524, #FF5470, #6E8BFF, #A98BFF, #F05B9C.
- Тёмное окно-терминал #120B2E, строки #1A1340. Стеклянные карточки rgba(30,22,68,0.78) с цветным свечением в правом верхнем углу.

## Шрифты
- Заголовки: гротеск 800 (`head`), плотный трекинг -0.045 em (рисуется по буквам, спрайты слов в кэше), 110-170 px, межстрочный 1.0. Точка в конце фразы обязательна («Шесть ответов.»).
- Двухцветный заголовок: строка 1 чёрная/белая, строка 2 серая (`grey:[1]`), или ключевое слово сиреневым/фиолетовым (`key`), или слово зачёркнуто красной линией (`strike`, `strikeAt`).
- Надзаголовок: моно капсом 700, 20-24 px, разрядка 0.22 em, фиолетовый (`label`).
- Данные, адреса, суммы, время, шаги: моно (`MONO`). Подписи и кнопки: гротеск 400-700 (`FT`).
- Деньги: `rub(1248)` → «1 248 ₽» (неразрывный пробел).

## Композиция (9:16)
- Светлые сцены: вкладки-таблетки y 170 (`tabs`), надзаголовок y 250-285, заголовок y 290-500 слева от x 60, под ним крупно карточка/окно 960 px шириной с y 620-650 до ~1500. Тень карточки лавандовая (спрайт).
- Тёмные сцены: заголовок по центру сверху (y 180) + подпись, ниже сетка 2×3 стеклянных карточек (470×345, зазор 20); или список пунктов с плитками-галочками слева (`checkTile`), текст 88-96 px.
- Хук: тёмный фон с «дождём», маленький значок + моно-название вверху (y 300), заголовок 150-170 px по центру в 2-3 строки.
- Финал: значок-плитка влетает с поворотом в центр, сдвигается влево, из-за него выезжает название 150 px, ниже слоган 72 px с ключевым словом сиреневым и белая таблетка-кнопка со свечением, под ней моно-подпись.
- Мелкие спутники карточки: тёмный чип времени «0,7 с» на правом верхнем углу, белый чип снизу-слева («0 ₽ лишнего»).
- Всё в x 60…1020, ничего важного ниже y 1690.

## Приёмы
- Поле ввода с печатью моно (`field` + `typeOn`, ~30 знаков/с) и фиолетовая кнопка справа; курсор (`cursor` + `path`) едет к кнопке и нажимает; кнопка пишет «Проверяю…».
- Шкала проверки из точек-этапов (`steps`), линия заливается, у текущей точки кольцо.
- Большой счёт (`score`) «82 → 85 /100» с мини-полосками вклада (`minibars`), зелёная метка «в норме».
- Окно с тремя точками и моно-заголовком (`win`), светлое или тёмное (`dark:1`); внутри строки-записи, сегментная полоса (`segbar`), плитки итогов (`stat`), кнопка с иконкой.
- Схема связей: значок сервиса в центре, белые узлы (`node`) с пунктирами (`link`) и бегущими точками.

## Движение
- Слова заголовка встают из-под маски по одному, шаг 0,07-0,16 с, ease-out без перелёта. Линия зачёркивания тянется слева направо за 0,28 с.
- Карточки и окна въезжают снизу на 110 px с лёгким перелётом (`rise`), чипы и метки всплывают масштабом (`pop`), стеклянные карточки каскадом по 0,1 с.
- Камера: плавный наезд 2-4% за сцену (`cam`). Фон тёмных сцен живёт «дождём» строк.

## Переходы (`play` + CUTS)
- `circle`: белый шар прилетает справа на ключевое слово за 0,6 с до склейки, затем раскрывается кругом и открывает светлую сцену (из тёмного хука в интерфейс).
- `panel`: тёмная сцена выезжает снизу панелью с круглыми верхними углами (r 90), старая слегка уменьшается.
- `fade`: растворение 0,45 с, старая сцена чуть приближается (смена режима фона, финал).
- `tab`: быстрое растворение 0,32 с; активная таблетка во вкладках переезжает (`from`) на новый пункт.

## Ритм
Сцена 2,6-3,4 с, склейка на ключевом слове фразы. Порядок как в оригинале: тёмный хук → светлая карточка с проверкой → тёмная сетка ответов → светлые вкладки (2-3 сцены) → тёмный итог списком → логотип. Последние 2 с - финальный кадр.

## Звуки
Склейки `cutSounds` (marimba_run / kalimba_run, на вкладках toggle_on, финал magic). Печать type, нажатие click, шаги tick, счёт counter/tally, карточки pop_soft/pop_high, шар bubble, зачёркивание и дубль error_soft, успех success/success3, финал sparkle → ta_da. Громкость 0.1-0.18.

## Запреты
Без чужих логотипов, названий и адресов сайтов; без длинного тире; без эмодзи; без свечения у карточек интерфейса (только мягкая тень); заголовок не бывает тонким или с обычным трекингом; не больше 2-3 текстовых блоков в кадре; деньги в рублях.

## Каркас
```js
const {C,head,label,bgDark,bgLight,win,tabs,tag,rise,prog,cam,play,sfx,cutSounds}=SAAS;
const TR={type:'circle',x:540,y:1000,r:72};
function s0(g,lt,t,S){bgDark(g,t,{rain:1});g.save();const z=cam(g,lt,S.dur,{z:0.04,cy:900});
  const a=head(g,['Стоп','лишнему'],540,640,{size:160,dark:1,lt,strike:'лишнему',strikeAt:0.9});
  const b=head(g,['до кассы.'],540,640+a.h,{size:a.sz,dark:1,lt,delay:1.2,key:['кассы.']});
  const k=b.box['кассы'];if(k){TR.x=540+(k.x+k.w/2-540)*z;TR.y=900+(k.y+a.sz/2-900)*z;}g.restore();}
function s1(g,lt,t,S){bgLight(g,t,{cy:1050});g.save();cam(g,lt,S.dur,{cy:1050});tabs(g,['Чек','Месяц'],1,170,lt,{from:0});
  label(g,'За месяц',60,285);head(g,['Весь месяц','за минуту.'],60,325,{align:'left',size:116,grey:[1],lt});
  g.save();rise(g,prog(lt,0.15,0.6));const b=win(g,60,620,960,880,'отчёт');tag(g,'готово',b.x,b.y+60,'green');g.restore();g.restore();}
const CUTS=[[0,s0],[2.6,s1,TR]];
function draw(t,k){play(k.g,t,CUTS,k.duration);}
function sound(s){cutSounds(s,CUTS);sfx(s)(2.0,'bubble',0.14);}
```
Адреса сайтов и ссылки в кадр не ставь.
