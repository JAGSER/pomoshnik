# Стиль PLK: плакат-эссе

Редакционный документальный ролик-эссе: неторопливый, много пустоты, мысль за мыслью. Три фона (почти чёрный со звёздной пылью и созвездиями, тёплая кремовая бумага с сильной виньеткой, сплошной красный в финале), узкий жирный гротеск капсом, антиква в цитатах, тонкий моно-HUD по краям кадра. Тема любая: город, деньги, наука, здоровье, история.

## Палитра (`PLK.C`)
- Тёмный фон #0A0A12 (к краям #05060A), бумага #ECE6DD (к углам #A39F98, виньетка заметная), красный фон #E1372A (края #8E211B).
- Текст на тёмном: крем #EEE5DA. Текст на бумаге: тушь #0B0A10.
- Акцент 1: красный #E2362B (ключевое слово, точка кикера #CD2F28, шар, стопка, зачёркивание).
- Акцент 2: охра-золото #E2AC4C (ключевое слово на тёмном, узлы созвездия, фронтон, кикер сцены-вывода). Тусклое золото #5B4529 только для больших кавычек.
- Маркер подсветки #EAC984 (только на бумаге, под 1–3 словами цитаты).
- Серые столбцы #BDB8B1 / #86817D. Фишки: красный, синий #3F67B0, жёлтый #E3B240, зелёный #4E8C69, фиолетовый #7A5C8A, чёрный.
- Других цветов нет. Градиентов на фигурах нет, свечение только у красного шара и под курсивной цитатой-угрозой.

## Шрифты
- Заголовок: жирный гротеск 700, сжатый `scale(0.72,1)` (как DIN Condensed), капс, 130–240 px, межстрочный 1.02. `head()` сам уменьшает кегль под ширину 920 px.
- Кикер: тот же гротеск 700, 22–32 px, капс с разрядкой 0.3–0.5 em (рисуется по буквам), красный квадратик слева над строкой.
- Цитата: антиква `"Liberation Serif","Times New Roman",Georgia,...` 56–72 px прямым, ключевые слова красным; курсив той же антиквы 58–90 px для подзаголовка и финальной строки.
- Моно `DejaVu Sans Mono` 17–22 px капс с разрядкой: HUD, атрибуции («ИМЯ · ИСТОЧНИК · ГОД»), подписи графиков, счётчики.

## Композиция (вертикаль 1080×1920)
- Поля: текст в x 80…1000, блоки слева (x 80–100) или по центру. Одна мысль в кадре: кикер + заголовок, или цитата + атрибуция, или график + заголовок.
- Заголовок y 420–1100, крупный объект (циферблат, график, доска, колонны) занимает середину кадра, под ним подписи. Ниже y 1690 ничего.
- HUD всегда: уголки по углам (y 52 и 1688), сверху слева метка ролика, справа таймкод «ТК 00:00:сс:кк», снизу слева глава «03 - НАЗВАНИЕ», справа «КД 0000» и тонкая шкала прогресса.
- Огромные контурные цифры (год, число) фоном справа на бумаге, линия 2 px, 16 % туши.

## Приёмы (функции `PLK`)
- `head` буквы встают из-под базовой линии с поворотом 0.3 рад (маска по строке), шаг 0.022–0.05 с; уход (`out`) буквы падают вниз. Смена слова = `out` старого + `t0` нового + малый глитч.
- `kicker`, `mono` (печать по буквам), `small`, `quote` (слова проявляются из «размытия», `acc` красным, `hl` маркер, `marks` большие кавычки, `bar` красная вертикальная линия слева), `attrib`, `strike` (красное зачёркивание 8 px), `rule`.
- Фоны: `bg(g,"dark"|"paper"|"red")`, `dust` (мерцающие пылинки), `constellation` (узлы-люди и связи, золотые узлы вспыхивают на `gold`), `rings` (концентрические круги), `dial` (циферблат с засечками и красной точкой), `glow`, `ball` (красный светящийся шар).
- Графика: `timeline` (годы, точки, подписи), `bars` (серый график; `gather` собирает его в красную стопку), `crane` (крюк опускает последний блок), `venn` (два круга со стрелками -> красная линза), `chess` (доска и фишки: из хаоса в круг/ряды, со шлейфом), `columns` (колонны встают по одной, фронтон золотым контуром), `outlineNum` (контурные цифры-одометр).

## Движение
- Медленно и мягко: появление 0.4–0.6 с `easeOut5`, без перелёта у текста; колонны и точки на `spring`. Уход в 1.4 раза быстрее.
- Камера: наезд 0.6 %/с и оседание после склейки (`camera`). Фон живёт: пылинки мерцают и плывут вверх, созвездие дрейфует, круги расходятся.
- Сцена 3.5–4.5 с, внутри одна смена (слово, зачёркивание, сборка графика).

## Переходы (`PLK.iris / stairs / withGlitch`)
- `iris`: красный шар растёт и заливает кадр, после склейки тёмные кольца расходятся и открывают новую сцену. Для начала и для входа в красный финал (`toRed`).
- `stairs`: «пиксельная лестница» с тремя серыми ступенями на кромке, смена тёмный <-> бумага.
- `withGlitch`: сдвиг полос + RGB-кант на тексте, 0.2–0.35 с; на склейках внутри одного фона и при смене слова.
- Не больше 3 типов переходов, никаких наплывов «всё плавно проявляется».

## Ритм и звук
- Склейки на ключевом слове фразы, 1 мысль = 1 фраза субтитров.
- Звуки (под музыку, 0.08–0.16): woodblock/wood с pitch 0.6–1.1 на заголовки, type на моно-печать, kalimba на курсивную строку, pop_soft/pop_high на точки таймлайна, counter/abacus на график, drop на крюк, toggle_off на зачёркивание, sparkle на маркер и золотые узлы, wood по одному на колонну, magic на фронтон, success3 + fanfare_soft в финале. Склейки: `cutSounds` (iris: bubble_down + marimba_run pitch 0.6, stairs: kalimba_run 0.75, glitch: click + toggle_off).

## Запреты
- Без «—», без эмодзи, без чужих брендов и реальных имён в цитатах (автор вымышленный).
- Не больше 2–3 текстовых блоков; не ставить заголовок по центру без HUD и фона-фактуры; красный фон только в финале; золото и красное не в одном слове.

## Каркас
```js
const P=PLK,C=P.C,pr=P.prog;let CUTS=null;
const BGS=["dark","paper","red"];
function s0(g,lt){P.dust(g,lt);P.dial(g,540,860,400,pr(lt,0,2.5));P.head(g,"СЛОВО,",{x:540,y:900,size:240,align:"center",lt,t0:0.3});}
function s1(g,lt){P.kicker(g,"КИКЕР",{x:100,y:470,col:C.ink,lt,t0:0.1});P.head(g,"ЗАГОЛОВОК|ВТОРАЯ",{x:80,y:660,size:170,col:C.ink,acc:["ВТОРАЯ"],lt,t0:0.3});}
function s2(g,lt){P.head(g,"ИТОГ.",{x:540,y:900,size:220,align:"center",col:C.cream,lt,t0:0.15});}
const SC=[s0,s1,s2];
function draw(t,k){const g=k.g;if(!CUTS)CUTS=P.cutsFromSubs(k);const {i,lt}=P.scene(t,CUTS),kind=BGS[i];
  P.bg(g,kind);
  P.withGlitch(g,t,[],kind,()=>{P.camera(g,lt);SC[i](g,lt,k);P.camEnd(g);});
  P.stairs(g,t,CUTS[1],"dark","paper");P.iris(g,t,CUTS[2],{toRed:1});
  P.hud(g,t,{theme:kind,chapter:"01 - ГЛАВА",dur:k.duration});}
function sound(s){const c=PLK.cutsFromSubs(s);PLK.cutSounds(s,c,[null,"stairs","red"]);s.play(c[0]+0.3,"woodblock",0.12,{pitch:0.7});}
```
