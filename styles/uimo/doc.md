# UIM: кинетика «одно слово на сцену» + продуктовый интерфейс

Бодрый продуктовый ролик-перечисление: каждую долю (около 1 с) новое огромное слово строчными с цветной точкой в конце на новом сплошном фоне, под словом один маленький элемент интерфейса, курсор кликает. Середина ролика - окно кабинета и чат-помощник крупным планом, финал - слово и зелёная плашка «онлайн». Чужие бренды не рисуй: знак слева внизу свой (`badge`, «окошко» в круге), название продукта придумывай под тему.

## Палитра (hex, пипеткой по образцу)
- Фоны сцен (`TH`): светлый `#F4F3F6`, чернила `#090911`, синий `#424AE5`; редкие акценты для смены фона на долях: бирюза `#0E9183`, оранжевый `#FD591F`, лайм `#D8F99C`. Экран чата `#F8F9FC`.
- Точка в конце слова: синяя `#424AE5` на светлом, `#6C72FE` на чёрном, чёрная на синем/оранжевом/лайме, жёлтая `#F8D877` на бирюзе.
- Интерфейс: белые карточки с мягкой тенью, рамки `#E1E3EA`, тёмный сайдбар `#0F172B`, график и кнопка кабинета `#12957F`, подсказки-шаги синие `#424AE5`, успех: фон `#EAFBF1`, точка `#12A150`, текст `#0B7A3B`. Подпись в углу `#748395` (на цветном фоне белый 74%).
- Без градиентов-фонов, без свечения, без зерна. Чистые плоские цвета.

## Шрифты
- Слово: жирный гротеск 800 (`word`), плотный трекинг -0.04 em, строчные, 175-300 px, ширина до 940 (сама уменьшается по measureText). Одно-два слова, максимум 2 строки (`'всегда\nна связи'`).
- Смена шрифта на доле: `kind:'serif'` (антиква 400, на бирюзе), `kind:'cond'` (узкий через scale 0.72, на лайме). Только в приёме «смена фона».
- Подпись в левом верхнем углу: ВЕРХНИЙ РЕГИСТР, 26 px, вес 600, разрядка 0.3 em, формат «ТЕМА · УТОЧНЕНИЕ» (`caption`), справа тонкая иконка 40 px.
- Интерфейс: гротеск 400-700, сообщения 44 px, подписи карточек 28 px, цифры 50-66 px жирные.

## Композиция 1080×1920
- Слово: центр по y 840 (`WY`), интерфейс под ним y 1160 (`UY`), подпись y 150, знак `badge` (118, 1612). Ниже 1690 ничего.
- Сцены с окном: слово 175 px сверху (y 300), окно `windowFrame` x 70…1010, y 440…1510, внутри `dash`.
- Чат: белая панель на `#F8F9FC` во весь кадр, камера крупно (1.16 → 1.0) и сползает за новым сообщением. Знак в чате и в печати не показывай.
- Не больше 2-3 текстовых блоков: слово + один элемент интерфейса (+ подсказка).

## Приёмы (функции)
- `word(g, text, cx, cy, {u, color, dot, enter, from, kind, size})`: появление из размытия движения (`smear`, 0.22 с, слева или справа `from:±1`), `pop` (масштаб 0.88→1, для слова с `burst`), `none` (жёсткая смена на доле). Точка выпрыгивает пружиной через 0.14 с.
- `typeWord`: печать по буквам с кареткой на чёрном («знакомьтесь,|»), перед словом-раскрытием.
- Элементы под словом: `chips` (время, выбор), `tip` (синяя подсказка «1 из 4» + «Далее»), `btn` (белая или тёмная кнопка), `field` (поле с суммой/ссылкой и синей кнопкой, после клика «Оплачено» с галочкой), `stars`, `miniCards` (три карточки с цифрами или сетка 2×2), `qa` (вопрос клиента + печатный ответ с жирной частью), `status` (зелёная плашка «… онлайн · 23:40» с пульсом).
- Кабинет: `windowFrame` + `dash` (сайдбар, цифры считают `countUp`, линия графика растёт, точка с подписью суммы `hover`), `player` (вуаль + кнопка play = «или видео»).
- Чат: `chat(g, x, y, w, msgs, u)`: бот печатает 45 зн/с (перед этим три точки), клиент - белые пузыри справа, карточка-действие с синей рамкой и синим квадратом-иконкой.
- Курсор: `cursor` + `path` (inOut между ключами) + `press` + `ring` (два кольца на клик). Курсор есть в каждой сцене с действием.
- Слово садится в белую карточку (как «embed»): карточка пружиной за словом, слово становится чёрным, точка синей.
- `burst`: разлёт коротких штрихов вокруг слова при появлении ключевого героя.

## Движение и ритм
- Склейка каждые 1-1.6 с ровно на долю, сцены с окном и чатом 2.4-3.2 с. Жёсткие склейки без шторок: смена фона = переход.
- Внутри сцены: слово 0-0.22 с, интерфейс пружиной с 0.12-0.3 с (каскад 0.06-0.08), курсор приходит к 0.4-0.8 с и кликает, результат клика сразу (смена цвета, подсказка, галочка).
- `cam`: оседание 1.035 → 1 за 0.45 с после склейки + медленный наезд. Подпись и знак не двигаются.
- Смена фона на долях (`cycle(u, 0.4, 4)`): то же слово, новый фон и шрифт каждые 0.4 с (синий гротеск → бирюза антиква → оранжевый → лайм узкий). Один раз за ролик.
- Наезд в точку `zoomInto`: последние 0.3 с сцены камера влетает в точку, её цвет заливает кадр, следующая сцена на фоне того же цвета.
- Интерфейс с лёгким перелётом (`spr`), текст без перелёта (`eo`).

## Звуки
`wood` на склейках (`cutSounds`, высота чередуется), `click` на каждом клике курсора, `pop_soft`/`pop_high` на появление пилюль и подсказок, `notify` на напоминание, `toggle_on` на переключение, `success` на «Оплачено»/«готово», `bubble` на сообщения чата, `type` на печать, `counter` на счёт цифр, `tick` на смену времени, `magic` на появление помощника, `marimba_run`/`kalimba_run` на вход в окно и чат, `fanfare_soft` + `success3` на финал. 0.1-0.16, 25-35 событий.

## Запреты
Без чужих логотипов и маскотов, без эмодзи, без «—». Не больше одного слова (двух строк) на сцену. Не ставь два элемента интерфейса рядом с подсказкой, если они перекрываются: прячь подсказку (`globalAlpha`) до появления следующего. Антиква и узкий шрифт только в смене фона. Не смешивай больше трёх фонов подряд вне приёма `cycle`. Последние 2 с: финальное слово + плашка `status` + строка с названием, без пустоты.

## Каркас
```js
const U = UIM, C = U.C, TH = U.TH;
const CUTS = [0, 1.5, 2.5, 3.5, 6, 9];
const THEMES = ['light', 'ink', 'blue', 'light', 'light'];
const CAPS = [['ТЕМА · КЛИК', 'cursor'], ['ТЕМА · ДЕТАЛЬ', 'bell'], ['ТЕМА · ЕЩЁ', 'swap'], ['КАБИНЕТ', 'chart'], ['ИТОГ · 24/7', 'clock']];
function s0(g, u, th) {
  U.word(g, 'слово', 540, 840, { u, color: th.ink, dot: th.dot });
  U.chips(g, 540, 1160, ['10:00', '11:30', '14:00'], u >= 0.8 ? 1 : -1, u - 0.15);
  const q = U.path(u, [[0.25, 960, 1560], [0.7, 560, 1180], [1.5, 570, 1190]]);
  U.ring(g, 552, 1170, U.prog(u, 0.8, 1.25), 'rgba(66,74,229,0.8)'); if (u > 0.25) U.cursor(g, q[0], q[1], U.press(u, 0.8));
}
// s1..s4 так же: слово + один элемент; окно: U.windowFrame + U.dash; финал: U.word + U.status
const SC = [s0, s1, s2, s3, s4];
function draw(t, k) {
  const g = k.g; U.tex(); const S = U.scene(t, CUTS), th = TH[THEMES[S.i]];
  U.bg(g, th); g.save(); U.cam(g, S.u); SC[S.i](g, S.u, th, S, t); g.restore();
  U.caption(g, CAPS[S.i][0], th, 9, CAPS[S.i][1]); U.badge(g, th, t);
}
function sound(s) { U.cutSounds(s, CUTS); U.sfx(s, [[0.8, 'click', 0.15], [0.95, 'pop_soft', 0.12], [6.2, 'success3', 0.13]]); }
```
