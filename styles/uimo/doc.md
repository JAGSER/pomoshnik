# UIM: кинетика «одно слово на сцену» + продуктовый интерфейс

Бодрый ролик-перечисление: каждую долю (1-3 с) новое огромное слово строчными с цветной точкой в конце на новом сплошном фоне, под словом один элемент: **картинка** (`pic` с типовыми объектами) или элемент интерфейса. Плоские чистые цвета, белые карточки с мягкой тенью, жёсткие склейки на долях.

## Главные правила (против частых ошибок)
1. **Рисуй, а не подписывай.** Каждый предмет, место, животное, человек из фразы показывается картинкой в `pic` (типовые объекты ниже), а не словом в кнопке, пилюлей, подсказкой или пустой карточкой. Нет нужного предмета (маяк, кран, баян, рыба, фрукты) - нарисуй свою функцию из `box/disc/ell/poly/seg` в том же языке: плоская заливка, скругления, без обводки, 1-2 тона одного цвета.
2. **Люди рисуются, если о них речь** (жители, рыбаки, продавщица, дети, рабочие, бабушка, внуки, танцующие): `person`/`crowd` нужного возраста, одежды и действия. Названное число (семь лодок, два велосипедиста) показывай ровно столько.
3. **Названный цвет соблюдай** (розовое солнце, оранжевые куртки, синий автобус, жёлтый кран, рыжий пёс): передай его в параметр объекта, оттенком палитры: синий `#424AE5`, оранжевый `#FD591F`, жёлтый `#F8D877`, рыжий `#D9822B`, розовый `#F7A3C0`.
4. **Синхрон**: слово-заголовок, предмет, человек, действие появляются в момент своего слова в озвучке (± 0,2 с). Время слова внутри фразы считай пропорционально числу букв. Счётчик доезжает до числа, когда его произносят. Пустых кадров нет: сцена держится, пока о ней говорят.
5. **Надписи только по теме ролика**, по-русски. Интерфейс (курсор, кнопки «Купить/Оплачено», подсказки «1 из 4», окно кабинета, чат, плашка «онлайн», знак `badge`) только если тема про продукт или сервис. В ролике про город, природу, историю их нет: под словом картинка, цифры - `miniCards`/`chips` с фактами из текста.
6. **Сквозной герой** выбирается из самой темы (человек, животное, место, предмет) и возвращается между сценами. Подпись `caption` и знак `badge` не обязательны: подпись только с содержанием по теме (время дня, место), знак только для темы-сервиса.

## Палитра (hex)
- Фоны сцен (`TH`): светлый `#F4F3F6`, чернила `#090911`, синий `#424AE5`; акценты: бирюза `#0E9183`, оранжевый `#FD591F`, лайм `#D8F99C`, бумага `#F8F9FC`.
- Точка в конце слова: синяя на светлом, `#6C72FE` на чёрном, чёрная на синем/оранжевом/лайме, жёлтая `#F8D877` на бирюзе.
- Интерфейс: белые карточки с тенью, рамки `#E1E3EA`, сайдбар `#0F172B`, график `#12957F`, подсказки синие, успех `#EAFBF1`/`#12A150`/`#0B7A3B`, подпись `#748395`.
- Небо в `pic` плоскими полосами (`sky`): dawn розовое, morning/day голубое, evening сиреневое, night тёмно-синее. Без градиентов и свечения.

## Шрифты
- Слово (`word`): гротеск 800, трекинг -0.04 em, строчные, 175-300 px, ширина до 940 (подгоняется). До двух строк (`'всегда\nна связи'`). Над картинкой 150-190 px.
- Смена шрифта `kind:'serif'` (бирюза), `kind:'cond'` (лайм) только в приёме `cycle`.
- Подпись `caption`: ВЕРХНИЙ РЕГИСТР 26 px, разрядка, «ТЕМА · УТОЧНЕНИЕ», тонкая иконка справа.
- Интерфейс: 400-700, сообщения 44 px, подписи 28 px, цифры 50-66 px.

## Композиция 1080×1920
- Слово + элемент: слово y 840 (`WY`), элемент y 1160 (`UY`).
- Слово + картинка: слово y 250-300 (150-190 px), `pic(g, 60, 420, 960, 1180, …)`. Можно наоборот: картинка сверху, слово внизу y 1500.
- Окно/чат (тема-сервис): слово y 300, `windowFrame` x 70…1010, y 440…1510.
- Всё в x 60…1020, ничего важного ниже y 1690. Не больше 2-3 текстовых блоков.

## Приёмы (функции)
- `word(g, text, cx, cy, {u, color, dot, enter:'smear'|'pop'|'none', from:±1, kind, size})`: вылет из размытия 0.22 с, точка пружиной через 0.14 с. `typeWord` - печать с кареткой. `prep([[text, opts]])` - заранее собрать спрайты слов.
- Под словом: `chips(g, cx, cy, items, sel, u)`, `tip(g, x, y, w, title, step, u, {btn})` (step и btn необязательны), `btn(g, cx, cy, label, o)`, `field(g, cx, cy, w, label, btnLabel, u, {done, icon})`, `stars`, `miniCards(g, x, y, w, [{l, v, d, ok}], u, {cols})`, `qa`, `status(g, cx, cy, text, u, t)`.
- Сервис: `windowFrame(g, x, y, w, h, title)` + `dash(g, R, {u, brand, nav, active, title, btn, stats, series, hover, hoverU, hoverLabel, chartTitle})`, `player(g, R, u, {time})`, `chat(g, x, y, w, msgs, u)`, `cursor` + `path` + `press` + `ring`.
- Слово садится в белую карточку (`card` пружиной за словом). `burst` - разлёт штрихов при появлении героя. Все тексты - только из параметров.

## Типовые объекты
x - центр, y - земля (у лодки ватерлиния); цвет каждой части - параметр; `t` оживляет (шаг, волны, колёса, хвост). Рамка: `pic(g, x, y, w, h, (g, b) => {…}, {sky:'dawn'|'morning'|'day'|'evening'|'night'|{top,bot}, r, border})`, внутри b = {x, y, w, h}, всё обрезается по карточке.
- Люди: `person(g, x, y, {h:260, age:'adult'|'kid'|'old', pose, t, ph, dir:±1, skin, hair, hs:'short'|'long'|'bun'|'bald', shirt, sleeve, pants, dress, vest, helmet, cap, bag, glasses, book, cane, sleep})` → `{hand, hand2, head, top}`; pose: stand walk run wave hold read point shout dance sit. Предмет в руку кладётся по `hand`. `crowd(g, x0, x1, y, n, {h, pose, t, kids, old, dresses, shirts, seed, opts:i=>({…})})` - разные люди, соседи разного цвета. Палитры `SKIN` `HAIR` `SHIRTS`.
- Здания: `house(g, x, y, w, h, {wall, roof, door, lit, night})` · `tower(g, x, y, cols, rows, {wall, roof, lit:0..1 (гаснут по одному), grow:0..1 (стройка по этажам), night, cw, ch, seed})` → {x0, top, w, h} · `shop(g, x, y, w, h, {kind:'shop'|'cafe', sign, awning, awning2, door, lit, night})` · `school(g, x, y, w, h, {sign:'Школа'|'Библиотека', flag, lit, night, t})` · `winR(g, x, y, w, h, lit, night)`.
- Растения: `tree(g, x, y, s, {kind:'leaf'|'oak'|'pine', col, trunk, t})` · `grass(g, x0, x1, y, {col, h, t})` · `leaf(g, x, y, s, {col, rot})` · `leaves(g, t, x0, x1, y0, y1, {n, cols, s})` - падают.
- Транспорт (`dir` ±1, `t` крутит колёса): `car(g, x, y, s, {col})` · `bus(g, x, y, s, {col, num:'№3', people})` · `bike(g, x, y, s, {col, rider:{shirt, helmet, dress…}|false})` · `boat(g, x, y, s, {col, stripe, cabin|false, motor, run:0..1, t})` → {deck:[x,y]} (людей ставь на deck).
- Животные: `dog(g, x, y, s, {col, pose:'stand'|'run'|'sit'|'sleep', collar, t})` · `cat(g, x, y, s, {col, pose:'sit'|'walk'|'sleep'})` · `bird(g, x, y, s, {col, fly, t})` · `flock(g, t, cx, cy, n, {r, s})` - стая кружит.
- Небо и природа: `sky(g, x, y, w, h, {tone})` · `sun(g, x, y, r, {col, rays, t})` · `moon(g, x, y, r, {bg})` · `starsky(g, t, x, y, w, h, {n, alpha})` · `cloud(g, x, y, s)` · `sea(g, t, x0, y, x1, y1, {col, amp})` · `hill(g, x, y, w, h, {col})`.
- Улица: `lamp(g, x, y, h, {on:0..1})` · `garland(g, x0, y0, x1, y1, {n, on:0..1, sag, cols})` · `board(g, x, y, w, h, ['Уха 350 ₽', 'Кофе 120 ₽'], {kind:'chalk'|'white'|'wood', legs, n})` (n - сколько букв уже написано).
- Примитивы для своих предметов: `box disc ell poly seg ik mix dark light hsh`.

## Движение и ритм
- Склейка на долю, когда в озвучке звучит новое ключевое слово; сцены с картинкой 2-4 с, с окном 2.4-3.2 с. Смена фона = переход.
- Внутри сцены: слово 0-0.22 с, картинка/интерфейс пружиной (`spr`) с 0.1-0.3 с, дальше внутри картинки действие ровно на слово озвучки (лодки уходят, окна гаснут, кран поднимает плиту, люди машут).
- `cam`: оседание 1.035 → 1 за 0.45 с + медленный наезд. `cycle(u, 0.4, 4)` - смена фона и шрифта на долях, один раз за ролик. `zoomInto` - камера влетает в точку слова, её цвет заливает кадр.

## Звуки
`wood` на склейках (`cutSounds`), `click` на клик, `pop_soft`/`pop_high` на появление, `success` на итог, `bubble` на сообщения, `type` на печать, `counter` на счёт, `tick` на смену времени, `magic` на героя. Для картинок - по смыслу: `bamboo` на проезд, `sparkle` на зажигание огней. 0.1-0.16, 25-40 событий.

## Запреты
Без чужих логотипов и маскотов, без эмодзи, без «-». Не больше одного слова (двух строк) на сцену. Интерфейс и курсор не подменяют предметы. Антиква и узкий шрифт только в `cycle`. Последние 2 с: финальное слово + картинка из темы (или `status` для сервиса), без пустоты.

## Каркас
```js
const U = UIM, C = U.C, TH = U.TH;
const CUTS = [0, 2.5, 5, 8];
const THEMES = ['light', 'ink', 'blue'];
function s0(g, u, th, S, t) {                       // слово + картинка: розовое солнце над морем, лодка с рыбаком
  U.word(g, 'рассвет', 540, 280, { u, color: th.ink, dot: th.dot, size: 180 });
  const p = U.spr(u - 0.15, 10); if (p <= 0) return;
  g.save(); g.globalAlpha = U.cl((u - 0.15) / 0.12, 0, 1); g.translate(0, (1 - p) * 60);
  U.pic(g, 60, 420, 960, 1180, (g, b) => {
    U.sun(g, 760, 760 - U.eo(u / 2) * 120, 90, { col: '#F7A3C0', t });
    U.sea(g, t, b.x, 1000, b.x + b.w, b.y + b.h);
    const B = U.boat(g, 420, 1180, 380, { t, motor: 1, run: U.prog(u, 1.2, 1.6) });
    U.person(g, B.deck[0] + 40, B.deck[1], { h: 150, shirt: C.orange, pose: 'wave', t });
  }, { sky: 'dawn' });
  g.restore();
}
// s1, s2 так же: слово + картинка или слово + один элемент интерфейса (если тема-сервис)
const SC = [s0, s1, s2];
function draw(t, k) {
  const g = k.g; U.tex(); const S = U.scene(t, CUTS), th = TH[THEMES[S.i]];
  U.bg(g, th); g.save(); U.cam(g, S.u); SC[S.i](g, S.u, th, S, t); g.restore();
}
function sound(s) { U.cutSounds(s, CUTS); U.sfx(s, [[1.2, 'bamboo', 0.12]]); }
```
