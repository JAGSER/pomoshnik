# UIM: брендовый UI-моушн

Уверенный продуктовый ролик: интерфейс нарисован кодом, курсор-герой кликает, всё садится пружиной на долю 120 BPM. Сменщик в кадре - продукт под твою тему (сервис, приложение, процесс). Чужие бренды и логотипы не рисуй, имя и адрес придумывай под тему.

## Правила стиля
1. **Палитра**: фиолет `#6C47FF` (акцент, кнопки, ключевое слово), светлый фиолет `#A48FFF` (ключ на тёмном), чернила `#120E2A` (тёмный фон, текст), лаванда `#F3F0FF` (светлый фон), жёлтый `#FFE27A` только для финала и штампа, зелёный `#1FAF6A` только для «готово». Белые карточки с мягкой тенью `card`.
2. **Фон**: `bg(g,t,mode)` чередуй `'dark'`/`'light'`, финал `'brand'`. Точечная сетка дрейфует, пятно света гуляет, это фоновый слой. Никаких градиентов-заглушек.
3. **Линии и формы**: только скруглённые прямоугольники (радиус 18-36, пилюли h/2), обводки 3-8 px, пунктир для пустых слотов. Без свечения у интерфейса.
4. **Текст**: гротеск 800, заголовок 100-124 px по центру сверху (y 270-380), 1-2 строки, слова снизу вверх по очереди, ключевое слово цветом + маркер-плашка. Сообщения ≥44 px, моно для адресов, чисел, меток. Не больше 3 текстовых блоков. Без «—».
5. **Композиция**: заголовок сверху, герой-окно в центре (y 470-1300), снизу подпись/счётчик (y 1330-1600). Каждую сцену 3-4 с меняется главный объект: окно, карусель, ИИ-карточка, график, финал.
6. **Движение**: въезды `spr` (интерфейс с перелётом), текст `eo` без перелёта, курсор `path` с inOut и паузами на кликах. Уход в 1.4 раза быстрее (`t1` в `head`).
7. **Переходы**: жёсткая склейка на доле + `flash` + оседание `cam`. Новый объект въезжает снизу пружиной (`slideY`). Иногда `wipe` фиолетом.
8. **Сквозное**: курсор `cursor` в каждой сцене, счётчик `counter` растёт по шагам, в финале `stamp`.
9. **Звук**: `click` на каждом нажатии курсора (pitch растёт по шагам), `marimba_run`/`kalimba_run` на склейках, `magic`/`sparkle` на ИИ, `type` на печати, `success`/`notify` на результат, `woodblock`+`success3` на штамп, `fanfare_soft` на финал, `drop` на хук.
