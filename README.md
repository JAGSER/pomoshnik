# Помощник — Claude для семьи

Две части:
- **index.html, app.js, style.css, config.json** — само приложение. Лежит на GitHub Pages по адресу ai.duetplay.app. Ключа здесь нет.
- **proxy.js** — прослойка. Работает на бесплатном Deno Deploy, хранит ключи и пароли в секретных настройках.

---

## Запуск — один раз, около 30 минут

### 1. Ключи в консоли Anthropic
1. В консоли Anthropic создайте по рабочему пространству (Workspace) на каждого: «Мама», «Папа», «Сестра».
2. В каждом пространстве поставьте лимит трат в месяц. Например, по $15 родителям и $40 сестре, итого в пределах ваших $100.
3. В каждом пространстве создайте API-ключ и сохраните его. Ключ показывается только один раз.

### 2. Репозиторий на GitHub
1. Создайте новый репозиторий, например `pomoshnik`.
2. Загрузите в корень все файлы.

### 3. Прослойка на Deno Deploy
1. Войдите в Deno Deploy через свой GitHub.
2. Создайте новый проект из репозитория `pomoshnik`, файл запуска — `proxy.js`.
3. В настройках проекта, в разделе переменных окружения (Environment Variables), добавьте:

**ALLOWED_ORIGIN**
```
https://ai.duetplay.app
```

**USERS** — пароли и ключи, всё в одну строку:
```
{"mama":{"password":"придумайте","key":"sk-ant-...мамин","models":["claude-sonnet-5-5"],"webSearch":true},"papa":{"password":"придумайте","key":"sk-ant-...папин","models":["claude-sonnet-5-5"],"webSearch":true},"sister":{"password":"придумайте","key":"sk-ant-...сестры","models":["claude-opus-5-5","claude-sonnet-5-5"],"webSearch":true,"maxTokens":16000}}
```
- Пароли должны быть **новыми**, не от почты или банка. Удобно что-то простое для родителей, например «роза2026».
- `models` — какие модели доступны человеку. Если моделей несколько, в чате появится переключатель.
- `webSearch` — разрешить Claude искать в интернете.

4. Скопируйте адрес проекта вида `https://что-то.deno.dev`.

### 4. Адрес прослойки в настройках приложения
Откройте `config.json` в репозитории и вставьте этот адрес в строку `"proxy"`.

### 5. Поддомен ai.duetplay.app
1. Cloudflare → домен duetplay.app → DNS → добавьте запись:
   тип **CNAME**, имя **ai**, значение **jagser.github.io**.
   **Важно:** облачко должно быть **серым** (DNS only). Если оно оранжевое, трафик идёт через Cloudflare, а его в России замедляют.
2. В репозитории откройте Settings → Pages. Источник — ветка main, корень. Custom domain — `ai.duetplay.app`. Включите Enforce HTTPS.

### 6. Проверка из России
Попросите кого-то из родственников открыть ai.duetplay.app и войти. Если вход не проходит, но сайт открывается, значит, в России недоступен Deno Deploy. Напишите мне, перенесу прослойку на другой бесплатный сервис.

### 7. Установка на телефоне родителей
1. Откройте ai.duetplay.app в Chrome.
2. Меню (три точки) → «Добавить на главный экран». Появится иконка «Помощник».
3. При первом нажатии на 🎤 разрешите доступ к микрофону.
4. После входа пароль запоминается, вводить его снова не нужно.

## Админка: как управлять

Всё настраивается в **config.json** на GitHub. Нажимаете на карандаш, правите, сохраняете. Через минуту у всех обновится.

- **Новая функция:** скопируйте блок `"example"` в разделе `presets` и дайте ему своё имя, например `"lekarstva"`. Заполните поля:
  - `icon` — значок;
  - `title` — название;
  - `subtitle` — подпись;
  - `system` — скрытая инструкция для Claude;
  - `greeting` — первое сообщение, которое видит человек.
- **Показать функцию человеку:** добавьте её имя в его список `presets`.
- **Крупный текст:** `bigText: true`.
- **Ответы вслух автоматически:** `readAloud: true`.
- **Общий стиль ответов для всех:** поле `baseSystem`.

**Новый человек** (например, муж сестры) добавляется в двух местах:
- в `config.json` → `users`;
- в переменную `USERS` в Deno Deploy, с паролем и ключом.

**Сменить пароль или отключить человека:** правите `USERS` в Deno Deploy. Приложение трогать не нужно.

**Если ключ утёк:** удалите его в консоли Anthropic, создайте новый и вставьте в `USERS`.

## Что умеет первая версия
- вход по имени и паролю;
- функции-пресеты, у каждого свой набор;
- вопросы голосом (микрофон) и чтение ответов вслух;
- фото (сжимаются автоматически, чтобы было дешевле), PDF и текстовые файлы;
- поиск в интернете;
- история разговоров на устройстве; если почистить браузер, она удалится;
- выбор модели для тех, у кого их несколько;
- кнопка остановки ответа, кнопка «Повторить» при ошибке, понятные сообщения, если закончился лимит.

**Следующий этап для сестры:** субтитры (Whisper) и монтаж (ffmpeg) прямо в браузере.
